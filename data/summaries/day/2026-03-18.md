On Mar 18, 2026, Optimism's development focused heavily on improving CI stability and addressing critical infrastructure issues, alongside significant progress in core protocol enhancements and Supernode functionality. Key achievements include the completion of the Makefile to Justfile migration across the monorepo and the resolution of several flaky tests, while investigations into a "BAD BLOCK" error on Base Mainnet and persistent CI job failures are ongoing. The team also introduced L2 Dev Flags and enhanced Supernode interoperability, demonstrating continued commitment to a robust and scalable Superchain ecosystem.

## 🚨 Needs Attention
- **Urgent Discussion: `op-node` Initial EL Sync UX and Correctness**: The discussion on [#17631](https://github.com/ethereum-optimism/infra/issues/17631) (also in `superchain-ops` and `op-geth`) requires input to finalize the approach for correctly setting safe and finalized heads after initial EL sync, with option 2 (setting safe/finalized to unsafe head minus sequencer window) currently favored.
- **Urgent Discussion: Non-terminating CI job `memory-all-opn-op-geth`**: The issue [#19563](https://github.com/ethereum-optimism/infra/issues/19563) (also in `superchain-ops` and `op-geth`) was reopened due to continued flakiness, and a draft fix is in progress to address RPC calls blocking indefinitely due to CI resource contention.
- **Urgent Discussion: Flaky test `TestSupernodeSameTimestampInvalidTransitive`**: The issue [#19570](https://github.com/ethereum-optimism/infra/issues/19570) (also in `superchain-ops` and `op-geth`) requires a decision on the best fix for a race condition causing infinite retries in the `RewindEngine`.
- **New Issue: Base Mainnet Bad Block**: Issue [#778](https://github.com/ethereum-optimism/infra/issues/778) (also in `superchain-ops` and `op-geth`) reports a critical "BAD BLOCK, invalid gas used" error on Base Mainnet that requires immediate investigation.
- **New Issue: Kona Protocol Configuration**: Issue [#19636](https://github.com/ethereum-optimism/infra/issues/19636) (also in `superchain-ops` and `op-geth`) highlights Kona's `MessageGraph` using a hardcoded `MESSAGE_EXPIRY_WINDOW` instead of configurable values, which may need to be addressed for flexibility.
- **New Issue: Interop activation transactions omitting bridge deployment**: Issue [#19646](https://github.com/ethereum-optimism/optimism/issues/19646) indicates that interop activation transactions are not deploying and funding `SuperchainETHBridge` and `ETHLiquidity` in the hardfork path, which needs to be resolved for proper interoperability.
- **New Issue: Kona guest program panicking**: Issue [#19654](https://github.com/ethereum-optimism/optimism/issues/19654) reports the Kona guest program panicking during Cannon VM execution due to a missing `name` field in the superchain registry chain list, requiring urgent attention.

## ✅ Completed Work
### CI/CD & Build System Improvements
- **Makefile to Justfile Migration Completed**: The migration of all Makefiles in the monorepo to Justfiles was completed, improving build system consistency and maintainability. ([ethereum-optimism/infra#19546](https://github.com/ethereum-optimism/infra/issues/19546), [ethereum-optimism/superchain-ops#19546](https://github.com/ethereum-optimism/superchain-ops/issues/19546), [ethereum-optimism/op-geth#19546](https://github.com/ethereum-optimism/op-geth/issues/19546), [ethereum-optimism/optimism#19546](https://github.com/ethereum-optimism/optimism/issues/19546))
- **Flaky Test `TestCLIBootstrapForge` Resolved**: The root cause of this flaky test was identified as a 60-second context timeout during contract deployments, and a fix was implemented to increase the timeout to 5 minutes. ([ethereum-optimism/infra#19627](https://github.com/ethereum-optimism/infra/issues/19627), [ethereum-optimism/superchain-ops#19627](https://github.com/ethereum-optimism/superchain-ops/issues/19627), [ethereum-optimism/op-geth#19627](https://github.com/ethereum-optimism/op-geth/issues/19627), [ethereum-optimism/optimism#19627](https://github.com/ethereum-optimism/optimism/issues/19627))
- **`TestCLIMigrate` Flakiness Addressed**: Increased timeouts for `TestCLIMigrate` tests in `op-deployer` to resolve flakiness caused by external RPC dependencies. ([ethereum-optimism/optimism#19625](https://github.com/ethereum-optimism/optimism/pull/19625), [ethereum-optimism/optimism#19624](https://github.com/ethereum-optimism/optimism/issues/19624))
- **`TestAddressValidDeployment` Reliability Improved**: Implemented retry logic for flaky RPC calls in `TestAddressValidDeployment` within `op-validator` to improve test reliability. ([ethereum-optimism/optimism#19592](https://github.com/ethereum-optimism/optimism/pull/19592), [ethereum-optimism/optimism#19591](https://github.com/ethereum-optimism/optimism/issues/19591))
- **`GameHelper` Flakiness Addressed**: Added a 5-minute timeout to transactions in `GameHelper` to prevent tests from hanging indefinitely. ([ethereum-optimism/optimism#19556](https://github.com/ethereum-optimism/optimism/pull/19556))
- **New Scripts for Test Debugging**: Introduced new scripts to split `gotestsum` logs into per-test files, improving test debugging and analysis. ([ethereum-optimism/optimism#19575](https://github.com/ethereum-optimism/optimism/pull/19575))

### Core Protocol & Supernode Enhancements
- **L2 Dev Flags Implemented**: Added an `L2DevFeatureFlags` predeploy to store per-chain flags, enhancing development flexibility and control. ([ethereum-optimism/optimism#19324](https://github.com/ethereum-optimism/optimism/pull/19324))
- **L2 Proxied Contracts Standardized**: Moved `ProxyAdminOwnedBase` to a universal location and added its inheritance to 7 L2 contracts with `initialize()` functions, standardizing contract patterns. ([ethereum-optimism/optimism#19564](https://github.com/ethereum-optimism/optimism/pull/19564))
- **Supernode `check-super-root` Script Updated**: The `check-super-root` script was updated to utilize a single SuperNode RPC, simplifying the process of fetching verified super roots and improving efficiency. ([ethereum-optimism/optimism#19454](https://github.com/ethereum-optimism/optimism/pull/19454), [ethereum-optimism/optimism#19177](https://github.com/ethereum-optimism/optimism/issues/19177))
- **`op-supernode` Interop `CurrentL1` Bug Fix**: Fixed a bug in `op-supernode` to cap interop `CurrentL1` at the minimum of node `CurrentL1`s during advancement, ensuring correct L1 block derivation across chains. ([ethereum-optimism/optimism#19620](https://github.com/ethereum-optimism/optimism/pull/19620))
- **`op-supernode` Beacon Fallback Support**: Added beacon fallback support for blob sidecar retrieval in `op-supernode`, mirroring `op-node`'s functionality and improving robustness. ([ethereum-optimism/optimism#19645](https://github.com/ethereum-optimism/optimism/pull/19645))
- **Supernode and Interop Official Releases**: Official releases for the Supernode and Interop filter binaries have been cut, moving from branch builds to formal versioned releases. ([ethereum-optimism/optimism#19568](https://github.com/ethereum-optimism/optimism/issues/19568))

### Testing & Interoperability Enhancements
- **`TestSupernodeInteropActivationAfterGenesis` Re-enabled**: This test was re-enabled by removing a previous skip, allowing for full testing of interop activation scenarios. ([ethereum-optimism/optimism#19615](https://github.com/ethereum-optimism/optimism/pull/19615), [ethereum-optimism/optimism#19403](https://github.com/ethereum-optimism/optimism/issues/19403), [ethereum-optimism/optimism#19609](https://github.com/ethereum-optimism/optimism/issues/19609))
- **`TestInteropFaultProofs_VariedBlockTimes` Migrated**: Migrated this test to the shared `superfaultproofs` package, enabling more comprehensive testing of super fault proofs with non-uniform block times. ([ethereum-optimism/optimism#19626](https://github.com/ethereum-optimism/optimism/pull/19626))
