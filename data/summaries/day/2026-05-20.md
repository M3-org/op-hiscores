On May 20, 2026, the Optimism project focused heavily on infrastructure improvements, particularly migrating CircleCI jobs to Gen2 for cost optimization and enhancing CI/CD reliability. Significant progress was also made in addressing several flaky tests across multiple repositories, with root causes identified and fixes proposed, alongside critical bug fixes for L2CM upgrades and `op-supernode` interop configurations.

## ✅ Completed Work
### CI/CD Infrastructure & Efficiency
- **CircleCI Gen2 Migration**: Migrated 41 Docker jobs in `optimism` from Gen1 to Gen2 resource classes, and resized the `fuzz-golang` job to `xlarge.gen2` for better performance. ([ethereum-optimism/optimism#20917](https://github.com/ethereum-optimism/optimism/pull/20917), [ethereum-optimism/optimism#20931](https://github.com/ethereum-optimism/optimism/pull/20931))
- **`infra` CircleCI Upgrade**: Migrated three Docker jobs in `infra` from Gen1 to Gen2 on CircleCI for cost reduction. ([ethereum-optimism/infra#626](https://github.com/ethereum-optimism/infra/pull/626))
- **`superchain-registry` CI Configuration Update**: Removed `circleci_ip_ranges` flag from six jobs and migrated five Tier-B jobs to `circleci-repo-rpc-secrets` context. ([ethereum-optimism/superchain-registry#1233](https://github.com/ethereum-optimism/superchain-registry/pull/1233))

### Core Protocol & Interoperability Fixes
- **L2CM Upgrade Fixes**: Addressed a bug in the L2CM upgrade path that silently dropped authorized minters on XLayer, ensuring minters are preserved across upgrades. ([ethereum-optimism/optimism#20816](https://github.com/ethereum-optimism/optimism/pull/20816))
- **`op-supernode` Backfill Logic Refinement**: Resolved an issue where `op-supernode` would fail to start if a backfill depth was specified but the interop activation timestamp was not set, by implementing a fix to ignore the backfill depth in such cases. ([ethereum-optimism/optimism#20894](https://github.com/ethereum-optimism/optimism/pull/20894), [ethereum-optimism/infra#20892](https://github.com/ethereum-optimism/infra/issues/20892), [ethereum-optimism/specs#20892](https://github.com/ethereum-optimism/specs/issues/20892))
- **Superchain Registry Depsets**: Fixed an issue in Kona's registry to embed `superchain-registry` depsets, ensuring `BootInfo::load` correctly uses embedded dependency sets. ([ethereum-optimism/optimism#20837](https://github.com/ethereum-optimism/optimism/pull/20837))
- **`debug_executePayload` Necessity Confirmed**: Investigated and confirmed that `debug_executePayload` and related crates are essential for `op-reth` to function as a source for `kona-proofs`, serving as an active, opt-in fast-path for fault-proof witness prefetching. ([ethereum-optimism/infra#20879](https://github.com/ethereum-optimism/infra/issues/20879), [ethereum-optimism/specs#20879](https://github.com/ethereum-optimism/specs/issues/20879))

### Testing & Development Experience
- **Acceptance Test Refinements**: Replaced sleep polling with condition-based waits and context-aware timers in acceptance tests to improve reliability. ([ethereum-optimism/optimism#20868](https://github.com/ethereum-optimism/optimism/pull/20868))
- **Resource Configuration Scaling**: Implemented a feature to scale `ResourceConfig` to accommodate smaller `gasLimits` in `DeployOPChain.s.sol`. ([ethereum-optimism/optimism#20919](https://github.com/ethereum-optimism/optimism/pull/20919))
