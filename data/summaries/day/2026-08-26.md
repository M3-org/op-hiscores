Aug 26, 2026

Today, significant progress was made across the Optimism ecosystem, with key developments in infrastructure, protocol specifications, and core Optimism components. Notably, `op-geth` saw a major upgrade to its P2P networking with the migration of the STUN client to Pion v3, while `infra` enhanced `proxyd` with improved rate-limiting metrics and a new transaction UX monitor. The `optimism` repository also advanced with `kona` protocol enhancements and several new pull requests addressing sequencer-defined fees and private interoperable chains.

## 🚨 Needs Attention
- **Kona Node Configuration Issues**: The `--sequencer.max-safe-lag` and `--conductor.rpc.timeout` flags in `kona-node` are silently ignored, leading to unexpected behavior for operators. This issue requires investigation to ensure proper flag application. ([#22667](https://github.com/ethereum-optimism/optimism/issues/22667))

## ✅ Completed Work
### P2P Networking Enhancements
- **`op-geth` STUN Client Migration**: The NAT STUN client was migrated from Pion v2 to Pion v3, removing legacy modules and updating dependency files for improved performance and dependency management. ([#807](https://github.com/ethereum-optimism/op-geth/pull/807))

### Infrastructure Tooling Improvements
- **`proxyd` Rate-Limiting Metrics**: A bug fix was implemented in `proxyd` to add fixed-cardinality frontend rate-limit metrics, providing better visibility into rate-limited addresses and rejection distribution. ([#725](https://github.com/ethereum-optimism/infra/pull/725))
- **`proxyd` Passive Transaction UX Monitor**: A new `tx_monitor` feature was introduced to `proxyd` for passive transaction user experience monitoring. ([#726](https://github.com/ethereum-optimism/infra/pull/726))

### Kona Protocol Enhancements
- **Actionable Proof Replay Warnings**: Proof replay warnings in `kona-sp1-proposer` were clarified to provide actionable guidance during L1 rewinding for channel recovery. ([#22623](https://github.com/ethereum-optimism/optimism/pull/22623))
- **Gossip Subscription Topic Handling**: The `kona-gossip` component was updated to allowlist gossip subscription topics, preventing acceptance of subscriptions for any announced topic. ([#22661](https://github.com/ethereum-optimism/optimism/pull/22661))
