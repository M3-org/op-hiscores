Optimism's development today saw significant progress in enhancing the Optimism Portal's security and enabling permissionless fault games from initial deployment, alongside critical Superchain registry maintenance and performance optimizations for proof backfilling. ## ✅ Completed Work
### Security & Fault Game Enhancements
- Security for the Optimism Portal was strengthened with new validation checks for inputs during `migrateToSharedDisputeGame` ([ethereum-optimism/optimism#20928](https://github.com/ethereum-optimism/optimism/pull/20928)).
- New chains can now be launched with permissionless fault games (Cannon and Cannon-Kona) from genesis, removing the need for a permissioned game type at initial deployment ([ethereum-optimism/optimism#21588](https://github.com/ethereum-optimism/optimism/pull/21588)).
- Critical fix for `OptimismPortal2.migrateToSharedDisputeGame` to prevent acceptance of bad targets without validation ([ethereum-optimism/optimism#20881](https://github.com/ethereum-optimism/optimism/issues/20881)).
- The permissioned-only guard and dead anchor placeholder in `DeployOPChain.s.sol` were removed, allowing more flexible initial deployments ([ethereum-optimism/optimism#20913](https://github.com/ethereum-optimism/optimism/issues/20913)).

### Superchain Registry & Configuration Management
- The `superchain-registry` submodule was updated to fix a drift issue, ensuring consistency in checks ([ethereum-optimism/superchain-ops#1496](https://github.com/ethereum-optimism/superchain-ops/pull/1496)).
- The `sepolia-devnet-2` chain configuration was added to the Superchain registry ([ethereum-optimism/superchain-registry#1283](https://github.com/ethereum-optimism/superchain-registry/pull/1283)).
- The `rehearsal-0-bn` superchain was removed from the registry ([ethereum-optimism/superchain-registry#1285](https://github.com/ethereum-optimism/superchain-registry/pull/1285)).
- CI was improved to prune removed superchains during codegen, replacing a hardcoded exception ([ethereum-optimism/superchain-registry#1286](https://github.com/ethereum-optimism/superchain-registry/pull/1286)).
- An automated codegen update was performed, primarily affecting `addresses.json` ([ethereum-optimism/superchain-registry#1284](https://github.com/ethereum-optimism/superchain-registry/pull/1284)).
- The Superchain Registry was updated to sync Karst gas compatibility configurations, including bumping the registry gitlink and regenerating embedded artifacts ([ethereum-optimism/optimism#21674](https://github.com/ethereum-optimism/optimism/pull/21674)).

### Performance & Code Refactoring
- The `op-proofs backfill` process was optimized by batching multiple blocks into a single MDBX transaction, improving performance ([ethereum-optimism/optimism#21602](https://github.com/ethereum-optimism/optimism/pull/21602)).
- The base pool-builder configuration in `OpNode` was extracted into a reusable method ([ethereum-optimism/optimism#21688](https://github.com/ethereum-optimism/optimism/pull/21688)).
- The `fetch_safe_head_hash` function in Kona was refactored and hoisted into `kona-proof`, eliminating duplicate code and tests ([ethereum-optimism/optimism#21696](https://github.com/ethereum-optimism/optimism/pull/21696)).

### Issue Resolution & Interop Audit
- Several flaky tests related to reorgs and unsafe heads, including `TestReorgUnsafeHead` ([ethereum-optimism/optimism#20198](https://github.com/ethereum-optimism/optimism/issues/20198)) and `TestReorgInitExecMsg` ([ethereum-optimism/optimism#20943](https://github.com/ethereum-optimism/optimism/issues/20943)), were closed.
- Issues identified during interop audits were closed ([ethereum-optimism/optimism#20985](https://github.com/ethereum-optimism/optimism/issues/20985)).
- The versioning discrepancy in Kona and op-reth Prometheus metrics was resolved ([ethereum-optimism/optimism#20832](https://github.com/ethereum-optimism/optimism/issues/20832)).
- The security threat model and analysis for interop has been completed ([ethereum-optimism/superchain-ops#21475](https://github.com/ethereum-optimism/superchain-ops/issues/21475), [ethereum-optimism/superchain-registry#21475](https://github.com/ethereum-optimism/superchain-registry/issues/21475), [ethereum-optimism/optimism#21475](https://github.com/ethereum-optimism/optimism/issues/21475)).
