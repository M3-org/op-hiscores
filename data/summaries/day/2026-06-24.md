On Jun 24, 2026, significant progress was made on core infrastructure and security, including enhancements to FeeVault security and the refinement of the op-node's P2P sync client. A major ongoing discussion across multiple repositories centers on a flaky test related to blob encoding, with implications for potential hardforks or test adjustments. Documentation for Sequencer Defined Metering (SDM) was also substantially updated and completed.

## 🚨 Needs Attention
- **Urgent Discussions**: The flaky test `FuzzDetectNonBijectivity` ([#21539](https://github.com/ethereum-optimism/design-docs/issues/21539), [#21539](https://github.com/ethereum-optimism/infra/issues/21539), [#21539](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/21539), [#21539](https://github.com/ethereum-optimism/superchain-ops/issues/21539), [#21539](https://github.com/ethereum-optimism/superchain-registry/issues/21539), [#21539](https://github.com/ethereum-optimism/optimism/issues/21539)) requires a decision on whether to adjust the test harness or consider a hardfork to change encoding/decoding behavior, as the current test premise is flawed due to non-bijective blob code.
- **New Issues**: `op-reth` has new issues regarding its transaction pool admitting transactions that cannot be included on OP chains due to missing L1-info deposit gas reservation ([#21546](https://github.com/ethereum-optimism/optimism/issues/21546)) and incorrect `contractAddress` in deposit contract-creation receipts ([#21549](https://github.com/ethereum-optimism/optimism/issues/21549)).
- **New Issue**: Building `kona-sp1` guest ELFs in CI is proposed as the current monorepo CircleCI does not build them, leading to builds against empty placeholder ELFs ([#21553](https://github.com/ethereum-optimism/optimism/issues/21553)).

## ✅ Completed Work
### Core Protocol Enhancements & Security
- **FeeVault Security and Withdrawal Route Management**: A new feature was added to the FeeVault allowing proxy admin owners to atomically update recipient and withdrawal networks, enhancing security and preventing partial updates ([#20982](https://github.com/ethereum-optimism/optimism/pull/20982)).
- **op-node P2P Sync Client Refinement**: The deprecated Req/Resp CL P2P sync client was removed from the op-node in a phased rollout to ensure a safe upgrade path ([#21498](https://github.com/ethereum-optimism/optimism/pull/21498)).
- **Kona SP1 Integration**: A new `kona-sp1` range-executor was introduced, enabling end-to-end testing of the range guest with op-e2e action tests ([#21528](https://github.com/ethereum-optimism/optimism/pull/21528)).

### Operational Maintenance and Developer Experience
- **Foundry Installation Fix**: Stale Foundry installations left by the old `mise` UBI alias were fixed, ensuring a cleaner environment for users running `mise install` ([#1485](https://github.com/ethereum-optimism/superchain-ops/pull/1485)).
- **Ink Sepolia Gas Limit Reset**: A bug in Karst (U19) related to an op-node/kona-node issue that left the effective L2 block gas limit above the SystemConfig value after activation was addressed for Ink Sepolia ([#1481](https://github.com/ethereum-optimism/superchain-ops/pull/1481)).
- **Foundation Safe Signer Rotation**: Two signers were rotated on both the Foundation Upgrade Safe (FUS) and Foundation Operations Safe (FOS) to enhance security and operational resilience ([#1479](https://github.com/ethereum-optimism/superchain-ops/pull/1479)).
- **op-reth Proofs Bug Fix**: A bug in `op-reth`'s `op-proofs init` command was fixed to ensure correct post-init backfill behavior ([#21543](https://github.com/ethereum-optimism/optimism/pull/21543)).
- **Karst Activation Acceptance Test**: An acceptance test was added for the Karst activation to verify the upgrade-gas revert across activation, addressing a previous leak fix ([#21533](https://github.com/ethereum-optimism/optimism/pull/21533)).

### Documentation and Guides
- **Sequencer Defined Metering (SDM) Documentation**: Operator documentation for SDM, covering activation, behavior, limitations, and rollout guidance, was completed ([#21211](https://github.com/ethereum-optimism/optimism/pull/21211)).
- **Protocol Explainer Migration**: Protocol explainers and network design documentation were migrated to op-reth/kona ([#21146](https://github.com/ethereum-optimism/optimism/pull/21146)).
