On Aug 25, 2026, Optimism's development focused on infrastructure enhancements, with `kona-node-service` gaining multi-chain L1 watcher support for improved scalability, and `proxyd` receiving new rate-limiting metrics. Routine maintenance and updates to Superchain operations, including a nested upgrade rehearsal, also took place.

## ✅ Completed Work
### Superchain Operations & Infrastructure
- An update was made to the Ink Mainnet FOS/FUS switch status task README ([ethereum-optimism/superchain-ops#1526](https://github.com/ethereum-optimism/superchain-ops/pull/1526)).
- A rehearsal for a 2026-08-25 R3 nested upgrade was added, including new configuration files and addresses ([ethereum-optimism/superchain-ops#1525](https://github.com/ethereum-optimism/superchain-ops/pull/1525)).
- An issue concerning contracts being compiled twice during simulation, signing, or running was closed, with the resolution that `forge build` is not needed before `forge run script` ([ethereum-optimism/superchain-ops#423](https://github.com/ethereum-optimism/superchain-ops/issues/423)).

### Core Protocol Enhancements
- The `L1WatcherActor` in `kona-node-service` was refactored to support multiple chains, improving its ability to monitor various L1 chains simultaneously ([ethereum-optimism/optimism#22567](https://github.com/ethereum-optimism/optimism/pull/22567)).
