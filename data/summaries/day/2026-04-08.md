On Apr 8, 2026, Optimism saw significant progress in stabilizing its testing infrastructure with numerous flaky tests resolved, alongside critical updates to dispute game functionalities and dependency upgrades across several components. A key emerging challenge is the reactive runtime configuration reloading for op-node verifier nodes, which is causing issues with unsafe block signer mismatches and requires immediate attention.

## 🚨 Needs Attention
- **Urgent Discussions**: The issue `op-node: reactive runtime config reload on unsafe block signer mismatch` [#19981](https://github.com/ethereum-optimism/design-docs/issues/19981) is actively discussing solutions for verifier nodes rejecting valid blocks due to stale signer windows, with a draft PR [#19982](https://github.com/ethereum-optimism/design-docs/pull/19982) already created. Input is needed on the proposed grace period or more frequent config loading.
- **Blocked Issues/PRs**: The `Chore(proof/ci): Reactivate Interop Action Tests` [#18974](https://github.com/ethereum-optimism/design-docs/issues/18974) is awaiting migration of `op-e2e` interop action tests to `op-acceptance-tests` in a separate ticket.

## ✅ Completed Work
### Test Stability and Infrastructure Improvements
- **Flaky Test Resolution**: Several flaky tests, including `TestTruncateDatabaseOnELResync` and `TestExecutePayloadSuccess`, were resolved across `design-docs`, `ecosystem`, `infra`, and `optimism` repositories, significantly improving CI reliability. ([#19897](https://github.com/ethereum-optimism/design-docs/issues/19897), [#19898](https://github.com/ethereum-optimism/design-docs/issues/19898))
- **Acceptance Test Unskip**: Acceptance tests for invalid executing messages were unskipped and closed, indicating readiness of the test infrastructure. ([#19712](https://github.com/ethereum-optimism/design-docs/issues/19712))
- **Flashblocks Test Stabilization**: `TestFlashblocksTransfer` was stabilized by removing a wall-clock assertion, addressing a common cause of flakiness. ([#19959](https://github.com/ethereum-optimism/optimism/pull/19959))

### Dispute Game and Supernode Enhancements
- **Dispute Game Migration**: Shared dispute game functionalities were migrated from `OptimismPortalInterop` to `OptimismPortal2`, unifying contract logic for interop migrations. ([#19840](https://github.com/ethereum-optimism/optimism/pull/19840))
- **Superroot SLA Updates**: Final updates related to Full Outputs in Denylist and its use for OptimisticOutput were merged, closing the `op-supernode: Superroot SLA Updates` issue. ([#19180](https://github.com/ethereum-optimism/design-docs/issues/19180))
- **Dispute Game Helper Logic Fixes**: Corrected dispute game helper logic in `op-e2e` to send required bonds and restore correct Cannon-Kona game types, resolving deployment and challenger configuration mismatches. ([#19953](https://github.com/ethereum-optimism/optimism/pull/19953), [#19983](https://github.com/ethereum-optimism/optimism/pull/19983))

### Core Component Updates and Tooling
- **NUTs Command Addition**: New `update-nuts` and `verify-nuts` commands were added for managing NUT bundles, enhancing the integrity and verification process of forks. ([#19463](https://github.com/ethereum-optimism/optimism/pull/19463))
- **`op-reth` Engine Validator Customization**: A method to customize the engine validator in `OpAddOns` for `op-reth` was introduced, allowing for more flexible engine configurations. ([#19907](https://github.com/ethereum-optimism/optimism/pull/19907))
- **`kona-node` Sequencer Panic Fix**: A panic in `kona-node`'s sequencer was fixed by gracefully handling missing L1 origin blocks, preventing crashes during reorgs or sync lags. ([#19945](https://github.com/ethereum-optimism/optimism/pull/19945))

### Dependency and Documentation Updates
- **OpenTelemetry and `lodash` Updates**: Multiple OpenTelemetry dependencies in `op-acceptor` and the `lodash` library in `replica-healthcheck` were updated to their latest versions. ([#601](https://github.com/ethereum-optimism/infra/pull/601), [#600](https://github.com/ethereum-optimism/infra/pull/600), [#599](https://github.com/ethereum-optimism/infra/pull/599), [#598](https://github.com/ethereum-optimism/infra/pull/598))
- **`drizzle-orm` and `hono` Updates**: Core dependencies `drizzle-orm` and `hono` were updated across various applications in the `ecosystem` repository. ([#989](https://github.com/ethereum-optimism/ecosystem/pull/989), [#988](https://github.com/ethereum-optimism/ecosystem/pull/988), [#987](https://github.com/ethereum-optimism/ecosystem/pull/987), [#986](https://github.com/ethereum-optimism/ecosystem/pull/986))
- **Fee Vaults Documentation**: New documentation for fee vaults, including an explainer and an operations guide, was published to enhance clarity for chain operators. ([#19952](https://github.com/ethereum-optimism/optimism/pull/19952))
