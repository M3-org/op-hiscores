On Jul 13, 2026, the Optimism project focused on refining core infrastructure, enhancing observability, and improving documentation, alongside ongoing discussions about `op-revm` synchronization and simplifying `op-challenger`'s dispute game handling. Key developments included the removal of deprecated features, introduction of new metrics for hardfork activation data, and updates to documentation and CI/CD processes.

## ✅ Completed Work
### Infrastructure Refinements and Deprecation
- The `CANNON_KONA` development feature toggle was removed, streamlining the codebase and simplifying CI processes by removing several `op-geth` CI variants. ([ethereum-optimism/optimism#21663](https://github.com/ethereum-optimism/optimism/pull/21663), [ethereum-optimism/optimism#21715](https://github.com/ethereum-optimism/optimism/pull/21715))
- The APKO factory workflow pin was updated to the latest merged commit, ensuring CI/CD processes use recent configurations. ([ethereum-optimism/infra#667](https://github.com/ethereum-optimism/infra/pull/667))
- CircleCI configuration was updated to correctly tag the Protocol team for daily codegen job and run failure notifications. ([ethereum-optimism/superchain-registry#1287](https://github.com/ethereum-optimism/superchain-registry/pull/1287))

### Enhanced Observability and Metrics
- New metrics were introduced to expose chain hardfork activation data in Prometheus for `op-reth` and `op-node`, improving monitoring of L2 hardfork schedules. ([ethereum-optimism/optimism#21704](https://github.com/ethereum-optimism/optimism/pull/21704), [ethereum-optimism/optimism#21701](https://github.com/ethereum-optimism/optimism/pull/21701))

### Documentation and Tooling Improvements
- Documentation for rollup configuration fields was updated, and the `op-geth` decoupling plan documentation was revised to a strategic overview. ([ethereum-optimism/optimism#21694](https://github.com/ethereum-optimism/optimism/pull/21694), [ethereum-optimism/optimism#21721](https://github.com/ethereum-optimism/optimism/pull/21721))
- A new check was added to verify NUT pre-fork state snapshots, ensuring consistency. ([ethereum-optimism/optimism#21716](https://github.com/ethereum-optimism/optimism/pull/21716))
