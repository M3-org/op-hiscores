## ✅ Completed Work

### Protocol Specification & Interoperability Enhancements
- **Subblocks Specification**: Replaced the detailed Flashblocks specification with a minimal, consumer-facing Subblocks specification, including documentation for WebSocket payload format, sequencing guarantees, JSON-RPC behavior, and transaction inclusion implications. ([ethereum-optimism/specs#933](https://github.com/ethereum-optimism/specs/pull/933))
- **`op-challenger` Bug Fix**: Fixed a critical bug in `op-challenger` where the interop VM runner selected an unusable game L1 head, preventing proper claim serving. ([ethereum-optimism/optimism#22727](https://github.com/ethereum-optimism/optimism/pull/22727))
- **Kona SP1 Prover Improvements**: Enhanced the Kona SP1 prover to retain proving progress across retries, preventing loss of completed chunks and SPN request IDs after failures. ([ethereum-optimism/optimism#22717](https://github.com/ethereum-optimism/optimism/pull/22717))

### Infrastructure & Dependency Streamlining
- **`op-service` Refactoring**: Moved `PathFlag` to a new leaf package in `op-service` to allow `oppprof` to be imported downstream without pulling in the superchain config bundle. ([ethereum-optimism/optimism#22700](https://github.com/ethereum-optimism/optimism/pull/22700))
- **`op-batcher` Dependency Reduction**: Removed `op-batcher`'s dependency on the `superchain-configs.zip` bundle and enabled `op-node` to build its display map without parsing every embedded chain config at initialization. ([ethereum-optimism/optimism#22712](https://github.com/ethereum-optimism/optimism/pull/22712))

### CI/CD & Documentation Updates
- **CI Configuration Update**: Bumped the `circleci-utils` orb to version 1.0.31, which includes a fix for stale PR close timing. ([ethereum-optimism/optimism#22723](https://github.com/ethereum-optimism/optimism/pull/22723))
- **`apko` Factory Pin Update**: Updated the `apko` factory pin to restore version stamping in image builds. ([ethereum-optimism/optimism#22722](https://github.com/ethereum-optimism/optimism/pull/22722))
- **RPC Provider Documentation**: Enhanced documentation by adding SolidRPC to the OP Stack production RPC provider directory, detailing its support for various mainnets and testnets. ([ethereum-optimism/optimism#22710](https://github.com/ethereum-optimism/optimism/pull/22710))
