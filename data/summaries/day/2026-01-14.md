On January 14, 2026, a critical `eth_simulateV1` issue, which had been impacting transaction simulations on OP Stack-based EVM chains, was resolved and released in `op-geth` v1.101605.0, addressing a significant concern for backrunning strategies. Concurrently, significant progress was made in enabling SaferSafes across various networks, alongside enhancements to testing infrastructure and core configurations within the `optimism` repository.

    - `ethereum-optimism/optimism` [#18784](https://github.com/ethereum-optimism/optimism/issues/18784) An issue highlights the problem of having multiple nearly-identical `DummyCaller` contracts and suggests consolidating them into a single generic implementation.

### Superchain Operations & Security Enhancements
- **`superchain-ops`**: Added new features to enable SaferSafes on Betanet/Sepolia, involving updates to configuration files and READMEs for multiple tasks. ([#1343](https://github.com/ethereum-optimism/superchain-ops/pull/1343))
- **`superchain-ops`**: Introduced new tasks to enable the LivenessModule (SaferSafes) on FUS and FOS, with Superchain as a backup and required parameters. ([#1340](https://github.com/ethereum-optimism/superchain-ops/pull/1340))
- **`optimism`**: Completed L1 Pectra Defense DGF Upgrade tasks for both Sepolia and Mainnet Superchains. ([#14065](https://github.com/ethereum-optimism/optimism/issues/14065), [#14068](https://github.com/ethereum-optimism/optimism/issues/14068))

### Developer Experience & Code Quality

- **`optimism`**: Introduced a Semgrep rule to enforce `opcM` prefixing for all immutable variables in `OPContractsManagerV2`, ensuring proper identification by the `VerifyOPCM` script. ([#18679](https://github.com/ethereum-optimism/optimism/pull/18679))
