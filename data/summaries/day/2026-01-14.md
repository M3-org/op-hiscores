On January 14, 2026, a critical `eth_simulateV1` issue impacting transaction simulations on OP Stack-based EVM chains was resolved and released in `op-geth v1.101605.0`, alongside significant progress in testing for this function across multiple repositories. Documentation efforts continued with new pull requests for operator fees and flashblocks, while development in `superchain-ops` focused on enabling SaferSafes across various networks. The `optimism` repository saw enhanced deployment testing, critical configuration updates, and initial work on porting the Kona project.

## ✅ Completed Work

### `eth_simulateV1` Functionality and Testing Improvements
- A critical issue where `eth_simulateV1` returned an error related to missing deposit transactions was resolved and released in `op-geth v1.101605.0`, fixing a problem that affected backrunning strategies on OP Stack-based EVM chains. ([ethereum-optimism/op-geth#739](https://github.com/ethereum-optimism/op-geth/issues/739), [ethereum-optimism/optimism#739](https://github.com/ethereum-optimism/optimism/issues/739), [ethereum-optimism/docs#739](https://github.com/ethereum-optimism/docs/issues/739), [ethereum-optimism/op-analytics#739](https://github.com/ethereum-optimism/op-analytics/issues/739), [ethereum-optimism/ethereum-optimism.github.io#739](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/739), [ethereum-optimism/superchain-ops#739](https://github.com/ethereum-optimism/superchain-ops/issues/739))
- A long-standing issue to add a test for `eth_simulateV1` in `op-e2e` was closed, indicating that necessary testing has been implemented. ([ethereum-optimism/op-geth#14690](https://github.com/ethereum-optimism/op-geth/issues/14690), [ethereum-optimism/optimism#14690](https://github.com/ethereum-optimism/optimism/issues/14690), [ethereum-optimism/docs#14690](https://github.com/ethereum-optimism/docs/issues/14690), [ethereum-optimism/op-analytics#14690](https://github.com/ethereum-optimism/op-analytics/issues/14690), [ethereum-optimism/ethereum-optimism.github.io#14690](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/14690), [ethereum-optimism/superchain-ops#14690](https://github.com/ethereum-optimism/superchain-ops/issues/14690))

### Superchain Operations and Deployment Enhancements
- New features were added to enable the SaferSafes module on Betanet/Sepolia, impacting multiple configuration files. ([ethereum-optimism/superchain-ops#1343](https://github.com/ethereum-optimism/superchain-ops/pull/1343))
- Tasks were introduced to enable the new LivenessModule (SaferSafes) on FUS and FOS, with SC as a backup and required parameters. ([ethereum-optimism/superchain-ops#1340](https://github.com/ethereum-optimism/superchain-ops/pull/1340))
- Additional test cases and natspec comments were added for `DeployImplementations.s.sol` and `makeDCI` to ensure correct `DeployOPChainInput` generation and overall robustness of the deployment process. ([ethereum-optimism/optimism#18725](https://github.com/ethereum-optimism/optimism/pull/18725))

### Configuration Updates and CI/CD Reliability
- Critical updates were made to the fees depositor address and minimum withdrawal amounts, and the CI configuration was updated to retry snapshot clean tasks, improving build reliability. ([ethereum-optimism/optimism#18736](https://github.com/ethereum-optimism/optimism/pull/18736), [ethereum-optimism/optimism#18659](https://github.com/ethereum-optimism/optimism/pull/18659), [ethereum-optimism/optimism#18778](https://github.com/ethereum-optimism/optimism/pull/18778))
- An update was made to the System Config Transform in Clickhouse, affecting `dim_superchain_system_configs_v1.sql` files, `Makefile`, and `helm/dagster/values.yaml`. ([ethereum-optimism/op-analytics#1782](https://github.com/ethereum-optimism/op-analytics/pull/1782))

### Code Quality and Security Checks
- A new semgrep rule was introduced to enforce a consistent naming convention for immutable variables within `OPContractsManagerV2`. ([ethereum-optimism/optimism#18679](https://github.com/ethereum-optimism/optimism/pull/18679))
