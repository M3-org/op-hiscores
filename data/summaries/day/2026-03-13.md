On Mar 13, 2026, Optimism saw significant progress in core infrastructure stability with the resolution of derivation pipeline error handling and span batch extraction issues across multiple repositories. A major `go-ethereum v1.17.1` merge updated `op-geth`'s syncing and block building, while critical CI/CD pipeline fixes and documentation enhancements improved developer experience. The ongoing `op-reth` memory leak issue remains a key concern, with new reports from World Chain users highlighting its impact.

## 🚨 Needs Attention

    - `op-reth` Database Memory Leak ([ethereum-optimism/infra#19212](https://github.com/ethereum-optimism/infra/issues/19212), [ethereum-optimism/op-geth#19212](https://github.com/ethereum-optimism/op-geth/issues/19212), [ethereum-optimism/docs#19212](https://github.com/ethereum-optimism/docs/issues/19212), [ethereum-optimism/superchain-ops#19212](https://github.com/ethereum-optimism/superchain-ops/issues/19212), [ethereum-optimism/superchain-registry#19212](https://github.com/ethereum-optimism/superchain-registry/issues/19212)): Discussion continues on this critical memory leak affecting `op-reth` and World Chain v1.10.1, requiring input on v1.11 upgrade efficacy.
    - `op-reth` Sync Stalls and State Mismatches ([ethereum-optimism/optimism#19529](https://github.com/ethereum-optimism/optimism/issues/19529), [ethereum-optimism/optimism#19532](https://github.com/ethereum-optimism/optimism/issues/19532)): These new issues highlight critical synchronization and state root mismatch problems in `op-reth` on Base mainnet, leading to crashes and stalls.
    - CI/CD `Make` to `Just` Migration Failure ([ethereum-optimism/optimism#19524](https://github.com/ethereum-optimism/optimism/issues/19524)): The `docker-build-prep` GitHub Actions composite action is failing due to `just` not being installed, blocking CI execution.

## ✅ Completed Work
### Core Infrastructure Stability & Upgrades
- **Derivation Pipeline Robustness**: Audits of the derivation pipeline's external input error handling were completed, ensuring malformed L1 inputs are dropped without halting derivation across `infra`, `op-geth`, `docs`, `superchain-ops`, and `superchain-registry`.
- **Span Batch Extraction Fix**: An issue where span batch extraction failures returned a Critical error instead of flushing was addressed, preserving historical behavior for invalid batch data in `infra`, `op-geth`, `docs`, `superchain-ops`, and `superchain-registry`.
- **`op-geth` Core Client Update**: `go-ethereum v1.17.1` was merged into `op-geth`, bringing improvements to syncing and block building packages ([ethereum-optimism/op-geth#774](https://github.com/ethereum-optimism/op-geth/pull/774)).
- **Dispute Game Template Updates**: `addGameType` and `setDisputeGame` templates in `superchain-ops` were updated to align with U18 OPCM breaking changes regarding implied proxies ([ethereum-optimism/superchain-ops#1378](https://github.com/ethereum-optimism/superchain-ops/pull/1378)).
- **Interop Mode Enhancements**: Kona's interop mode now supports `L2PayloadWitness` hint for execution witness pre-fetching via `debug_executePayload` RPC, improving interop capabilities ([ethereum-optimism/optimism#19408](https://github.com/ethereum-optimism/optimism/pull/19408)).
- **`op-supernode` Sync Status Initialization**: An issue where `ChainContainer.SyncStatus()` returned an empty status when uninitialized was closed, ensuring callers receive an error ([ethereum-optimism/optimism#19538](https://github.com/ethereum-optimism/optimism/issues/19538)).

### CI/CD Pipeline and Build System Improvements
- **`Make` to `Just` Migration Fixes**: Multiple fixes were implemented in `optimism` to address issues during the migration from `make` to `just`, including restoring `compute-git-versions`, updating `.semgrepignore`, and ensuring `just` installation in Dockerfiles ([ethereum-optimism/optimism#19523](https://github.com/ethereum-optimism/optimism/pull/19523), [ethereum-optimism/optimism#19522](https://github.com/ethereum-optimism/optimism/pull/19522), [ethereum-optimism/optimism#19521](https://github.com/ethereum-optimism/optimism/pull/19521), [ethereum-optimism/optimism#19477](https://github.com/ethereum-optimism/optimism/pull/19477), [ethereum-optimism/optimism#19482](https://github.com/ethereum-optimism/optimism/pull/19482)).

### Developer Experience and Documentation
- **Rust Docs Hosting Strategy**: The issue concerning Rust documentation hosting was closed across `infra`, `op-geth`, `docs`, `superchain-ops`, and `superchain-registry`, as it's now part of a broader documentation migration project.
- **AI Agent Documentation**: Documentation for AI agents was significantly enhanced with new guidance for Go and Rust development workflows in `optimism`, improving the developer experience for AI-assisted contributions ([ethereum-optimism/optimism#19518](https://github.com/ethereum-optimism/optimism/pull/19518)).

### Core Component Refactoring and Updates
- **`superchain-registry` Submodule Bump**: The `superchain-registry` submodule was updated to its latest version in `optimism`, incorporating recent contract updates and prestates ([ethereum-optimism/optimism#19528](https://github.com/ethereum-optimism/optimism/pull/19528)).
- **`op-devstack` Updates**: `op-devstack` was updated in `optimism` to allow explicit local contract artifact overrides, providing more flexibility ([ethereum-optimism/optimism#19516](https://github.com/ethereum-optimism/optimism/pull/19516)).
- **OP EVM Code Refactoring**: OP EVM code was refactored into `alloy-op-evm` newtypes in `optimism` ([ethereum-optimism/optimism#19252](https://github.com/ethereum-optimism/optimism/pull/19252)).
