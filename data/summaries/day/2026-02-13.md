On Feb 13, 2026, Optimism saw significant progress in enhancing L2 deployment capabilities and fault proof testing within the `optimism` repository, alongside crucial bug fixes for `proxyd` error handling across `infra`, `op-geth`, and `docs`. A new pull request was also opened to update the bridge tutorial content.

## ✅ Completed Work

### Infrastructure Stability & API Compliance
- A bug in `proxyd` that caused incorrect HTTP and JSON errors for unfound blocks when using `eth_getBlockByHash` or `eth_getBlockByNumber` was resolved, ensuring compliance with Ethereum API specifications. ([#552](https://github.com/ethereum-optimism/infra/pull/552), [#546](https://github.com/ethereum-optimism/infra/issues/546), [#546](https://github.com/ethereum-optimism/op-geth/issues/546), [#546](https://github.com/ethereum-optimism/docs/issues/546), [#546](https://github.com/ethereum-optimism/optimism/issues/546))

### L2 Deployment & Fault Proof Enhancements
- A Conditional L2 Deployer was introduced to enable non-reverting deterministic deployments, even with address collisions during network upgrade transactions, improving L2 deployment robustness. ([#18864](https://github.com/ethereum-optimism/optimism/pull/18864))
- The `TestInteropFaultProofs` action test was ported to a supernode devstack, enhancing the acceptance testing framework, and the Kona prestate build script was restored for easier local development. ([#19163](https://github.com/ethereum-optimism/optimism/pull/19163))
- A coordinated interop pause was added to the DSL for acceptance testing, allowing for more precise testing scenarios. ([#19179](https://github.com/ethereum-optimism/optimism/pull/19179))
- The build process for Cannon was optimized to use local monorepo sources instead of cloning a pinned tag, streamlining prestate generation for Kona. ([#19183](https://github.com/ethereum-optimism/optimism/pull/19183), [#18965](https://github.com/ethereum-optimism/optimism/issues/18965))

### Documentation & Developer Experience
- Documentation for Kona, op-reth, and op-alloy was unified into a single site, improving developer experience and accessibility. ([#19101](https://github.com/ethereum-optimism/optimism/pull/19101))
