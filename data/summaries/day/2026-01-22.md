On Jan 22, 2026, Optimism focused on enhancing CI/CD infrastructure by migrating Docker builds to GitHub Actions, improving node operator documentation for historical proofs, and making significant progress on withdrawal proving mechanisms for cross-chain interoperability. Key technical developments also included stricter integer handling across core components and advancements in `op-deployer` with forge script integration.

## ✅ Completed Work
### CI/CD & Infrastructure Improvements
- Migrated Docker builds from CircleCI to GitHub Actions, updating the build process to push to the `images` registry and removing legacy configurations, streamlining the CI/CD pipeline. ([#972](https://github.com/ethereum-optimism/ecosystem/pull/972))

### Documentation & Developer Experience
- Added comprehensive documentation for running `op-reth` with historical proofs Execution Extension (ExEx), including new configuration and tutorial files for node operators. ([#1949](https://github.com/ethereum-optimism/docs/pull/1949))
- Closed the issue requesting `op-reth` subsection for historical proofs ExEx, addressed by the new documentation. ([#1894](https://github.com/ethereum-optimism/docs/issues/1894))

### Core Protocol Enhancements
- Integrated a new feature flag into `op-deployer` to enable the use of forge scripts, starting with Deplo, to broaden forge execution within the deployment process. ([#18881](https://github.com/ethereum-optimism/optimism/pull/18881))
- Increased the timeout for contracts tests to prevent flakes caused by long execution times. ([#18914](https://github.com/ethereum-optimism/optimism/pull/18914))
- Replaced `big.Int.Uint64()` with `bigs.Uint64Strict` across `op-challenger`, `op-dispute-mon`, and `op-program` for stricter handling of `uint64` values. ([#18902](https://github.com/ethereum-optimism/optimism/pull/18902))
- Closed issues related to Forge Deployer integration, including converting `DeploySuperchain` to use Forge ([#17215](https://github.com/ethereum-optimism/optimism/issues/17215)) and creating a default flag for Forge in `op-deployer` ([#18761](https://github.com/ethereum-optimism/optimism/issues/18761)).
