On Mar 10, 2026, Optimism saw significant progress in refining its documentation, particularly by updating OP Stack terminology and consolidating Superchain content, alongside critical CI/CD pipeline enhancements and bug fixes in the `optimism` monorepo. Key developments included making Kona the default game type and addressing EIP-4844 transaction handling, while ongoing discussions continue regarding Kona hardfork cleanups and the removal of legacy interface calls.

## 🚨 Needs Attention
*   **Urgent Discussions**:
    *   [ethereum-optimism/docs#19450](https://github.com/ethereum-optimism/docs/issues/19450) and [ethereum-optimism/optimism#19450](https://github.com/ethereum-optimism/optimism/issues/19450): Discussion continues on Kona hardfork cleanups, specifically regarding a "footgun" related to implicit behavior when scheduling forks, with a suggestion to remove this behavior and consider rollup configurations invalid if a new fork is scheduled before a prior one is complete.

### CI/CD Pipeline & Rust Integration Enhancements
*   [ethereum-optimism/optimism#19453](https://github.com/ethereum-optimism/optimism/pull/19453): Added required gate jobs for Rust CI to improve pipeline robustness.
*   [ethereum-optimism/optimism#19222](https://github.com/ethereum-optimism/optimism/pull/19222): Implemented acceptance tests against the Rust stack (Kona/op-reth) to ensure functionality.

### Critical Bug Fixes
*   [ethereum-optimism/optimism#19355](https://github.com/ethereum-optimism/optimism/pull/19355): Fixed a bug in Kona's derive module to correctly accept EIP-4844 type-3 batcher transactions in `CalldataSource`.
*   [ethereum-optimism/optimism#19458](https://github.com/ethereum-optimism/optimism/pull/19458): Corrected `op-devstack` to properly select the sequencer EL node in flashblocks presets.
*   [ethereum-optimism/optimism#19442](https://github.com/ethereum-optimism/optimism/pull/19442): Implemented a fix to capture `vm-compat` findings JSON as a CI artifact, preventing data truncation.
*   [ethereum-optimism/optimism#19352](https://github.com/ethereum-optimism/optimism/issues/19352): Resolved a critical issue where `CalldataSource` silently dropped EIP-4844 (type 3) batcher transactions pre-Ecotone.

### Kona Default Game Type & Codebase Clean-up
*   [ethereum-optimism/optimism#19117](https://github.com/ethereum-optimism/optimism/pull/19117): Added initial scaffolding to make Kona the default respected game type.
*   [ethereum-optimism/optimism#19341](https://github.com/ethereum-optimism/optimism/pull/19341): Removed dead code related to `EthereumDataSourceVariant` from Kona's derive module.
*   [ethereum-optimism/optimism#19470](https://github.com/ethereum-optimism/optimism/pull/19470): Removed remnants of `kona-supervisor` from the codebase.
*   [ethereum-optimism/optimism#19340](https://github.com/ethereum-optimism/optimism/issues/19340): Closed an issue regarding the cleanup of the orphaned `sources/variant.rs` file in `kona-derive`.
