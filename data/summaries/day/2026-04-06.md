On Apr 6, 2026, the Optimism project saw significant progress in stabilizing the `op-supernode` and interop functionality, particularly with L1 reorg handling improvements and bug fixes for the Kona interop host. A major architectural change was the deprecation of the `docs` repository, centralizing documentation within the main `optimism` repository, while several new flaky tests emerged across different components, requiring immediate attention.

## ✅ Completed Work
### Supernode Stability & L1 Reorg Handling
- **`ethereum-optimism/infra`**:
    - Closed issues related to pruning data in `op-supernode` during L1 reorgs, including clearing verifications and denied blocks ([#19245](https://github.com/ethereum-optimism/infra/issues/19245)), pruning the interop database ([#19287](https://github.com/ethereum-optimism/infra/issues/19287)), and pruning the denylist ([#19289](https://github.com/ethereum-optimism/infra/issues/19289)), all resolved by WAL implementation.
- **`ethereum-optimism/docs`**:
    - Resolved issues concerning supernode L1 reorg handling, specifically clearing verifications and denied blocks ([#19245](https://github.com/ethereum-optimism/docs/issues/19245)), pruning the interop database ([#19287](https://github.com/ethereum-optimism/docs/issues/19287)), and pruning the denylist ([#19289](https://github.com/ethereum-optimism/docs/issues/19289)), enhancing consistency during reorgs.
- **`ethereum-optimism/optimism`**:
    - Closed issues related to `op-supernode` and interop implementation, including `Interop Implementation` ([#18741](https://github.com/ethereum-optimism/optimism/issues/18741)), `Interop Algo` ([#18743](https://github.com/ethereum-optimism/optimism/issues/18743)), and `Invalidate Block` ([#18944](https://github.com/ethereum-optimism/optimism/issues/18944)).
    - Resolved L1 reorg issues within `op-supernode` by WAL implementation, including `Clear Verifications and Denied Blocks on L1 Reorg` ([#19245](https://github.com/ethereum-optimism/optimism/issues/19245)), `Prune Interop Database on L1 Reorg` ([#19287](https://github.com/ethereum-optimism/optimism/issues/19287)), and `Prune Denylist on L1 Reorg and Alert` ([#19289](https://github.com/ethereum-optimism/optimism/issues/19289)).

### Kona Interop Host & Acceptance Test Improvements
- **`ethereum-optimism/optimism`**:
    - Enhanced Kona interop host stability by replacing `HashMap` with `BTreeMap` for deterministic JSON serialization ([#19906](https://github.com/ethereum-optimism/optimism/pull/19906)).
    - Ensured proper compilation of `kona-host` by adding it to `build-rust-release` target ([#19931](https://github.com/ethereum-optimism/optimism/pull/19931)).
    - Unskipped `TestInteropFaultProofs_InvalidBlock` acceptance test ([#19932](https://github.com/ethereum-optimism/optimism/pull/19932)).
    - Refactored flashblocks tests to use a reusable `FlashblockClient` ([#19942](https://github.com/ethereum-optimism/optimism/pull/19942)).
    - Closed a flaky test, `TestSuperCannonStepWithPreimage_nonExistingPreimage` ([#19892](https://github.com/ethereum-optimism/optimism/issues/19892)), after identifying resource contention as the cause.
    - Closed a test for invalid executing messages on the interop devnet ([#19566](https://github.com/ethereum-optimism/optimism/issues/19566)).

### Documentation & Architectural Streamlining
- **`ethereum-optimism/docs`**:
    - Deprecated the `docs` repository and moved all content to the `optimism` repository ([#2019](https://github.com/ethereum-optimism/docs/pull/2019)).
- **`ethereum-optimism/optimism`**:
    - Removed native `rollup-boost` support, routing Engine API v3/v4 calls directly to the L2 execution engine ([#19900](https://github.com/ethereum-optimism/optimism/pull/19900)).
    - Updated documentation references to reflect the new centralized docs location ([#19943](https://github.com/ethereum-optimism/optimism/pull/19943)).
