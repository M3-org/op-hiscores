On Aug 6, 2026, Optimism's development focused on significant documentation and CLI enhancements, particularly for `op-reth` and `kona-node`, alongside core code refactoring in `op-core`, `op-service`, and `op-chain-ops`. A critical recurring test flake related to metrics port collisions was identified and is under investigation, while a long-standing issue tracking pipeline improvements was closed due to the upcoming deprecation of `op-node`.

## ✅ Completed Work
### Documentation & CLI Enhancements
- Extensive documentation updates were made, including a fault proofs reference page, regenerated `op-reth` CLI references to v2.4.1, and corrections for `kona-node` supervisor and conductor flag facts. [ethereum-optimism/optimism#22311](https://github.com/ethereum-optimism/optimism/pull/22311), [ethereum-optimism/optimism#21838](https://github.com/ethereum-optimism/optimism/pull/21838), [ethereum-optimism/optimism#22193](https://github.com/ethereum-optimism/optimism/pull/22193), [ethereum-optimism/optimism#22310](https://github.com/ethereum-optimism/optimism/pull/22310), [ethereum-optimism/optimism#22309](https://github.com/ethereum-optimism/optimism/pull/22309), [ethereum-optimism/optimism#22302](https://github.com/ethereum-optimism/optimism/pull/22302), [ethereum-optimism/optimism#22109](https://github.com/ethereum-optimism/optimism/pull/22109)
- The unsupported `--minimal` option was removed from `op-reth`, representing a breaking change. [ethereum-optimism/optimism#22293](https://github.com/ethereum-optimism/optimism/pull/22293)

### Core Code Refactoring & Dispute Monitoring
- Significant code refactoring was performed in `op-core`, `op-service`, and `op-chain-ops` to clean up receipt wrapping constructors and codecs. [ethereum-optimism/optimism#22295](https://github.com/ethereum-optimism/optimism/pull/22295)
- `op-dispute-mon` was updated to normalize fault bond snapshots, improving its monitoring capabilities. [ethereum-optimism/optimism#22226](https://github.com/ethereum-optimism/optimism/pull/22226)

### Infrastructure & CI/CD Improvements
- CI/CD pipelines were enhanced to page `protocol-oncall` for `go-tests-full` develop failures and to build the superchain bundle in `go-release`. [ethereum-optimism/optimism#22212](https://github.com/ethereum-optimism/optimism/pull/22212), [ethereum-optimism/optimism#22233](https://github.com/ethereum-optimism/optimism/pull/22233)
- All `apko` images now include `busybox` and `apk-tools` for better shell and package management. [ethereum-optimism/optimism#22290](https://github.com/ethereum-optimism/optimism/pull/22290)
- The upstream `reth` pin was updated. [ethereum-optimism/optimism#22287](https://github.com/ethereum-optimism/optimism/pull/22287), [ethereum-optimism/optimism#22285](https://github.com/ethereum-optimism/optimism/pull/22285)

### Kona-SP1 Proposer Enhancements
- The `kona-sp1-proposer` now supports a fast finality mode, allowing it to prove games without waiting for a challenge. [ethereum-optimism/optimism#22173](https://github.com/ethereum-optimism/optimism/pull/22173)
- The super root RPC configuration was renamed for clarity. [ethereum-optimism/optimism#22308](https://github.com/ethereum-optimism/optimism/pull/22308)
