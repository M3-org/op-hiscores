On Jan 21, 2026, Optimism's development focused heavily on refining the OPCMv2 and SystemConfig, with multiple issues related to `proxyAdmin` and `isCustomGasToken` being closed across several repositories. Significant progress was also made in enhancing core protocol specifications, improving CI/CD stability, and optimizing simulation performance, alongside a new pull request to fix a gas calculation issue in `op-geth`.

## 🚨 Needs Attention
- **Urgent Discussions**:
    - `ethereum-optimism/specs` issue [#18502](https://github.com/ethereum-optimism/specs/issues/18502) discusses the temporary allowance for `SystemConfig::isCustomGasToken` override in OPCMv2, with a comment indicating it's fixed by an external PR, but the details of that fix are not in this report.
    - `ethereum-optimism/optimism` issue [#18886](https://github.com/ethereum-optimism/optimism/issues/18886) was opened to re-enable a flaky batcher test that is currently disabled due to a "nonce too high error."

## ✅ Completed Work
### OPCMv2 and SystemConfig Refinements
*   **Streamlined OPCMv2 by removing unnecessary instructions**: The CGT instruction was removed from OPCMv2 as it's no longer needed with U18, streamlining the contract manager ([#18878](https://github.com/ethereum-optimism/optimism/pull/18878)).
*   **Resolved `proxyAdmin` input redundancy**: Multiple issues across `op-geth`, `docs`, `infra`, `specs`, `superchain-registry`, `superchain-ops`, `design-docs`, and `optimism` related to removing the `proxyAdmin` input from the `OpChainConfig` struct were closed, as it can now be derived from `systemConfigProxy.proxyAdmin()` ([#16728](https://github.com/ethereum-optimism/op-geth/issues/16728), [#16728](https://github.com/ethereum-optimism/docs/issues/16728), [#16728](https://github.com/ethereum-optimism/infra/issues/16728), [#16728](https://github.com/ethereum-optimism/specs/issues/16728), [#16728](https://github.com/ethereum-optimism/superchain-registry/issues/16728), [#16728](https://github.com/ethereum-optimism/superchain-ops/issues/16728), [#16728](https://github.com/ethereum-optimism/design-docs/issues/16728), [#16728](https://github.com/ethereum-optimism/optimism/issues/16728)).
*   **Addressed `isCustomGasToken` override allowance**: Issues concerning the removal of the `SystemConfig::isCustomGasToken` override allowance for OPCMv2 were closed across `op-geth`, `docs`, `infra`, `superchain-registry`, `superchain-ops`, `design-docs`, and `optimism`, indicating the temporary measure is no longer needed with U18 ([#18502](https://github.com/ethereum-optimism/op-geth/issues/18502), [#18502](https://github.com/ethereum-optimism/docs/issues/18502), [#18502](https://github.com/ethereum-optimism/infra/issues/18502), [#18502](https://github.com/ethereum-optimism/superchain-registry/issues/18502), [#18502](https://github.com/ethereum-optimism/superchain-ops/issues/18502), [#18502](https://github.com/ethereum-optimism/design-docs/issues/18502), [#18502](https://github.com/ethereum-optimism/optimism/issues/18502)).

### Core Protocol and Infrastructure Enhancements
*   **Enhanced `op-acceptor` log persistence**: A critical bug fix was implemented in `infra` to prevent data loss in `op-acceptor` logs during unexpected terminations, improving debugging capabilities ([#540](https://github.com/ethereum-optimism/infra/pull/540)).
*   **Improved op-node configurability**: The `optimism` repository now allows for configurable sequencer sealing duration ([#18777](https://github.com/ethereum-optimism/optimism/pull/18777)) and added a `SupervisorEnabled` configuration to the op-node ([#18808](https://github.com/ethereum-optimism/optimism/pull/18808)).
*   **Optimized simulation performance**: `superchain-ops` fixed slow simulation times by unsetting `ETHERSCAN_API_KEY` in `forge script` recipes, reducing simulation duration significantly ([#1351](https://github.com/ethereum-optimism/superchain-ops/pull/1351)).
*   **Automated `addresses.json` update**: `superchain-registry` performed an automated codegen update to `addresses.json` as part of a daily CircleCI job ([#1196](https://github.com/ethereum-optimism/superchain-registry/pull/1196)).

### CI/CD and Testing Improvements
*   **Fixed CircleCI tag creation**: `optimism` implemented a critical fix to address broken tag creation in CircleCI releases, ensuring smoother continuous integration processes ([#18883](https://github.com/ethereum-optimism/optimism/pull/18883)).
*   **Updated `op-acceptor` version**: `optimism` updated `op-acceptor` to v3.8.2 ([#18890](https://github.com/ethereum-optimism/optimism/pull/18890)).
*   **Documented flake-shake gate usage**: `optimism` added documentation on using the flake-shake gate ([#18889](https://github.com/ethereum-optimism/optimism/pull/18889)).
*   **Temporarily skipped flaky batcher test**: `optimism` temporarily skipped a flaky batcher test to investigate a "nonce too high error" ([#18887](https://github.com/ethereum-optimism/optimism/pull/18887)).
