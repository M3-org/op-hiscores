On Jul 31, 2026, a major cleanup effort across several repositories saw the closure of numerous long-standing issues related to the deprecated `op-program` and the superseded "Standard L2 Genesis" initiative, streamlining development focus. Concurrently, significant progress was made on the Kona ZK dispute game with new tests and Docker image publishing, alongside extensive documentation restructuring and critical `op-deployer` bug fixes.

## ✅ Completed Work
### Core Protocol & Infrastructure Updates
- **Block Header and Hash Calculation**: The 'bal' field has been integrated into the block header and hash calculation process in `op-geth`, affecting core types, genesis, and beacon engine components ([ethereum-optimism/op-geth#804](https://github.com/ethereum-optimism/op-geth/pull/804)).
- **`op-deployer` Bug Fix**: A critical bug in `op-deployer` was fixed, ensuring that `State.SuperchainDeployment` is correctly set after the `prepare` step ([ethereum-optimism/optimism#22082](https://github.com/ethereum-optimism/optimism/pull/22082)).
- **`op-chain-ops` Streamlining**: Several pre-Holocene fork checkers and tools like `op-simulate` and `op-run-block` were removed from `op-chain-ops`, streamlining the codebase ([ethereum-optimism/optimism#22164](https://github.com/ethereum-optimism/optimism/pull/22164)).
- **`OPContractsManagerV2` Version Bump**: The major version of `OPContractsManagerV2` was bumped for the upcoming U20 ([ethereum-optimism/optimism#22158](https://github.com/ethereum-optimism/optimism/pull/22158)).

### Closed Issues
A large number of issues were closed across `design-docs`, `superchain-registry`, `infra`, and `op-geth` repositories, primarily marked as "not planned" or "superseded" due to the deprecation of `op-program` in favor of `kona-client` and the superseding of the "Standard L2 Genesis" effort.
- **Deprecation of `op-program`**: Issues related to `op-program`'s custom configs, prestate creation, Go SSA analysis, hash scheme dependency removal, TinyGo compilation, non-determinism sanitization, host request timeouts, recursive block execution prevention, consolidation bypass, `transitionState` sanity checks, test setup failures, reproducible prestate issues, reproducibility verification, and engine API checks were closed.
- **"Standard L2 Genesis" Initiative**: Issues concerning `FeeVault`, `OptimismPortal`, `CrossDomainMessenger`, `SuperchainConfig` upgrader role, failure mode analysis, Isthmus tracking, L1 contracts using OZ v5 Initializable, L2BlockGasLimit prevention, start block misconfiguration prevention, Semgrep rule for non-initializable predeploys, L2 Genesis file generation, `uprgrader` role renaming, `setFeeVaultConfig` calls to `SystemConfig.init`, audit findings review, and upgrade path testing were closed.
- **Contract and Deployment Tooling**: Issues related to `FaultDisputeGame.sol`'s immutable `L2_CHAIN_ID`, `op-deployer` separation, `AnchorStateRegistry` event emission, L2 Contracts Release, Contract Versioning Tool, `op-deployer` build/usage issues, `deploy-config.json` errors, `L2 ProxyAdmin`, `OptimismMintableERC721Factory` Modifications, `SystemConfig` Modifications, and `StandardBridge` Changes were closed.
- **Miscellaneous Closures**: Other closed issues include a withdrawal transaction stuck on OP Sepolia, adding a default `M-needs-triage` label, Optimism `mise` install errors, and adding a safe head DB to Kona.
