Jul 20, 2026 - Overall Project Daily Digest

Today's focus across Optimism was on critical infrastructure stability and `op-geth` decoupling efforts, with significant progress made in resolving long-standing flaky tests and standardizing Dockerfiles for enhanced security. Key design corrections were made for `op-batcher` migration strategies, and `op-challenger` received crucial bug fixes for dispute game functionality.

## ✅ Completed Work
### Infrastructure Security & Standardization
- All `infra` service Dockerfiles were standardized to use Chainguard `wolfi-base` for improved security and maintainability. [`ethereum-optimism/infra#671`](https://github.com/ethereum-optimism/infra/pull/671)
- Vulnerable dependencies across Go modules, Yarn workspaces, and Poetry projects were updated to remediate flagged CVEs. [`ethereum-optimism/infra#670`](https://github.com/ethereum-optimism/infra/pull/670)

### `op-geth` Decoupling & `op-core` Migration
- The issue of swapping `PostExecTx` span-batch sites and remaining one-off fork symbols to `op-core` was closed, advancing the `op-geth` decoupling initiative. [`ethereum-optimism/optimism#21901`](https://github.com/ethereum-optimism/optimism/issues/21901)
- Remaining one-off fork symbols in `op-node` were swapped to `op-core`, ensuring byte-identical behavior and wire format compatibility. [`ethereum-optimism/optimism#21904`](https://github.com/ethereum-optimism/optimism/pull/21904)

### `op-challenger` & Dispute Game Enhancements
- A crucial bug fix was implemented in `op-challenger` to advance anchors for finalized `SuperPermissionedDisputeGame` games, ensuring proper lifecycle management. [`ethereum-optimism/optimism#21811`](https://github.com/ethereum-optimism/optimism/pull/21811)
- Cannon was removed from default game types, with Cannon Kona remaining the sole default. [`ethereum-optimism/optimism#21912`](https://github.com/ethereum-optimism/optimism/pull/21912)
- End-to-end withdrawal coverage for `SuperPermissionedDisputeGame` was added. [`ethereum-optimism/optimism#21712`](https://github.com/ethereum-optimism/optimism/issues/21712)
- The `kona-sp1` Super program was completed. [`ethereum-optimism/optimism#21459`](https://github.com/ethereum-optimism/optimism/issues/21459)

### `kona` Transaction & Gossip Handling Improvements
- Fixes were implemented in `kona` to preserve span-batch transaction type prefixes during parsing, preventing reinterpretation as prefixless legacy transactions. [`ethereum-optimism/optimism#21808`](https://github.com/ethereum-optimism/optimism/pull/21808)
- Invalid gossip messages are now metered, and warnings downgraded to debug logs to prevent spamming. [`ethereum-optimism/optimism#21804`](https://github.com/ethereum-optimism/optimism/pull/21804)
- Invalid span-batch transaction types are now deferred to the typed decoder. [`ethereum-optimism/optimism#21850`](https://github.com/ethereum-optimism/optimism/pull/21850)

### Documentation & CI Process Updates
- Documentation was enhanced with a persona router homepage and a repaired `create-l2-rollup` tutorial, updating references from `op-geth` to `op-reth`. [`ethereum-optimism/optimism#21848`](https://github.com/ethereum-optimism/optimism/pull/21848), [`ethereum-optimism/optimism#21899`](https://github.com/ethereum-optimism/optimism/pull/21899)
- The CI process now mandates scoped commits and enforces this via CI checks, improving commit hygiene. [`ethereum-optimism/optimism#21855`](https://github.com/ethereum-optimism/optimism/pull/21855)
- Dependency versions were bumped to patched versions across JS docs and Rust workspaces to address security advisories. [`ethereum-optimism/optimism#21896`](https://github.com/ethereum-optimism/optimism/pull/21896)

### `op-devstack` Refinements
- The `op-devstack` now discovers OS-assigned service ports, using port 0 for Kona metrics and rollup-boost RPC in `sysgo` and then discovering actual bound addresses from structured startup logs, removing race-prone local port preallocation. [`ethereum-optimism/optimism#21872`](https://github.com/ethereum-optimism/optimism/pull/21872)
