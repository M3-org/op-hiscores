On May 1, 2026, the Optimism project focused heavily on diagnosing and addressing a critical fatal panic in `op-reth` during 1.x to 2.x upgrades, which appears to be a shared bug in parallel trie computation. Concurrently, significant progress was made in enabling core protocol features like Cannon Kona and L2CM by default, alongside crucial bug fixes for LightCL genesis sync and improvements to dispute monitoring. A key bug in `op-supernode`'s `VerifiedRequiredL1` calculation was also identified and is being actively addressed.

## 🚨 Needs Attention
- **Urgent Discussion: Fatal Panic in op-reth Upgrade** ([#20462](https://github.com/ethereum-optimism/infra/issues/20462)): The `--engine.legacy-state-root` flag does not fix the panic, which is now confirmed to affect both `StateRootTask` and `Parallel` strategies due to a shared bug in `alloy-trie-0.9.5`. Further investigation and input are needed to resolve this critical upgrade blocker.
- **Urgent Discussion: op-supernode L1 Verification Logic Error** ([#20481](https://github.com/ethereum-optimism/infra/issues/20481)): `op-supernode` is incorrectly using the MIN instead of MAX for `VerifiedRequiredL1` calculation, leading to incorrect data. This needs immediate attention to ensure correct L1 verification status.
- **Pull Request to Review: `op-reth` Proofs ExEx Store Wait** ([#20487](https://github.com/ethereum-optimism/optimism/pull/20487)): This PR aims to fix a validator `eth_getProof` issue by waiting for the proofs ExEx store, and requires review.
- **Pull Request to Review: `op-reth` RW Transaction Commit Fix** ([#20485](https://github.com/ethereum-optimism/optimism/pull/20485)): This PR addresses an `init-state` stall by committing the RW transaction before `init_from_state_dump` and needs review.
- **Pull Request to Review: `op-supernode` VerifiedRequiredL1 Fix** ([#20484](https://github.com/ethereum-optimism/optimism/pull/20484)): This PR directly addresses the `op-supernode` L1 verification logic error by ensuring `VerifiedRequiredL1` takes the MAX of per-chain L1s, and requires urgent review.
