## ✅ Completed Work
### Protocol Specification & Interoperability
- The OPCMv2 specification was introduced, expanding the protocol's capabilities. ([#875](https://github.com/ethereum-optimism/specs/pull/875))
- Interop Migration with OPCM v2 support was added to improve compatibility and functionality for contract management. ([#18738](https://github.com/ethereum-optimism/optimism/pull/18738))
- A bug fix ensured correct Permissioned Dispute Game implementation addresses for OPCM v2. ([#18900](https://github.com/ethereum-optimism/optimism/pull/18900))

### Deployment & Contract Enhancements
- The `op-deployer` tool was updated to include Forge flag support for bootstrap and apply operations, streamlining deployment processes. ([#18913](https://github.com/ethereum-optimism/optimism/pull/18913))
- Contract code was refactored to standardize OPCM v2 version checks using semantic version comparisons, replacing older feature flags. ([#18893](https://github.com/ethereum-optimism/optimism/pull/18893))
- Proposed block numbers in dispute games were restricted to `uint64` to align with JSON-RPC API limitations. ([#18903](https://github.com/ethereum-optimism/optimism/pull/18903))
- A bug fix was implemented in `SuperchainAddressRegistry.sol` to support `op-contracts v6.0.0 gameArgs` and simplify the code. ([#1353](https://github.com/ethereum-optimism/superchain-ops/pull/1353))

### Security & Testing Improvements
- The `just sign-stack` command was updated to include a check ensuring the signer is an owner of the safe, mirroring the existing check in `just sign` for improved security. ([#1354](https://github.com/ethereum-optimism/superchain-ops/pull/1354))
- New test coverage was added for `MIPS64Memory` functions `isValidProof` and `memoryProofOffset`. ([#18905](https://github.com/ethereum-optimism/optimism/pull/18905))
- Code across `op-e2e`, `op-acceptance-tests`, `op-devstack`, and `op-sync-tester` was updated to use `Uint64Strict` for improved type safety and compliance with new lint checks. ([#18904](https://github.com/ethereum-optimism/optimism/pull/18904))

### Documentation & Infrastructure Updates
- Significant effort was put into streamlining the documentation by removing unused images and code. ([#1955](https://github.com/ethereum-optimism/docs/pull/1955))
- A new guide on flashblocks and gas usage was created, and the description and link for Openfort were updated. ([#1947](https://github.com/ethereum-optimism/docs/pull/1947), [#1954](https://github.com/ethereum-optimism/docs/pull/1954))
- A new rehearsal configuration was added for the OPSC R1 welcome, scheduled for January 2026. ([#1350](https://github.com/ethereum-optimism/superchain-ops/pull/1350))
