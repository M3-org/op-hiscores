On July 2, 2026, Optimism saw significant development in `op-deployer` and `op-reth` with new features introduced via three new pull requests, alongside the resolution of a long-standing `op-node` compatibility issue with EIP-4444. However, new security audit feedback from Lumi Beacon was raised as issues, and a potential discrepancy in the `op-reth` transaction pool balance check was identified.

## ✅ Completed Work
### Protocol Security & Compatibility
- The `op-node` compatibility issue with EIP-4444 enabled L1 nodes, which previously caused errors when L1 pruned historic blocks, was closed: [#13570](https://github.com/ethereum-optimism/optimism/issues/13570)

## 🏗️ Work in Progress
### New Pull Requests
**ethereum-optimism/optimism**
- Introduces a feature to commit prestates before chain deployment in `op-deployer`: [#21611](https://github.com/ethereum-optimism/optimism/pull/21611)
- Adds a feature to source permissionless deploy inputs from chain state in `op-deployer`: [#21610](https://github.com/ethereum-optimism/optimism/pull/21610)
- Implements a feature in `op-reth/txpool` to reserve the Isthmus operator fee in the pool balance check: [#21609](https://github.com/ethereum-optimism/optimism/pull/21609)

## 🐞 Issue Triage
### New Issues
**ethereum-optimism/optimism**
- `op-reth` transaction pool balance check omits the Isthmus operator fee, potentially admitting under-funded transactions: [#21608](https://github.com/ethereum-optimism/optimism/issues/21608)
- Lumi Security Audit Feedback for `solutil.go` within `op-chain-op`: [#21612](https://github.com/ethereum-optimism/optimism/issues/21612)
- Lumi Security Audit Feedback for `mod.rs` within `rust/kona/crate`: [#21613](https://github.com/ethereum-optimism/optimism/issues/21613)

### Closed Issues
**ethereum-optimism/optimism**
