On June 5, 2026, Optimism made significant strides in enhancing Superchain stability and performance, particularly in addressing persistent synchronization and recovery issues related to `op-supernode` and `op-reth`. Key achievements include critical fixes for devstack configurations, improvements to `proxyd`'s consensus layer routing, and the implementation of permissionless dispute game rollouts for Karst U19, while ongoing efforts focus on resolving complex cyclic deadlocks in `reth`'s state trie machinery.

## ✅ Completed Work
### Superchain Stability and Synchronization Improvements
- **Devstack Configuration Fixes**: Resolved an issue where the devstack interop preset incorrectly shared the Execution Layer (EL) between the light node sequencer and the supernode, improving isolation and stability. ([ethereum-optimism/superchain-registry#21158](https://github.com/ethereum-optimism/superchain-registry/issues/21158), [ethereum-optimism/specs#21158](https://github.com/ethereum-optimism/specs/issues/21158), [ethereum-optimism/infra#21158](https://github.com/ethereum-optimism/infra/issues/21158), [ethereum-optimism/superchain-ops#21158](https://github.com/ethereum-optimism/superchain-ops/issues/21158), [ethereum-optimism/optimism#21158](https://github.com/ethereum-optimism/optimism/issues/21158))
- **Sequencer Reorg Recovery Strategy**: Closed the issue concerning `op-conductor`'s graceful recovery from interop reorgs, opting for manual intervention via runbooks instead of auto-recovery. ([ethereum-optimism/superchain-registry#20006](https://github.com/ethereum-optimism/superchain-registry/issues/20006), [ethereum-optimism/specs#20006](https://github.com/ethereum-optimism/specs/issues/20006), [ethereum-optimism/infra#20006](https://github.com/ethereum-optimism/infra/issues/20006), [ethereum-optimism/superchain-ops#20006](https://github.com/ethereum-optimism/superchain-ops/issues/20006), [ethereum-optimism/optimism#20006](https://github.com/ethereum-optimism/optimism/issues/20006))
- **Sequencer Bootstrap Fix**: Addressed a problem where a follow-mode ELSync sequencer could not bootstrap a chain from genesis, preventing deadlocks. ([ethereum-optimism/optimism#21164](https://github.com/ethereum-optimism/optimism/issues/21164))

### Infrastructure and Protocol Enhancements
- **`proxyd` Consensus Layer Routing**: `proxyd` now includes output-root split protection for its consensus layer routing, enhancing robustness by comparing output roots across candidate backends. ([ethereum-optimism/infra#646](https://github.com/ethereum-optimism/infra/pull/646))
- **`peer-mgmt-service` External Peer Support**: The `peer-mgmt-service` has been updated to support external peers, allowing nodes to omit `rpc_address` and be reachable only from internal nodes. ([ethereum-optimism/infra#647](https://github.com/ethereum-optimism/infra/pull/647))
- **`op-node` Superroot Serving**: Added a new `superroot` JSON-RPC namespace to `op-node` to serve `superroot_atTimestamp` for non-interop chains, crucial for dispute games before interop activation. ([ethereum-optimism/optimism#20581](https://github.com/ethereum-optimism/optimism/pull/20581), [ethereum-optimism/optimism#20552](https://github.com/ethereum-optimism/optimism/issues/20552))
- **`op-reth` Trie Performance**: `op-reth/proofs` now snapshots hashed-leaf tables to accelerate backfill, addressing bottlenecks in `compute_block_backfill_diff`. ([ethereum-optimism/optimism#21088](https://github.com/ethereum-optimism/optimism/pull/21088))

### Dispute Game and CI/CD Improvements
- **Karst U19 Permissionless Rollout**: Implemented the permissionless rollout for `karst-u19-alpha` and a permissioned correction for `karst-u19-beta-0`, extending the `SetDisputeGameImpl` template. ([ethereum-optimism/superchain-ops#1447](https://github.com/ethereum-optimism/superchain-ops/pull/1447))
- **CI Configuration Fixes**: Corrected a `BASE_REVISION` typo in CI configuration and lazily generated genesis allocations in `op-e2e` to reduce test startup times. ([ethereum-optimism/optimism#21244](https://github.com/ethereum-optimism/optimism/pull/21244), [ethereum-optimism/optimism#21238](https://github.com/ethereum-optimism/optimism/pull/21238))
- **CI Build Speed Improvements**: De-duplicated command definitions and introduced a shared `sccache` compile cache for Rust in CI jobs, significantly speeding up builds. ([ethereum-optimism/optimism#21245](https://github.com/ethereum-optimism/optimism/pull/21245), [ethereum-optimism/optimism#21227](https://github.com/ethereum-optimism/optimism/pull/21227))

### Documentation and Contract Updates
- **Release Documentation**: Updated documentation for `op-batcher v1.16.10` and `op-reth v2.3.1` for Upgrade 19, including fixes for a deadlock bug. ([ethereum-optimism/optimism#21264](https://github.com/ethereum-optimism/optimism/pull/21264), [ethereum-optimism/optimism#21263](https://github.com/ethereum-optimism/optimism/pull/21263))
- **`SuperchainConfig` Audit and Version Bump**: The `SuperchainConfig` contract was marked as audited and its version bumped to `v2.4.3`. ([ethereum-optimism/optimism#21265](https://github.com/ethereum-optimism/optimism/pull/21265))
