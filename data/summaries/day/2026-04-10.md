## ✅ Completed Work
### Protocol & Rust Ecosystem Enhancements
- **`reth` Upgrade and `kona-genesis` Improvements**: `reth` was updated to `v2.0.0`, aligning with `alloy` and `revm` dependencies, and `kona-genesis` was enhanced with a `rollup_config_override` feature for custom `fjord_max_sequencer_drift`. ([#19989](https://github.com/ethereum-optimism/optimism/pull/19989), [#19994](https://github.com/ethereum-optimism/optimism/pull/19994))
- **Batch Type Handling Fix**: A critical fix in `kona` now returns an error instead of panicking on unknown batch types, improving robustness and matching the OP spec. ([#20000](https://github.com/ethereum-optimism/optimism/pull/20000))
- **L2 Upgrade Transaction Clarification**: A note about 'one-time only' transactions was removed from the L2 upgrades execution document, clarifying upgrade transaction requirements. ([#902](https://github.com/ethereum-optimism/specs/pull/902))
- **L2ContractsManager Security Enhancement**: An issue related to potential storage variable collisions in `L2ContractsManager` when executed via `DELEGATECALL` was resolved. ([#19315](https://github.com/ethereum-optimism/specs/issues/19315), [#19315](https://github.com/ethereum-optimism/superchain-ops/issues/19315), [#19315](https://github.com/ethereum-optimism/optimism/issues/19315))
- **Superchain Dispute Game Resolution**: The issue regarding all chains using SuperDisputeGame for Challenger, Proposer, and Dispute-Mon was closed. ([#19695](https://github.com/ethereum-optimism/optimism/issues/19695))

### Testing and Documentation Improvements
- **Flashblocks Transfer Reliability**: Acceptance tests for flashblocks transfer were made more reliable by switching to `op-rbuilder` and resolving a cleanup deadlock. ([#19985](https://github.com/ethereum-optimism/optimism/pull/19985))
- **New Fault Proof Program Test**: A new proof test was added to `op-e2e` to verify correct handling of batcher address changes within the `channel_timeout` window. ([#20021](https://github.com/ethereum-optimism/optimism/pull/20021))
- **Req/Res CL Sync Deprecation Notice**: Documentation was updated with a notice regarding the deprecation of Req/Res CL sync. ([#19998](https://github.com/ethereum-optimism/optimism/pull/19998))
- **`op-revm` Documentation and CI**: The `op-revm` crate received a new `README.md` and `no_std` CI coverage, improving its documentation and testability. ([#19962](https://github.com/ethereum-optimism/optimism/pull/19962))

### Infrastructure Cleanup and Maintenance
- **OPCMv1 References Cleanup**: References to OPCMv1 were mechanically cleaned up across the codebase, including CI configurations, documentation, and various Go packages. ([#19919](https://github.com/ethereum-optimism/optimism/pull/19919))
- **Dependency Cleanup Opportunities Identified**: An issue detailing opportunities to remove unused npm dependencies, dead Docker images, and slim Python requirements was closed, with the work being split into separate issues. ([#20016](https://github.com/ethereum-optimism/specs/issues/20016), [#20016](https://github.com/ethereum-optimism/superchain-ops/issues/20016), [#20016](https://github.com/ethereum-optimism/optimism/issues/20016))
