## ✅ Completed Work
### Core Protocol & Rust Tooling Enhancements
- **`reth` Dependency Upgrade**: The `reth` dependency in the Rust workspace was updated to `v2.0.0`, aligning with `alloy 1.8.2` and `revm 36.0.0`. ([ethereum-optimism/optimism#19989](https://github.com/ethereum-optimism/optimism/pull/19989))
- **`kona-genesis` Customization**: A `rollup_config_override` feature was added to `kona-genesis`, enabling custom `fjord_max_sequencer_drift`. ([ethereum-optimism/optimism#19994](https://github.com/ethereum-optimism/optimism/pull/19994))
- **`op-revm` Improvements**: `README` and `no_std` CI coverage were added to `op-revm`. ([ethereum-optimism/optimism#19962](https://github.com/ethereum-optimism/optimism/pull/19962))

### Bug Fixes and Test Improvements
- **Flashblocks Transfer Fix**: `TestFlashblocksTransfer` flakiness and a cleanup deadlock were resolved by switching to the `op-rbuilder` flashblock stream. ([ethereum-optimism/optimism#19985](https://github.com/ethereum-optimism/optimism/pull/19985))
- **Batch Type Handling**: The `kona` protocol was improved to return an error instead of panicking on unknown batch types, aligning with the OP spec. ([ethereum-optimism/optimism#20000](https://github.com/ethereum-optimism/optimism/pull/20000))
- **Batcher Address Change Proof Test**: A new `op-e2e` proof test was added to verify correct handling of batcher address changes within the `channel_timeout` window. ([ethereum-optimism/optimism#20021](https://github.com/ethereum-optimism/optimism/pull/20021))

### Documentation and Cleanup
- **L2 Upgrades Specification Clarification**: A note regarding 'one-time only' transactions was removed from the L2 upgrades execution document, clarifying upgrade transaction requirements. ([ethereum-optimism/specs#902](https://github.com/ethereum-optimism/specs/pull/902))
- **Req/Res CL Sync Deprecation**: A deprecation notice for Req/Res CL sync was added to the public documentation. ([ethereum-optimism/optimism#19998](https://github.com/ethereum-optimism/optimism/pull/19998))
- **Mechanical Cleanup**: `OpcmImpl` compatibility shims, `ReadSuperchainDeployment` v1 fields, and related CI and documentation references were removed. ([ethereum-optimism/optimism#19919](https://github.com/ethereum-optimism/optimism/pull/19919))
