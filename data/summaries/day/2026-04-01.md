Overall Project Summary for Apr 1, 2026:

Today's focus across Optimism included significant enhancements to the fault proof system, particularly with `CANNON_KONA` and `SUPER_CANNON_KONA` game types, alongside critical bug fixes in the derivation pipeline and acceptance tests. Additionally, the circulating supply of OP tokens was updated, and `proxyd` received substantial refactoring and consensus state improvements.

## ✅ Completed Work

### Fault Proof System & Dispute Game Enhancements
- All `op-e2e` fault proof tests were converted to use `CANNON_KONA` and `SUPER_CANNON_KONA` game types, utilizing `kona-host` instead of `op-program` in `ethereum-optimism/optimism` ([#19791](https://github.com/ethereum-optimism/optimism/pull/19791)).
- The `depset` configuration is now passed to the `kona` super executor to enable detection of expired messages in `ethereum-optimism/optimism` ([#19849](https://github.com/ethereum-optimism/optimism/pull/19849)).
- The issue regarding fixing host arguments in the Kona super executor for `op-challenger` was resolved, with the challenger runner now successfully running `kona-interop` in tests across `ethereum-optimism/ethereum-optimism.github.io` ([#18287](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18287)), `ethereum-optimism/docs` ([#18287](https://github.com/ethereum-optimism/docs/issues/18287)), `ethereum-optimism/superchain-registry` ([#18287](https://github.com/ethereum-optimism/superchain-registry/issues/18287)), `ethereum-optimism/infra` ([#18287](https://github.com/ethereum-optimism/infra/issues/18287)), and `ethereum-optimism/optimism` ([#18287](https://github.com/ethereum-optimism/optimism/issues/18287)).

### Core Protocol Stability & Correctness
- A pipeline initialization bug in `kona` using an incorrect system config during reset was fixed in `ethereum-optimism/optimism` ([#19792](https://github.com/ethereum-optimism/optimism/pull/19792)).
- A new Semgrep rule was implemented to prevent `L2ContractsManager` from declaring storage variables, avoiding collisions in `ethereum-optimism/optimism` ([#19649](https://github.com/ethereum-optimism/optimism/pull/19649)).
- The `L2Transactions` hint is now sent before the trie walk during block re-execution in `kona` in `ethereum-optimism/optimism` ([#19850](https://github.com/ethereum-optimism/optimism/pull/19850)).
- Flaky tests `TestSupernodeInteropChainLag` and `TestUnsafeChainNotStalling_DisabledReqRespSync` had their `MarkFlaky` tags removed after showing recent stability in `ethereum-optimism/optimism` ([#19846](https://github.com/ethereum-optimism/optimism/pull/19846)).
- A specific flake in `eth_simulateV1` acceptance tests was resolved in `ethereum-optimism/optimism` ([#19842](https://github.com/ethereum-optimism/optimism/pull/19842)).
- The proofs ExEx state provider was updated to error if state is unavailable, rather than falling back to a historical provider in `ethereum-optimism/optimism` ([#19855](https://github.com/ethereum-optimism/optimism/pull/19855)).

### Infrastructure & Tokenomics Updates
- The circulating supply of OP tokens was updated from 2,117,847,344 to 2,136,461,507 in `ethereum-optimism/ethereum-optimism.github.io` ([#1297](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1297)).
- `proxyd` now tracks `safeBlockHash` and `finalizedBlockHash` in its consensus state, improving block hash fetching accuracy in `ethereum-optimism/infra` ([#591](https://github.com/ethereum-optimism/infra/pull/591)).
- `proxyd` code was refactored to rename generic functions to EL-scoped names and extract a duplicated hash-verification walk-back loop into a reusable function, addressing type assertion panics in `ethereum-optimism/infra` ([#592](https://github.com/ethereum-optimism/infra/pull/592), [#590](https://github.com/ethereum-optimism/infra/pull/590)).
- Prestates for Kona client version 1.2.12 were added to `validation/standard/standard-prestates.toml` in `ethereum-optimism/superchain-registry` ([#1206](https://github.com/ethereum-optimism/superchain-registry/pull/1206)).

### Documentation & Build Process Refinements
- Documentation for historical proofs was enriched with context, architecture, metrics, and benchmarks in `ethereum-optimism/optimism` ([#19790](https://github.com/ethereum-optimism/optimism/pull/19790)).
- The `nut-bundle-check` build process was simplified by replacing a Go script with a `git diff` approach in `ethereum-optimism/optimism` ([#19852](https://github.com/ethereum-optimism/optimism/pull/19852)).
- Metrics reports for closed issues and opened pull requests for March 2026 were generated and closed in `ethereum-optimism/docs` ([#2015](https://github.com/ethereum-optimism/docs/issues/2015), [#2016](https://github.com/ethereum-optimism/docs/issues/2016)).
