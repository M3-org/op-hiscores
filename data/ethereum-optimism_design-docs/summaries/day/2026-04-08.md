**Flaky Test: `TestUnsafeGapFillAfterUnsafeReorg_RestartL2CL`** [#19936](https://github.com/ethereum-optimism/design-docs/issues/19936)

**Flaky Test: `TestInvalidPayloadThroughCLP2P`** [#19968](https://github.com/ethereum-optimism/design-docs/issues/19968)

**Op-node: Reactive Runtime Config Reload on Unsafe Block Signer Mismatch** [#19981](https://github.com/ethereum-optimism/design-docs/issues/19981)
This new issue discusses a problem where op-node verifier nodes reject valid blocks when the unsafe block signer address rotates due to a stale signer window. sebastianst suggested a grace period where both old and new keys are accepted to ensure a smoother transition. axelKingsley questioned the current 10-minute reload interval, suggesting it might be too long and that the L1 RPC might not be as overwhelmed as feared by more frequent updates. A draft PR [#19982](https://github.com/ethereum-optimism/design-docs/pull/19982) has been created to address this.

**Chore(proof/ci): Reactivate Interop Action Tests** [#18974](https://github.com/ethereum-optimism/design-docs/issues/18974)
Inphi commented on April 8th, 2026, that the `op-e2e` interop action tests are being migrated to `op-acceptance-tests`. This work will be handled in a separate ticket, and a follow-up will clean up the old `op-e2e` interop action test setup for proofs.
