# ethereum-optimism/design-docs Daily Update (Jun 19, 2026)
## OVERVIEW 
Today's development focused on expanding the Superchain's dispute game capabilities with new ZK features and enhancing the deployment process for OP Stack chains to reduce permissioned windows.

## KEY TECHNICAL DEVELOPMENTS

### Super ZK Dispute Game Enhancements
Significant progress was made on the Super ZK Dispute Game, including the addition of a failure mode analysis to cover the `SuperZKDisputeGame` for interop superchains ([#381](https://github.com/ethereum-optimism/design-docs/pull/381)). The design document for the Super ZK Dispute Game was also updated to incorporate super roots and moved to a new proofs folder ([#384](https://github.com/ethereum-optimism/design-docs/pull/384)).

### Predictive Chain Deployments (PCD)
A new design document for Predictive Chain Deployments (PCD) was added, aiming to eliminate the approximately 7-day permissioned window currently required for new OP Stack chains before their permissionless dispute game activates. This includes a failure mode analysis for the new deployment pipeline ([#385](https://github.com/ethereum-optimism/design-docs/pull/385)).

## ACTIVE ISSUES

### Kona-node/op-reth Metrics Version Discrepancy
Discussion continued on the issue where the version reported by `kona-node` and `op-reth` in Prometheus metrics does not align with the git/docker tag. A new comment highlighted that the `web3_clientVersion` and `--version` commands also return the internal reth crate version, not the expected git tag, indicating a persistent discrepancy that needs fixing ([#20832](https://github.com/ethereum-optimism/design-docs/issues/20832)).

### Flaky reth-optimism-node Integration Test
The `reth-optimism-node` integration test `peers_negotiate_eth_69` continues to experience SIGSEGV on teardown. The latest comment confirmed that this flake recurred, preventing a PR from merging. It was noted that the issue is non-deterministic and likely related to a race condition during runtime teardown, as previously analyzed, and not introduced by recent changes ([#20973](https://github.com/ethereum-optimism/design-docs/issues/20973)).

### Optimism Sepolia Intrinsic Gas After Karst Hard Fork
A bug report regarding high intrinsic gas on Optimism Sepolia after the Karst hard fork received a new comment confirming it as a known issue. It is expected to be resolved in the next release, with a link to the official notice provided for app developers ([#21457](https://github.com/ethereum-optimism/design-docs/issues/21457)).
