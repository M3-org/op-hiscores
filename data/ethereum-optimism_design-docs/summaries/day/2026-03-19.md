### Initial EL Sync UX and Correctness
Discussion on [#17631](https://github.com/ethereum-optimism/design-docs/issues/17631) continued, focusing on the correctness and user experience (UX) of the initial EL sync. The current implementation is deemed incorrect as it sets safe and finalized heads based on the unsafe head rather than the L1 finalization gadget. Three options for improvement were discussed:
1.  **Set safe/finalized to genesis:** Simplest but requires long derivation time.
2.  **Set safe/finalized to (unsafe head minus sequencer window):** Balances correctness with improved UX by reducing derivation time to ~12 hours. This option is currently favored.
3.  **Allow safe/finalized to be provided externally:** Best UX but adds complexity and reliance on trusted external values.

### Review Kona-Interop Block Hash Oracle
On [#18288](https://github.com/ethereum-optimism/design-docs/issues/18288), the discussion revolved around ensuring an integration/acceptance test for the kona-interop block hash oracle. The goal is to verify that block lookups prior to the current history window function correctly, potentially by moving an existing action test to an acceptance test and utilizing L1 time travel to generate sufficient chain history.

### Non-terminating CI Job: memory-all-opn-op-geth
Issue [#19563](https://github.com/ethereum-optimism/design-docs/issues/19563) was reopened due to continued flakiness in the `memory-all-opn-op-geth` CI job. The latest occurrences show `TestChallengerPlaysGame` and `TestProposer` in `interop/proofs` hitting the 2-hour subtest timeout. Root causes for these specific test hangs have been identified, involving `FailNow` calls within `testify.Eventually` goroutines, leading to silent goroutine termination and indefinite blocking. Fixes involve package isolation and replacing fatal assertions with error-returning variants in `Eventually` conditions.
