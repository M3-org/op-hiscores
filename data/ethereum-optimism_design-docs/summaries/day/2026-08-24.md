### Revisit SDM Operator Documentation
Discussion on [#21545](https://github.com/ethereum-optimism/design-docs/issues/21545) indicates significant progress in resolving the documentation for the SDM operator. The latest comment from einar-oplabs confirms that both outstanding items, environment variables and release-related documentation, are now resolvable.

Regarding **Environment Variables**:
*   It has been confirmed that `op-reth` is the only component with an SDM operator option.
*   All options are now supported via environment variables, with a specific test (`test_operator_sdm_opt_in_is_bound_to_env_var`) verifying this.
*   All relevant environment variables are now documented, with [#22659](https://github.com/ethereum-optimism/design-docs/pull/22659) adding the CLI flag and environment variable to the SDM guide.

Regarding **Release-related Documentation**:
*   The anticipated Upgrade 20 page was found to be unrelated to SDM activation.
*   SDM activation is gated by the **Lagoon** hardfork, which already lists SDM under "What's included" on its registry page.
*   [#22659](https://github.com/ethereum-optimism/design-docs/pull/22659) now correctly links the SDM guide's Lagoon mention to the hardfork registry page.
*   A reverse link from the Lagoon page to the SDM guide is intentionally omitted for now, as the guide remains hidden.
