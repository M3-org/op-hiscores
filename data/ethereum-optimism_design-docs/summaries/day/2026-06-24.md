## ACTIVE ISSUES
- **Investigation into Flaky Blob Encoding Test**
  A detailed comment was added to [#21539](https://github.com/ethereum-optimism/design-docs/issues/21539) regarding the "Flaky test: FuzzDetectNonBijectivity mutates a non-encoded bit (op-service/eth)". The comment clarifies that the test's premise is incorrect because the blob code is not bijective on the top two bits of the first field element. Both `op-node` and `kona` implementations treat the first element differently, masking out the top two bits regardless of their setting, leading to the same decoded data even if these bits are flipped. This behavior means the test fails because no error is returned, and the data is decoded unchanged. The comment also discusses the implications of changing this behavior (potential for breaking existing on-chain blobs) and suggests that a fix might require a hardfork or an understanding that honest batchers would not post malformed blobs.
