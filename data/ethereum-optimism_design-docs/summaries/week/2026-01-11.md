# ethereum-optimism/design-docs Weekly Report (Jan 11 - 17, 2026)

## 🚀 Highlights
This week focused on enhancing the protocol documentation with a specific emphasis on the technical architecture of the `kona-node`. The primary achievement was the formalization of the Light CL (follow mode) design, which strengthens the transparency of Optimism's node implementations. Additionally, active maintenance continues regarding the standardization of error handling within the Superchain's Data Availability (DA) layer.

This document provides the technical blueprint for how the node interacts with the Consensus Layer in a light capacity, improving the resource efficiency and accessibility of the protocol ([#359](https://github.com/ethereum-optimism/design-docs/pull/359)).
