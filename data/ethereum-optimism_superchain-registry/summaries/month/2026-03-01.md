# ethereum-optimism/superchain-registry Monthly Report (March 2026)

## 🚀 Highlights
In March 2026, development focused on hardening the Superchain's core infrastructure, specifically targeting derivation pipeline stability and CI/CD reliability. Significant efforts were made to resolve critical error-handling issues within the `op-node` and `kona` derivation logic to ensure protocol resilience. While progress was made on documentation migrations and code generation tooling, the community remains focused on investigating a persistent database memory leak affecting node stability in production environments like World Chain.

## 🛠️ Key Developments

### CI/CD and Tooling Enhancements
Efforts this month focused on improving the reliability of automated workflows and the robustness of code generation checks.
*   **Code Generation Auditing:** A new pull request [#1201](https://github.com/ethereum-optimism/superchain-registry/pull/1201) was introduced to expand the `check-codegen` tool. This enhancement allows for better detection of changes in Go code and underlying dependencies, preventing silent regressions.
*   **Dependency Management:** To resolve failures in the daily-codegen CI pipeline, developers bumped the `op-fetcher` dependency in [#1200](https://github.com/ethereum-optimism/superchain-registry/pull/1200).

### Protocol & Derivation Stability
Refinements to the derivation pipeline addressed how the system handles malformed or external data.
*   **Error Handling Audit:** The team completed a comprehensive audit of external-input error handling within the `op-node/derive` pipeline, ensuring that the system responds predictably to unexpected data.
*   **Batch Extraction Logic:** In `kona/derive`, the team addressed a specific failure regarding span batch extraction. It was determined that the system should preserve historical behavior for invalid batch data rather than flushing, maintaining consistency across the protocol.

## 🐛 Issues & Triage

### Closed Issues
*   **Derivation Pipeline:** Multiple issues were resolved following the audit of the `op-node/derive` pipeline ([#19491](https://github.com/ethereum-optimism/superchain-registry/issues/19491)) and the refinement of batch extraction in `kona` ([#19511](https://github.com/ethereum-optimism/superchain-registry/issues/19511)).
*   **Documentation:** The hosting of Rust documentation ([#1985](https://github.com/ethereum-optimism/superchain-registry/issues/1985)) was successfully integrated into the project's broader documentation migration strategy.

### New & Active Issues
*   **Critical Memory Leak:** A high-priority issue ([#19212](https://github.com/ethereum-optimism/superchain-registry/issues/19212)) involving long-running database read transactions in `op-reth` remains active. This leak has caused nodes on World Chain v1.10.1 to crash within minutes. Current triage efforts are focused on determining if the upgrade to v1.11.0 provides a definitive fix, as reports from different environments (v1.10.2 vs v1.11.0) have shown inconsistent results.

## 💬 Community & Collaboration
The month saw active technical coordination between contributors regarding node performance and protocol stability. Discussions around the `op-reth` memory leak indicate a high level of collaboration between infrastructure operators (such as those running World Chain) and core maintainers to diagnose version-specific regressions. The resolution of the derivation pipeline audit also reflects a successful cross-team effort to implement feedback from security audits and protocol research.
