## ACTIVE ISSUES

### Initial EL Sync UX and Correctness
Discussion continued on the `op-node`'s initial EL Sync behavior, focusing on the correctness and user experience of setting safe and finalized heads. The latest comments reiterate the issue's two dimensions: correctness (ensuring safe/finalized reflect L1 finalization gadget) and UX (reducing derivation time). Option 2 (setting safe/finalized to unsafe head minus sequencer window) is proposed as a balanced approach, maintaining correctness while improving UX by reducing derivation time compared to starting from genesis. [#17631](https://github.com/ethereum-optimism/superchain-registry/issues/17631)

### Review Kona-Interop Block Hash Oracle
The review of the `kona-interop` block hash oracle continued, with the latest comments focusing on the need for an integration/acceptance test to verify block lookups prior to the current history window. It was noted that an existing action test covers this, and the discussion revolved around whether to port this to an acceptance test, especially considering `op-supernode` integration and generating sufficient chain history using time travel. [#18288](https://github.com/ethereum-optimism/superchain-registry/issues/18288)

### Non-Terminating CI Job: memory-all-opn-op-geth
