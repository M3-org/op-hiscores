## CLOSED ISSUES

- **Derivation Pipeline Stability Audits:** An audit of the derivation pipeline's external-input error handling was completed, ensuring that malformed L1 inputs do not halt derivation. All sub-issues related to this audit have been closed ([#19491](https://github.com/ethereum-optimism/superchain-registry/issues/19491)).
- **Batch Queue Error Handling:** An issue regarding span batch extraction failure in `BatchQueue` returning `Critical` instead of flushing was closed. The decision was made to preserve historical behavior for invalid batch data, as these cases were not observed in production networks ([#19511](https://github.com/ethereum-optimism/superchain-registry/issues/19511)).
- **Rust Documentation Hosting:** The issue concerning the hosting of Rust documentation was closed, as it is now captured within the broader documentation migration project ([#1985](https://github.com/ethereum-optimism/superchain-registry/issues/1985)).

## ACTIVE ISSUES

- **Database Read Transaction Memory Leak:** Discussion continues on issue [#19212](https://github.com/ethereum-optimism/superchain-registry/issues/19212), where users are experiencing memory leaks due to database read transactions being open for too long. A new comment from 0xForerunner indicates that World Chain v1.10.1 also encountered this issue, leading to node crashes. The user inquired if upgrading to v1.11 has resolved the problem for others. Previously, `jonathanudd` noted that the issue had not recurred in the last 7 days on v1.10.2, but they had not yet upgraded to v1.11.0.
