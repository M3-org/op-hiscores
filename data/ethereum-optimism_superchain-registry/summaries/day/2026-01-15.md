# ethereum-optimism/superchain-registry Daily Update (Jan 15, 2026)
## OVERVIEW 
Today's activity focused on updating standard versions for op-contracts v6.0.0-rc.2, specifically for L1 contracts that remained unchanged from the previous release candidate. An issue related to Kona node's light CL implementation was also closed.

## KEY TECHNICAL DEVELOPMENTS

### Standard Version Updates
The standard versions for `op-contracts` v6.0.0-rc.2 were updated in the `mainnet.toml` and `sepolia.toml` files. This update was necessary for a release of `op-deployer` that includes changes to L2 contracts, even though the L1 contracts themselves were unchanged from the previous release candidate ([#1194](https://github.com/ethereum-optimism/superchain-registry/pull/1194)).
