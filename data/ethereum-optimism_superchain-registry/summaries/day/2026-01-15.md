# ethereum-optimism/superchain-registry Daily Update (Jan 15, 2026)
## OVERVIEW 
Today's activity focused on updating standard versions for op-contracts v6.0.0-rc.2, specifically for L1 contracts that remain unchanged from the previous release candidate. An active issue regarding Kona node's light CL implementation was also closed.
