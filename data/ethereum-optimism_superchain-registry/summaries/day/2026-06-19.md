### `op-reth` Versioning Inconsistencies
Issue [#20832](https://github.com/ethereum-optimism/superchain-registry/issues/20832) highlights that the `kona-node` and `op-reth` metrics info version field does not align with the git/docker tag. The latest comment from `sebastianst` on June 19, 2026, further details inconsistencies, noting that `op-reth`'s version command and `web3_clientVersion` return the internal `reth` crate version instead of the expected git tag.

### Recurring `op-reth` Integration Test Flake
Issue [#20973](https://github.com/ethereum-optimism/superchain-registry/issues/20973) reports a persistent flake in the `reth-optimism-node` integration test `peers_negotiate_eth_69`, which results in a `SIGSEGV` on teardown. `sebastianst`'s comment on June 19, 2026, confirms the recurrence of this flake, which caused a PR to be kicked out of the merge queue. The comment also reiterates that the teardown segfault is non-deterministic and not introduced by recent changes.

### Optimism Sepolia Intrinsic Gas Issue
Issue [#21457](https://github.com/ethereum-optimism/superchain-registry/issues/21457) describes an issue where Optimism Sepolia's intrinsic gas is too high after the Karst hard fork. `geoknee` commented on June 19, 2026, stating that this is a known issue and will be addressed in the next release, referencing the Optimism upgrade notices.
