### Flaky Test: `TestReorgUnsafeHead` ([#20198](https://github.com/ethereum-optimism/superchain-registry/issues/20198))
A root cause for the flaky `TestReorgUnsafeHead` was identified and a fix opened in a separate PR. The issue stemmed from the test picking the next block's parent by reading the EL's mutable `eth.Unsafe` label, which could lag behind `op-reth`'s canonical-tag swap, leading to reorgs that silently undid the test's intended reorg. The proposed fix involves using the `ReorgExact` DSL poll to wait for the divergence height to reorg and then taking the confirmed conflicting block as the explicit parent.

### Interop Proofs Devnet ([#20489](https://github.com/ethereum-optimism/superchain-registry/issues/20489))
Progress on the Interop Proofs Devnet continues, with the SuperFaultDisputeGame played and resolved. The main remaining task is to finalize a withdrawal, which was initiated last week. The team is currently working on fixing an `op-chain-ops` script required to prove withdrawals.

### [L2CM] Add setWithdrawalRoute to FeeVaults ([#20806](https://github.com/ethereum-optimism/superchain-registry/issues/20806))
This issue is currently blocked due to a problem with how L2 contract semvers are handled in testing. When an L2 contract's semver is bumped, the locked bundles used in `TestActivationBlockNUTBundle` can no longer be executed against the locally generated genesis state because the L2CM prevents downgrades. This is identified as a deficiency in the test rather than a bug in the L2CM, and a solution is being sought to allow L2 contract modifications without this testing impediment.
