## ACTIVE ISSUES

- **SDM Test Coverage:** Issue [#21344](https://github.com/ethereum-optimism/superchain-registry/issues/21344) discusses adding test coverage for SDM in `rust/kona/tests/proofs`. The latest comments from einar-oplabs suggest that existing coverage for the scenario (invalid PostExec tx leading to a deposit-only block) is already present in other areas, and the specific gap cannot be closed in the `rust/kona/tests/proofs` directory until the harness engine is swapped to `op-reth`. The recommendation is to close the issue as the combined scenario is deferred behind another issue.
- **Flaky Test: `TestP2PFull`:** Issue [#22381](https://github.com/ethereum-optimism/superchain-registry/issues/22381) reports a flaky `TestP2PFull` test. The latest comment from wwared provides a detailed investigation summary, identifying a strong candidate for the "no addresses" failures as a disconnect cleanup racing an immediate reconnect. However, the proposed fix for this specific race did not eliminate all failures in broader validation, and the root cause for other observed issues (like "noise: message is too short") remains unknown. The conclusion is that there is insufficient evidence for a root-cause fix, and the issue should remain open.
