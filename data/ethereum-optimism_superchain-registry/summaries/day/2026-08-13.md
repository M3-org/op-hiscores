## CLOSED ISSUES

### Batcher Sequencing Window Expiry Investigation Concluded
The investigation into `op-batcher` sequencing-window expiry recovery with span-batches has been closed as "wontfix." It was determined that recovery mode is primarily supported with the batcher in singular-batch mode, and supporting it with span batches is not a priority. ([#16036](https://github.com/ethereum-optimism/superchain-registry/issues/16036))

### op-deployer Changes for ZK Dispute Games Completed
The issue tracking `op-deployer` changes and new OPCM options for ZK dispute games has been closed, indicating that the work is complete. ([#21429](https://github.com/ethereum-optimism/superchain-registry/issues/21429))

### sdm-net-0 Permissionless Fault Proofs Decision
The issue regarding restoring permissionless fault proofs for `sdm-net-0` has been closed. The decision was made to use permissioned fault proofs instead, as they are simpler and already implemented on `sdm-net-0`. ([#22348](https://github.com/ethereum-optimism/superchain-registry/issues/22348))
