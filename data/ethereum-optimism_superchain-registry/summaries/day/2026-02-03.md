## ACTIVE ISSUES

### op-node: Initial EL Sync UX and Correctness
Discussion continued on issue [#17631](https://github.com/ethereum-optimism/superchain-registry/issues/17631), which addresses op-node marking an EL Sync target as finalized even if it's not actually finalized. The latest comments from @trianglesphere and @axelKingsley debated the feasibility of using Snap Sync with op-geth versus op-reth for this scenario, and the implications of treating EL-synced content as finalized. @sebastianst suggested running derivation from a prior L1 block and consolidation to verify alignment with the EL-synced unsafe chain.

### Enable skipped acceptance tests for interop proofs
Issue [#18616](https://github.com/ethereum-optimism/superchain-registry/issues/18616) was reopened by @ajsutton, noting that while some tests mentioned in the original issue might have been addressed, the `TestInteropReadiness` test in `op-acceptance-tests/tests/isthmus/preinterop/interop_readiness_test.go` is still skipped. The issue remains active until all relevant tests are unskipped, pending support for explicit output roots from the super DG.
