### `reth-optimism-node` Integration Test Flakiness ([#20973](https://github.com/ethereum-optimism/superchain-registry/issues/20973))
This issue describes a flaky `peers_negotiate_eth_69` integration test in `reth-optimism-node` that results in SIGSEGV crashes on teardown. The suspected root cause is a race condition during runtime teardown, specifically when the payload builder service, switched to `spawn_critical_os_thread`, attempts to access Tokio internals that the main thread is concurrently freeing. This issue is not test-specific and could affect any `op-reth` runtime teardown.
