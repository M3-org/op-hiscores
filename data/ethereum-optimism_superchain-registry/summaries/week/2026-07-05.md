# ethereum-optimism/superchain-registry Weekly Report (Jul 5 - 11, 2026)

## 🚀 Highlights
This week focused on maintaining the integrity of the Superchain registry through consistent automated updates and critical infrastructure stabilization. A major milestone was reached with the resolution of a "high intrinsic gas" bug on Optimism Sepolia following the Karst hard fork, ensuring network reliability for developers. The team also initiated a strategic re-evaluation of CI stability and testing methodologies, specifically addressing flaky sequencer tests and refining the project's long-term fuzzing strategy to prioritize high-value differential targets.

## 🛠️ Key Developments
The technical work this week centered on registry maintenance, dependency management, and refining the testing pipeline.

### Registry Maintenance & Automation
The core function of the registry was maintained through daily automated code generation updates. These updates consistently modified `addresses.json` within the `superchain/extra` directory to ensure the registry reflects the most current chain configurations.
*   **Automated Codegen Updates:** [#1276](https://github.com/ethereum-optimism/superchain-registry/pull/1276), [#1277](https://github.com/ethereum-optimism/superchain-registry/pull/1277), [#1278](https://github.com/ethereum-optimism/superchain-registry/pull/1278).

### Dependency Management
Efforts to keep the registry aligned with the broader OP Stack included updating core dependencies.
*   **Optimism Dependency:** A new PR was opened to bump the Optimism dependency to its latest version ([#1279](https://github.com/ethereum-optimism/superchain-registry/pull/1279)).
*   **REVM Tracking:** The team is currently monitoring for a new `revm` release (2.4.0 / 2.3.1) to update `op-reth` dependencies, though the release is not yet available ([#21524](https://github.com/ethereum-optimism/superchain-registry/issues/21524)).

### CI & Testing Infrastructure
Significant work was dedicated to improving the reliability of the development pipeline.
*   **Fuzzing Strategy Shift:** The team conducted an audit of Go fuzz tests and decided to retire current PR-time fuzzing jobs in favor of deterministic seed tests. Future fuzzing will focus on nightly jobs with committed corpora and crash-artifact alerting ([#21636](https://github.com/ethereum-optimism/superchain-registry/issues/21636)).
*   **Sequencer Test Fixes:** A root cause analysis was completed for flakiness in `TestSupernodeLightSequencerInteropInvalidMessageReplacement`. The proposed fix involves forcing sequencer resets on upstream local-safe advances to prevent stale build states ([#21635](https://github.com/ethereum-optimism/superchain-registry/issues/21635)).

## 🐛 Issues & Triage

### Closed Issues
*   **Critical Bug Fixes:** The "intrinsic gas too high" error on Optimism Sepolia ([#21457](https://github.com/ethereum-optimism/superchain-registry/issues/21457)) was resolved and included in the `op-reth/v2.3.3` release.
*   **Project Consolidation:** The "Unichain Mainnet Replicas Supernode" issue ([#21177](https://github.com/ethereum-optimism/superchain-registry/issues/21177)) was moved to a core team project, and the "Bond sizing model" issue ([#21417](https://github.com/ethereum-optimism/superchain-registry/issues/21417)) was closed as it is being handled within the main `optimism` repository.
*   **Spam Mitigation:** Several issues from "Lumi Security Audit" ([#21606](https://github.com/ethereum-optimism/superchain-registry/issues/21606), [#21623](https://github.com/ethereum-optimism/superchain-registry/issues/21623)) were identified as unsolicited advertisements/spam and closed.

### New & Active Issues
*   **CI Stability:** The primary focus remains on resolving the flaky interop tests identified in [#21635](https://github.com/ethereum-optimism/superchain-registry/issues/21635).
*   **Fuzzing Transition:** The transition from PR-time fuzzing to a more robust nightly strategy is ongoing, with PR [#21639](https://github.com/ethereum-optimism/superchain-registry/pull/21639) serving as the vehicle for these changes.
