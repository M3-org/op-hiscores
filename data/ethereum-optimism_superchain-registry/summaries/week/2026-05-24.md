# ethereum-optimism/superchain-registry Weekly Report (May 24 - 30, 2026)

## 🚀 Highlights
This week focused on critical Superchain maintenance, including the removal of sunsetting chains and the activation of the Karst (U19) hardfork across both Mainnet and Sepolia. A significant portion of development effort was dedicated to technical debt, as CI checks triggered the reopening of over a dozen issues related to unaddressed TODOs in Interop and L2 contract management. Meanwhile, the team advanced developer tooling through proposals for deployment factory support and refined user metrics to improve Sybil resistance within the ecosystem.

## 🛠️ Key Developments

### Superchain Configuration & Maintenance
The registry underwent significant updates to reflect the current state of the ecosystem and upcoming protocol upgrades.
*   **Chain Sunsetting:** Arena-Z and Swell were removed from the registry following their announced sunsets, involving cleanups across `CHAINS.md`, `chainList.json`, and various configuration files ([#1247](https://github.com/ethereum-optimism/superchain-registry/pull/1247)).
*   **Karst Hardfork:** Activation timestamps for the Karst (U19) hardfork were integrated for both Sepolia and Mainnet superchains ([#1246](https://github.com/ethereum-optimism/superchain-registry/pull/1246)).
*   **Kona Prestates:** Standard prestate entries for `kona-client` versions v1.2.14, v1.5.1, and v1.5.2 were added to ensure up-to-date validation data ([#1242](https://github.com/ethereum-optimism/superchain-registry/pull/1242)).
*   **Contract Versioning:** New standard version entries for `op-contracts/v7.0.0-rc.4` were incorporated into mainnet and sepolia configurations ([#1245](https://github.com/ethereum-optimism/superchain-registry/pull/1245)).

### Developer Tooling & Metrics
Work progressed on expanding the capabilities of the Superchain's developer and analytics infrastructure.
*   **Deployment Factories:** A new design was proposed to support `CREATE`/`CREATE2` factory dependencies in dev tooling, including a factory indexer and verification gates ([#12](https://github.com/ethereum-optimism/superchain-registry/issues/12)).
*   **Enhanced User Metrics:** Proposals were made to move beyond Farcaster IDs by implementing a blended user score. This includes weighting KYC-linked addresses and organic activity while using graph clustering for Sybil resistance ([#13](https://github.com/ethereum-optimism/superchain-registry/issues/13)).

## 🐛 Issues & Triage

### Closed Issues
*   **Component Removal:** The `op-supervisor` component was successfully removed from the codebase, marking the completion of a significant cleanup task ([#20124](https://github.com/ethereum-optimism/superchain-registry/issues/20124)).

### New & Active Issues
*   **Technical Debt & Reopened TODOs:** A large number of issues were reopened due to persistent TODOs identified by CI. Key areas include Interop activation awareness ([#16141](https://github.com/ethereum-optimism/superchain-registry/issues/16141)), Interop load test performance ([#16448](https://github.com/ethereum-optimism/superchain-registry/issues/16448)), and the productionization of test sequencing ([#14129](https://github.com/ethereum-optimism/superchain-registry/issues/14129)).
*   **L2 Contracts Manager (L2CM) Structural Risks:** Discussions highlighted a "structural pipeline gap" where implementation knowledge is spread across five independent data structures, risking silent failures during upgrades ([#19260](https://github.com/ethereum-optimism/superchain-registry/issues/19260)).
*   **Engine API & Reth Stability:** Investigation continues into a `SIGBUS` crash in `op-reth` during deep Forkchoice Updated (FCU) rewinds ([#20934](https://github.com/ethereum-optimism/superchain-registry/issues/20934)). Additionally, a new bug was reported regarding nondeterministic output in `generate-semver-lock` when multiple artifacts share semver keys ([#21032](https://github.com/ethereum-optimism/superchain-registry/issues/21032)).
*   **Flaky Tests:** `TestUnsafeChainNotStalling_CLSync` is regressing, with initial findings pointing toward an Engine API stall rather than a test budget issue ([#21041](https://github.com/ethereum-optimism/superchain-registry/issues/21041)).
