# ethereum-optimism/optimism Daily Update (Aug 10, 2026)
## OVERVIEW 
Today's development focused on CI/CD pipeline improvements, including front-loading tool installations and enhancing dependency review processes. Significant progress was also made in `op-deployer` for post-Glamsterdam L1 compatibility. Several key issues related to SDM devnet rollout and PCD Milestone 4 were closed.

## KEY TECHNICAL DEVELOPMENTS

### CI/CD Pipeline Enhancements
Improvements were made to the CI/CD pipeline to increase efficiency and reliability. This included front-loading `mise` tool installations to mitigate common infrastructure failures ([#22322](https://github.com/ethereum-optimism/optimism/pull/22322)). Additionally, dependency review checks were extended to merge groups and a repo-local exception mechanism was wired in for better security management ([#22363](https://github.com/ethereum-optimism/optimism/pull/22363), [#22350](https://github.com/ethereum-optimism/optimism/pull/22350)).

### `op-deployer` and Build System Updates
The `op-deployer` was updated to correctly estimate broadcast gas against the target chain, addressing deployment failures on post-Glamsterdam L1s ([#21728](https://github.com/ethereum-optimism/optimism/pull/21728)). The `justfile` was also enhanced to automatically select between native and Docker Kona prestate builds ([#22341](https://github.com/ethereum-optimism/optimism/pull/22341)).
