# ethereum-optimism/optimism Daily Update (Apr 14, 2026)

## OVERVIEW 
Today's development focused on enhancing Optimism's core infrastructure with new transaction types for sequencer metering, improving developer tooling, and migrating critical tests to the acceptance test suite. Significant progress was also made in addressing audit findings related to L2CM.

## KEY TECHNICAL DEVELOPMENTS

*   **Core Protocol Enhancements for Sequencer Defined Metering (SDM)**
    Introduced a new post-execution transaction type to carry SDM metadata, crucial for future metering mechanisms. This involved extensive updates across `alloy-op-evm`, `op-alloy`, and `op-reth` components.
    *   Added post-execution transaction and receipt types for SDM metadata ([#19954](https://github.com/ethereum-optimism/optimism/pull/19954)).

*   **Improved Developer Experience and Tooling**
    Streamlined the development environment by automating Rust toolchain and testing setup, and refactored binary tooling for better reusability.
    *   Automated installation of nightly Rust toolchain and `cargo-nextest` via `mise` ([#20052](https://github.com/ethereum-optimism/optimism/pull/20052)).
    *   Refactored Rust binary tooling into a shared package for `kona-host` and other binaries ([#20067](https://github.com/ethereum-optimism/optimism/pull/20067)).

*   **Enhanced Testing and Fault Proof Robustness**
    Migrated several critical fault proof and interop tests to the `op-acceptance-tests` suite, improving test coverage and reliability. Bug fixes were also implemented to ensure proof backend catch-up and strict frame ordering.
    *   Migrated `TestInteropFaultProofs_MessageExpiry` to `op-acceptance-tests` using devstack DSL ([#20047](https://github.com/ethereum-optimism/optimism/pull/20047)).
    *   Migrated `TestInteropFaultProofs_DepositMessage_InvalidExecution` to `op-acceptance-tests` ([#20046](https://github.com/ethereum-optimism/optimism/pull/20046)).
    *   Fixed `devstack` to retry until the proof backend catches up ([#19990](https://github.com/ethereum-optimism/optimism/pull/19990)).
    *   Made Holocene activation proof tests non-trivial for better coverage ([#20023](https://github.com/ethereum-optimism/optimism/pull/20023)).
    *   Enforced strict frame ordering in `ChannelAssembler` for `kona` ([#20011](https://github.com/ethereum-optimism/optimism/pull/20011)).
    *   Ensured L2 clock catch-up in flashblocks tests within `op-acceptance-tests` ([#20013](https://github.com/ethereum-optimism/optimism/pull/20013)).
