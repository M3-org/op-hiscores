## NEW ISSUES

### OptimismPortal2 Migration and Refactoring
Several new issues have been opened to facilitate the migration to OptimismPortal2. This includes merging features from OptimismPortalInterop into OptimismPortal2 ([#19708](https://github.com/ethereum-optimism/optimism/issues/19708)), deleting the now redundant OptimismPortalInterop contract ([#19709](https://github.com/ethereum-optimism/optimism/issues/19709)), and refactoring the `OPContractsManagerMigrator.migrate()` function to target OptimismPortal2 ([#19710](https://github.com/ethereum-optimism/optimism/issues/19710)).

### Superchain Interoperability and Dispute Games
New issues address critical aspects of Superchain interoperability, including considering potential issues with custom gas token chains in interop sets and shared dispute games ([#19711](https://github.com/ethereum-optimism/optimism/issues/19711)). Operational runbooks are also being developed for merging chains into a shared SuperDisputeGame ([#19714](https://github.com/ethereum-optimism/optimism/issues/19714)) and for removing a chain from a shared SuperDisputeGame ([#19715](https://github.com/ethereum-optimism/optimism/issues/19715)). A `superchain-ops` task for unmerging chains from shared dispute games has also been proposed ([#19713](https://github.com/ethereum-optimism/optimism/issues/19713)).

### Developer Tooling and Testing
An issue was opened to unskip acceptance tests for invalid executing messages once the test infrastructure is ready ([#19712](https://github.com/ethereum-optimism/optimism/issues/19712)). Additionally, a new issue highlights the availability of free API access for testing Base L2 developer tools, including a Base Gas Tracker API ([#19716](https://github.com/ethereum-optimism/optimism/issues/19716)).
