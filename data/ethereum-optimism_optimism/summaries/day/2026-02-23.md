# ethereum-optimism/optimism Daily Update (Feb 23, 2026)
## OVERVIEW 
Today's development focused on CI/CD pipeline improvements, enhancing smart contract test coverage, and addressing an issue related to Kona prestate publishing. Several new pull requests were opened, covering various fixes and updates across the codebase.

## KEY TECHNICAL DEVELOPMENTS

### CI/CD Pipeline Enhancements
Improvements were made to the continuous integration and continuous deployment pipelines, including a fix for the `kona-publish-prestates` workflow to ensure it triggers correctly on scheduled builds and webhook pushes [#19270](https://github.com/ethereum-optimism/optimism/pull/19270). Additionally, a redundant `cannon-kona-host` job was removed from the CI configuration [#19279](https://github.com/ethereum-optimism/optimism/pull/19279).

### Smart Contract Test Coverage
Test coverage for the `DelayedWETH` smart contract was significantly improved by converting existing tests to fuzz tests and adding new tests to cover previously missed scenarios [#19275](https://github.com/ethereum-optimism/optimism/pull/19275).

### Kona Hint Format Optimization
The issue regarding using a binary format for Kona hints instead of string serialization was closed [#19125](https://github.com/ethereum-optimism/optimism/issues/19125). The discussion highlighted the trade-offs between performance and debugging simplicity, with a focus on maintaining backward compatibility for the host program.

Two new issues were opened concerning the `op-supernode`'s behavior during L1 reorgs.
