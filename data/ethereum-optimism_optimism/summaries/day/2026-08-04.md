# ethereum-optimism/optimism Daily Update (Aug 4, 2026)
## OVERVIEW 
Today's development focused on enhancing the Superchain ecosystem with improvements to the Kona SP1 proposer, refining gas estimation, and bolstering CI efficiency. Significant progress was also made in documentation for AI-assisted development and acceptance test coverage.

## KEY TECHNICAL DEVELOPMENTS

### Kona SP1 Proposer Enhancements and Protocol Support
The Kona SP1 proposer now defends challenged games using SP1 super-aggregation proofs, porting functionality from `op-succinct` to strengthen fault proof mechanisms within the Superchain. Additionally, the Kona protocol has been updated to support extended transaction envelopes in `L2BlockInfo`, allowing for greater flexibility for downstream chains.
- [#22121](https://github.com/ethereum-optimism/optimism/pull/22121)
- [#22196](https://github.com/ethereum-optimism/optimism/pull/22196)

### Gas Estimation Refinements and DA Footprint Accounting
Improvements were made to gas estimation by allowing the target node to cap gas, preventing issues with `tx.gas` exceeding `2^24` for state gas. The DA footprint accounting was also refined to exclude PostExec transactions from Jovian accounting, with specific regression tests added for this intentional divergence.
- [#22217](https://github.com/ethereum-optimism/optimism/pull/22217)
- [#22219](https://github.com/ethereum-optimism/optimism/pull/22219)

### CI Efficiency and Acceptance Test Coverage
CI efficiency was boosted by caching Forge build artifacts in `contracts-bedrock-build`, reducing redundant compiles. Acceptance tests were enhanced to use `NewMinimalNoFaultProofs` in interop smoke tests, focusing on sequencer and EL surface exercises. The `op-devstack` now allows acceptance suites to select the sequencer EL binary, improving testing flexibility.
- [#22199](https://github.com/ethereum-optimism/optimism/pull/22199)
- [#22230](https://github.com/ethereum-optimism/optimism/pull/22230)
- [#22205](https://github.com/ethereum-optimism/optimism/pull/22205)

### AI Documentation and Devstack Stability
New AI documentation was added, providing recipes for local CI validation and Rust tool-config discovery. The `op-devstack` and `op-supernode` saw stability improvements by clearing EL proxy upstream on stop and backing off VN restarts, addressing a flake in `TestSupernodeEngineControllerConnectsAfterELUnavailableAtStartup`.
- [#22125](https://github.com/ethereum-optimism/optimism/pull/22125)
- [#22014](https://github.com/ethereum-optimism/optimism/pull/22014)
