# ethereum-optimism/optimism Daily Update (Jul 31, 2026)

## OVERVIEW 
Today's development focused on significant documentation improvements, particularly around normalizing URLs and restructuring content. Key bug fixes addressed missing Superchain Deployment data in `op-deployer`. There was also substantial work on the Kona ZK dispute game, including new tests and Docker image publishing for the `kona-sp1-proposer`.

## KEY TECHNICAL DEVELOPMENTS

### Documentation Restructuring and Normalization
Extensive work was done to enhance the project's documentation. This included normalizing stuttered URLs, cutting glossary stubs, and extracting shared content into snippets to reduce duplication. Navigation for Node Operators was restructured for better usability, and specific sections like Guardian and Flashblocks expositions were consolidated. AI-related documentation also saw enhancements with new symlinks.
([#22139](https://github.com/ethereum-optimism/optimism/pull/22139), [#22135](https://github.com/ethereum-optimism/optimism/pull/22135), [#22150](https://github.com/ethereum-optimism/optimism/pull/22150), [#22149](https://github.com/ethereum-optimism/optimism/pull/22149), [#22148](https://github.com/ethereum-optimism/optimism/pull/22148), [#22170](https://github.com/ethereum-optimism/optimism/pull/22170), [#22169](https://github.com/ethereum-optimism/optimism/pull/22169))

### Kona ZK Dispute Game Enhancements and Testing
Significant progress was made on the Kona ZK dispute game, with new acceptance tests added to cover the `kona-sp1` proposer's game-creation path and strengthen anchor assertions. The `kona-sp1-proposer` now publishes Docker images, and its build process for cannon prestate variants was optimized. The Interop hardfork was also consistently renamed to Lagoon across comments and labels.
([#22105](https://github.com/ethereum-optimism/optimism/pull/22105), [#22168](https://github.com/ethereum-optimism/optimism/pull/22168), [#22058](https://github.com/ethereum-optimism/optimism/pull/22058), [#22172](https://github.com/ethereum-optimism/optimism/pull/22172), [#22161](https://github.com/ethereum-optimism/optimism/pull/22161), [#22134](https://github.com/ethereum-optimism/optimism/pull/22134), [#22157](https://github.com/ethereum-optimism/optimism/pull/22157))

### `op-deployer` and `op-chain-ops` Improvements
A critical bug in `op-deployer` was fixed, ensuring that `State.SuperchainDeployment` is correctly set after the `prepare` step. Additionally, `op-chain-ops` saw the removal of several pre-Holocene fork checkers and tools like `op-simulate` and `op-run-block`, streamlining the codebase. The `OPContractsManagerV2` major version was also bumped for the upcoming U20.
([#22082](https://github.com/ethereum-optimism/optimism/pull/22082), [#22164](https://github.com/ethereum-optimism/optimism/pull/22164), [#22158](https://github.com/ethereum-optimism/optimism/pull/22158), [#22156](https://github.com/ethereum-optimism/optimism/pull/22156), [#22096](https://github.com/ethereum-optimism/optimism/pull/22096))
