# ethereum-optimism/optimism Daily Update (Jan 15, 2026)
## OVERVIEW 
Today's development focused on significant contract updates, CI/CD pipeline fixes, and the integration of Kona into the monorepo, alongside improvements in testing and deployment tooling.

## KEY TECHNICAL DEVELOPMENTS

### Dispute Game Modernization and Contract Updates
The project made a significant stride in modernizing its dispute game infrastructure by removing all references to V1 dispute games, making V2 the canonical version. This cleanup involved extensive changes across contracts, interfaces, and deployment scripts. Additionally, the `op-deployer` was updated to support the `op-contracts/v6.0.0-rc.2` release.
- Removed V1 dispute games and established V2 as canonical [#18714](https://github.com/ethereum-optimism/optimism/pull/18714)
- Updated `op-deployer` for `op-contracts/v6.0.0-rc.2` release [#18809](https://github.com/ethereum-optimism/optimism/pull/18809)

### CI/CD and Deployment Tooling Enhancements
Several critical fixes and refactorings were implemented in the CI/CD pipelines and deployment tooling. This included resolving issues with publishing prestate artifacts and consolidating `DummyCaller` contracts for more efficient deployment scripts.
- Fixed `kona-proof` prestate job and `kona-publish-prestates` workflow in CI [#18805](https://github.com/ethereum-optimism/optimism/pull/18805), [#18799](https://github.com/ethereum-optimism/optimism/pull/18799)
- Consolidated `DummyCaller` contracts into a single generic implementation [#18786](https://github.com/ethereum-optimism/optimism/pull/18786)
- Avoided fallback artifact downloads when not on the `develop` branch [#18788](https://github.com/ethereum-optimism/optimism/pull/18788)

### Kona Integration and Testing Improvements
The Kona project was successfully upstreamed into the monorepo, marking a significant organizational change. Alongside this, test coverage for `DisputeMonitorHelper` and `OptimismSuperchainERC20Factory` contracts was improved with fuzz tests and edge case handling.
- Upstreamed `op-rs/kona` to the monorepo [#18754](https://github.com/ethereum-optimism/optimism/pull/18754)
- Enhanced `DisputeMonitorHelper` test coverage with fuzz tests and edge cases [#18732](https://github.com/ethereum-optimism/optimism/pull/18732)
- Improved `OptimismSuperchainERC20Factory` test coverage and naming conventions [#18791](https://github.com/ethereum-optimism/optimism/pull/18791)
