# ethereum-optimism/optimism Daily Update (Jan 15, 2026)

## OVERVIEW
Today's development focused on significant contract updates, including the removal of V1 dispute games and an `op-deployer` update for `op-contracts/v6.0.0-rc.2`. CI/CD pipelines saw fixes for prestate publishing, and contract test coverage was improved. The `kona` project was also upstreamed into the monorepo.

## KEY TECHNICAL DEVELOPMENTS

### Dispute Game and Contract Modernization
- Removed all references to V1 dispute games, making V2 games canonical, and updated related contract interfaces, scripts, and tests. [#18714](https://github.com/ethereum-optimism/optimism/pull/18714)
- Updated `op-deployer` to support the `op-contracts/v6.0.0-rc.2` release. [#18809](https://github.com/ethereum-optimism/optimism/pull/18809)
- Consolidated seven nearly identical `DummyCaller` contracts into a single generic implementation, improving code reusability. [#18786](https://github.com/ethereum-optimism/optimism/pull/18786)

### CI/CD and Testing Improvements
- Fixed CI jobs for publishing `kona-proof` prestates to the correct Google Cloud folder. [#18805](https://github.com/ethereum-optimism/optimism/pull/18805), [#18799](https://github.com/ethereum-optimism/optimism/pull/18799)
- Enhanced test coverage for `DisputeMonitorHelper` by converting focused tests to fuzz tests and adding edge case coverage. [#18732](https://github.com/ethereum-optimism/optimism/pull/18732)
- Improved test coverage for `OptimismSuperchainERC20Factory` by fixing naming conventions and adding fuzz tests. [#18791](https://github.com/ethereum-optimism/optimism/pull/18791)

### Infrastructure and `kona` Integration
- Upstreamed the `kona` project into the monorepo, including its configuration, dependencies, and various components. [#18754](https://github.com/ethereum-optimism/optimism/pull/18754)
- Refactored CI logic to avoid fallback artifact downloads when not on the `develop` branch. [#18788](https://github.com/ethereum-optimism/optimism/pull/18788)
- Addressed an issue in `op-challenger` where `closeGame()` was not called for permissioned games without bonds to claim, which could lead to outdated anchor states. [#18787](https://github.com/ethereum-optimism/optimism/pull/18787)
- Removed pre-Fulu restrictions on the blobs endpoint, simplifying beacon provider modeling. [#18810](https://github.com/ethereum-optimism/optimism/pull/18810)
