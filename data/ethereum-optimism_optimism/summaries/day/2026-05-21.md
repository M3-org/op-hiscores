# ethereum-optimism/optimism Daily Update (May 21, 2026)
## OVERVIEW 
Today's development focused on enhancing the OP Stack with unified predeploys and improved span batch support, alongside critical bug fixes for devstack stability and e2e test reliability. Significant refactoring efforts streamlined interop components, and documentation was updated for upcoming interop activations.

## KEY TECHNICAL DEVELOPMENTS

### OP Stack Core Enhancements & Interoperability
- **Unified Predeploys Source of Truth:** Implemented a unified source of truth for predeploys, addressing a critical architectural gap and improving upgrade safety within the `contracts-bedrock` package. This resolves a long-standing issue regarding implementation deployment completeness and validation. ([#19847](https://github.com/ethereum-optimism/optimism/pull/19847))
- **Advanced Batch Processing:** Added support for post-execution span batches in `op-node`, enhancing the efficiency and capabilities of batch processing. ([#20515](https://github.com/ethereum-optimism/optimism/pull/20515))
- **Dynamic Dependency Loading:** Enabled `op-node` to load dependency sets directly from the superchain-registry, improving configuration flexibility and mirroring rollup config loading. ([#20893](https://github.com/ethereum-optimism/optimism/pull/20893))

### Stability and Testing Improvements
- **Devstack and E2E Test Stabilization:** Fixed a race condition in `op-devstack` related to pre-genesis super game L1 block timing and stabilized `TestSequenceWindowExpired` in `op-e2e` by pinning L2 nonces, significantly reducing test flakiness. ([#20874](https://github.com/ethereum-optimism/optimism/pull/20874), [#20942](https://github.com/ethereum-optimism/optimism/pull/20942))
- **Refactored Interop Safety Levels:** Moved `SafetyLevel` constants into a new `op-service/eth/safety` sub-package, improving code organization and maintainability across various interop-related tests and services. ([#20889](https://github.com/ethereum-optimism/optimism/pull/20889))

### Documentation and Infrastructure Updates
- **Interop Activation Guide:** Added a comprehensive notice for node operators detailing the action checklist for the upcoming OP Sepolia and Unichain Sepolia interop activation. ([#20835](https://github.com/ethereum-optimism/optimism/pull/20835))
- **Kona Prestate Build Instructions:** Updated documentation for reproducible build flows for Kona FPVM prestates. ([#20951](https://github.com/ethereum-optimism/optimism/pull/20951))
- **CI Infrastructure Migration:** Completed the migration of 22 `optimism` jobs to Gen2 CircleCI resources, enhancing CI performance and reliability. ([#20927](https://github.com/ethereum-optimism/optimism/pull/20927))

## CLOSED ISSUES

### Contract Management and Upgrade Safety
- **Unified Predeploys Source of Truth:** The issue of adding an array of predeploys to increase upgrade safety for L2 Contracts Manager has been closed, with the implementation of a unified source of truth. This addresses concerns about missing implementation deployments and structural pipeline gaps identified during previous upgrades. ([#19260](https://github.com/ethereum-optimism/optimism/issues/19260))
- **L2CM Standard Validator Assertions:** The issue regarding missing standard validator assertions in L2CM has been closed. It was determined that the proposed checks on non-standard values would introduce breaking changes with little value. ([#20805](https://github.com/ethereum-optimism/optimism/issues/20805))
- **SystemConfig Ownership Renunciation:** The issue of preventing ownership renunciation in the SystemConfig has been closed. The team decided that while renouncing ownership could lead to bad outcomes, it would still be recoverable via a security council upgrade, making the implementation unnecessary. ([#20807](https://github.com/ethereum-optimism/optimism/issues/20807))

### Test Flakiness and Stability
- **Flaky Pre-Genesis Super Game Test:** The `TestChallengerCountersPreGenesisGame` test, which was flaking due to a race condition in L1 block timing during pre-genesis super game setup, has been fixed and the issue closed. The fix involved increasing the delay budget and adding a fast-fail invariant. ([#20869](https://github.com/ethereum-optimism/optimism/issues/20869))
- **Flaky Sequence Window Expiry Test:** The `TestSequenceWindowExpired` test, which was flaking due to "already known" transaction errors, has been fixed by pinning Bob's L2 nonce, and the issue is now closed. ([#20941](https://github.com/ethereum-optimism/optimism/issues/20941))
- **Flaky Supernode Resync Test:** The `TestSupernodeResyncResumesAtActivation_PostActivation` test, which was flaking due to issues with EL finalized state before fresh-data-dir restart, has been fixed and closed. ([#20944](https://github.com/ethereum-optimism/optimism/issues/20944))

### Kona Readiness and Dependency Management
- **Kona Production Readiness Evaluation:** The issue evaluating Kona's production readiness against `op-node` for interop and proofs has been closed, with all consensus-critical and liveness-related issues resolved. ([#20444](https://github.com/ethereum-optimism/optimism/issues/20444))
- **op-rbuilder and rollup-boost Decision:** The issue concerning the handling of `op-rbuilder` and `rollup-boost` dependencies has been closed, indicating a decision has been made on how to proceed. ([#20599](https://github.com/ethereum-optimism/optimism/issues/20599))
