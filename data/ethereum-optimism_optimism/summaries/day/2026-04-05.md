# ethereum-optimism/optimism Daily Update (Apr 5, 2026)
## OVERVIEW 
Today's development focused on enhancing the Supernode's interaction with the Denylist for optimistic output roots, alongside ongoing discussions on critical issues related to node stability and state root mismatches.

## KEY TECHNICAL DEVELOPMENTS

### Supernode Denylist Integration for Optimistic Output Roots
The Supernode now utilizes the Denylist Output for "OptimisticOutputRoot", ensuring that the Chain Container verifies with the Denylist before providing optimistic outputs. This update builds upon previous work to use full Outputs for the Denylist, enhancing the robustness of the Supernode's output handling. ([#19880](https://github.com/ethereum-optimism/optimism/pull/19880))

### Receipt Root Mismatch
A new issue, [#19930](https://github.com/ethereum-optimism/optimism/issues/19930), was opened to track a receipt root mismatch problem, cross-posted from a Reth issue. This issue highlights potential discrepancies during the syncing of older chains with hard forks.

## ACTIVE ISSUES
### Unknown Batch Type Panics and DoS in Kona-Protocol
Discussion on [#19334](https://github.com/ethereum-optimism/optimism/issues/19334) intensified today, with a security researcher, zhuzhushiwojia, claiming the bounty and proposing a fix for the critical DoS vulnerability. The proposed solution involves replacing `panic!()` with proper error handling for unknown batch types, returning a `Result` type, adding graceful error propagation, and including tests for malformed batch data. The estimated timeline for the fix is 2-3 days.

### Recurring State Root Mismatch in op-reth on Base Mainnet
The issue [#19532](https://github.com/ethereum-optimism/optimism/issues/19532) continues to be active, with a new comment from InoMurko asking if the problem is related to another Reth issue ([#23309](https://github.com/paradigmxyz/reth/issues/23309)). This issue describes recurring "mismatched block state root" errors causing permanent sync stalls and fatal crashes for op-reth archive nodes on Base mainnet.
