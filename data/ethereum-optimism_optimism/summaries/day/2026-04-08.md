# ethereum-optimism/optimism Daily Update (Apr 8, 2026)
## OVERVIEW 
Today's development focused on significant feature additions, critical bug fixes across various components, and important documentation updates. Key highlights include new commands for NUTs, shared dispute game migration for interop, and several fixes addressing flakiness in acceptance tests.

## KEY TECHNICAL DEVELOPMENTS

### Enhanced Tooling and Dispute Game Infrastructure
- Added `update-nuts` and `verify-nuts` commands for managing NUT bundles, improving the integrity and verification process of forks ([#19463](https://github.com/ethereum-optimism/optimism/pull/19463)).
- Migrated shared dispute game functionalities from `OptimismPortalInterop` to `OptimismPortal2`, unifying the contract logic for interop migrations ([#19840](https://github.com/ethereum-optimism/optimism/pull/19840)).
- Introduced a method to customize the engine validator in `OpAddOns` for `op-reth`, allowing for more flexible engine configurations ([#19907](https://github.com/ethereum-optimism/optimism/pull/19907)).

### Critical Bug Fixes and Stability Improvements
- Consolidated block-to-timestamp helpers in `op-supernode` and ensured proper respect for genesis offsets, resolving issues with timestamp conversions ([#19542](https://github.com/ethereum-optimism/optimism/pull/19542)).
- Fixed a panic in `kona-node`'s sequencer by handling missing L1 origin blocks gracefully, preventing crashes during reorgs or sync lags ([#19945](https://github.com/ethereum-optimism/optimism/pull/19945)).
- Addressed several flaky acceptance tests, including `TestFlashblocksTransfer` by removing a wall-clock assertion ([#19959](https://github.com/ethereum-optimism/optimism/pull/19959)) and `TestExecutePayloadSuccess` by waiting for the proofs ExEx store before execution ([#19986](https://github.com/ethereum-optimism/optimism/pull/19986)).
- Corrected dispute game helper logic in `op-e2e` to send required bonds and restore correct Cannon-Kona game types, resolving deployment and challenger configuration mismatches ([#19953](https://github.com/ethereum-optimism/optimism/pull/19953), [#19983](https://github.com/ethereum-optimism/optimism/pull/19983)).

### Documentation and Infrastructure Updates
- Published new documentation for fee vaults, including an explainer and an operations guide, enhancing clarity for chain operators ([#19952](https://github.com/ethereum-optimism/optimism/pull/19952)).
- Upgraded `op-geth` across the project, ensuring the use of the latest client version ([#19844](https://github.com/ethereum-optimism/optimism/pull/19844)).
- Integrated `op-revm` into the workspace and removed remaining patch dependencies in the Rust codebase, streamlining development ([#19961](https://github.com/ethereum-optimism/optimism/pull/19961), [#19948](https://github.com/ethereum-optimism/optimism/pull/19948)).
