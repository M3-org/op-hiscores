# ethereum-optimism/optimism Daily Update (Apr 8, 2026)
## OVERVIEW 
Today's development focused on significant feature additions, critical bug fixes across various components, and important documentation updates. Key highlights include new commands for managing NUT bundles, migration of dispute game functionalities, and several fixes addressing flakiness in acceptance tests and improving system stability.

## KEY TECHNICAL DEVELOPMENTS

### Enhanced Dispute Game and Interoperability Features
- Added new `update-nuts` and `verify-nuts` commands to manage NUT bundles, improving the snapshotting and verification process for forks ([#19463](https://github.com/ethereum-optimism/optimism/pull/19463)).
- Migrated shared dispute game functionalities (`migrateToSuperRoots`, `migrateLiquidity`, `initialize`) from `OptimismPortalInterop` to `OptimismPortal2` to unify the OPCM_V2 target for interop migration ([#19840](https://github.com/ethereum-optimism/optimism/pull/19840)).
- Exposed a new `with_engine_validator` method in `OpAddOns` to allow for customized engine validators in `op-reth` ([#19907](https://github.com/ethereum-optimism/optimism/pull/19907)).

### Critical Bug Fixes and Stability Improvements
- Consolidated block-to-timestamp helpers in `op-supernode` and ensured respect for genesis offset, resolving issues with conversion logic and error handling ([#19542](https://github.com/ethereum-optimism/optimism/pull/19542)).
- Fixed an issue in `kona-proof-interop` to only print missing chain IDs in rollup config warnings, reducing log verbosity ([#19729](https://github.com/ethereum-optimism/optimism/pull/19729)).
- Isolated `anvil FOUNDRY_HOME` in the deployer to prevent bloat of `~/.foundry` by using a temporary directory ([#19813](https://github.com/ethereum-optimism/optimism/pull/19813)).
- Addressed a panic in `kona-node`'s sequencer by handling missing L1 origin blocks gracefully with an `OriginNotFound` error, triggering an engine reset instead ([#19945](https://github.com/ethereum-optimism/optimism/pull/19945)).
- Resolved flaky acceptance tests by removing a wall-clock assertion in `TestFlashblocksTransfer` ([#19959](https://github.com/ethereum-optimism/optimism/pull/19959)) and increasing the CrossSafe sync timeout for EL Sync tests ([#19977](https://github.com/ethereum-optimism/optimism/pull/19977)).
- Fixed issues with dispute game creation in `op-e2e` by ensuring the required bond is sent ([#19953](https://github.com/ethereum-optimism/optimism/pull/19953)) and restoring correct cannon-kona game types ([#19983](https://github.com/ethereum-optimism/optimism/pull/19983)).
- Corrected a misleading error message in `op-devstack`'s `rust_binary.go` and added debug build targets ([#19988](https://github.com/ethereum-optimism/optimism/pull/19988)).
- Fixed a recurring flake in `TestExecutePayloadSuccess` by waiting for the proofs ExEx store before `debug_executePayload` ([#19986](https://github.com/ethereum-optimism/optimism/pull/19986)).

### Documentation and Infrastructure Updates
- Added a comprehensive explainer and operations guide for fee vaults, covering their mechanics, configuration, and withdrawal processes ([#19952](https://github.com/ethereum-optimism/optimism/pull/19952)).
- Upgraded `op-geth` to its latest version ([#19844](https://github.com/ethereum-optimism/optimism/pull/19844)).
- Integrated `op-revm` into the workspace and updated `kona-hardforks` to use the local path ([#19961](https://github.com/ethereum-optimism/optimism/pull/19961)).
