# ethereum-optimism/optimism Daily Update (Jun 3, 2026)
## OVERVIEW 
Today's development focused on enhancing testing infrastructure, particularly for supernode interoperability and the integration of `op-rbuilder` for L2 testing.

## KEY TECHNICAL DEVELOPMENTS

### Supernode Interoperability Testing
A new test was added to validate follow-mode supernode interop using EL sync, specifically proving that a light op-node sequencer correctly adopts invalid message replacements from the supernode. This addresses a previously identified issue. ([#21122](https://github.com/ethereum-optimism/optimism/pull/21122))

### `op-rbuilder` Integration for L2 Testing
The `op-devstack` now includes `op-rbuilder` as an execution layer option. This integration is currently for manual testing of Osaka on L2 against `op-rbuilder`, with future plans to potentially run all CI tests against it. ([#21165](https://github.com/ethereum-optimism/optimism/pull/21165))
