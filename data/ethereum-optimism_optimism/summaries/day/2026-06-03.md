# ethereum-optimism/optimism Daily Update (Jun 3, 2026)
## OVERVIEW
Today's development focused on enhancing Kona's native single-chain proofs, improving `op-reth`'s state-dump import, and significant code refactoring to reduce cross-package coupling. Several CI fixes and dependency reductions were also implemented.

## KEY TECHNICAL DEVELOPMENTS

### Kona Proofs and `op-reth` Enhancements
- Validated SDM `PostExec` blocks in native single-chain proofs for Kona, including acceptance coverage for Interop-active and Interop-inactive configurations, and added Kona-native devstack support for Interop activation overrides ([#21034](https://github.com/ethereum-optimism/optimism/pull/21034)).
- Seeded the slot-preimage DB during `op-reth` state-dump import to prevent crashes during backfill sync, addressing issues with missing slot preimages ([#21108](https://github.com/ethereum-optimism/optimism/pull/21108)).

### Code Refactoring and Dependency Management
- Relocated the generic preimage key-value store from `op-program/host/kvstore` to `op-challenger/kvstore` and interop transition types to `op-service/eth`, reducing cross-package coupling ([#21176](https://github.com/ethereum-optimism/optimism/pull/21176)).
- Reduced low-risk dependency surface across the monorepo to enhance supply-chain security and simplify CVE management, without altering protocol behavior ([#20988](https://github.com/ethereum-optimism/optimism/pull/20988)).
- Renamed the Interop hardfork to Lagoon across the OP Stack, updating configuration files and documentation ([#21105](https://github.com/ethereum-optimism/optimism/pull/21105)).

### CI/CD and Testing Improvements
- Fixed CI failures for docs-only PRs by forcing `always-succeed` on Rust skip-path gates, ensuring trivial completion of Rust fast paths ([#21172](https://github.com/ethereum-optimism/optimism/pull/21172), [#20863](https://github.com/ethereum-optimism/optimism/pull/20863)).
- Added a new test for follow-mode supernode interop on ELSync, including an end-to-end proof for light `op-node` sequencer adoption of supernode's deposits-only invalid-message replacement ([#21122](https://github.com/ethereum-optimism/optimism/pull/21122)).
- Removed the `op-e2e/system/proofs/system_fpp_test.go` and its helper, as its coverage is now handled by `op-acceptance-tests` ([#21174](https://github.com/ethereum-optimism/optimism/pull/21174)).
