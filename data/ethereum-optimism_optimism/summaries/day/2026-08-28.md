# ethereum-optimism/optimism Daily Update (Aug 28, 2026)
## OVERVIEW 
Today's development focused on infrastructure updates, including upgrading `op-geth` and `bun` versions, and updating release documentation. Significant progress was made in testing a new L1 chain deployment on the Plataberget testnet, including deposit and withdrawal flows.

### Infrastructure and Dependency Updates
Key dependencies were updated to improve compatibility and address parsing issues. This includes an update to `op-geth` to `v1.101702.3-rc.7` ([#22694](https://github.com/ethereum-optimism/optimism/pull/22694)) and `bun` to `1.4.0` ([#22697](https://github.com/ethereum-optimism/optimism/pull/22697)) to resolve JavaScript syntax parsing errors.

## CLOSED ISSUES

### Testnet Deployment and Withdrawal Testing
The "Plataberget test deployment" issue was closed today ([#22696](https://github.com/ethereum-optimism/optimism/issues/22696)). The long-standing issue "Spin up devnet" was closed ([#20691](https://github.com/ethereum-optimism/optimism/issues/20691)). This issue tracked the effort to establish a new devnet, which has now been achieved with the Plataberget deployment.
