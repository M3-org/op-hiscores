# ethereum-optimism/optimism Daily Update (Jan 6, 2026)
## OVERVIEW 
Today's development focused on enhancing dispute game interoperability with a new `rootClaim` function, streamlining the batcher by removing outdated Pectra checks, and improving test coverage for OPCMv2 upgrades.

## KEY TECHNICAL DEVELOPMENTS

### Dispute Game Interoperability Enhancements
- Added an overloaded `rootClaim` function to the `IDisputeGame` interface, allowing claims to be retrieved by L2 chain ID, which is crucial for future interop support. ([#18559](https://github.com/ethereum-optimism/optimism/pull/18559))

### Batcher Code Simplification
- Removed `isPectra` checks from the batcher, simplifying the codebase by assuming the Pectra fork is always active on L1. ([#18534](https://github.com/ethereum-optimism/optimism/pull/18534))

### Improved Testing and Developer Experience
- Enhanced test coverage and documentation for the `UpgradeOPChain` script, specifically for the OPCM V2 upgrade path, including fuzzing and revert case testing. ([#18704](https://github.com/ethereum-optimism/optimism/pull/18704))
- Improved skip messages for tests that are conditionally skipped based on feature flags. ([#18661](https://github.com/ethereum-optimism/optimism/pull/18661))
