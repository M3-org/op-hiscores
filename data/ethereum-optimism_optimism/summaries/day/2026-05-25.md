# ethereum-optimism/optimism Daily Update (May 25, 2026)

Today's development focused on critical bug fixes in `op-supernode` and CI, alongside important documentation updates and dependency management. Several stale TODOs were also removed, streamlining the codebase.

### Supernode Stability and Interoperability
A significant bug fix was implemented in `op-supernode` to correctly propagate verifier read errors, preventing silent failures and ensuring proper handling of verified block data. ### Supernode Test Flakiness Addressed
A flaky test, `TestSupernodeResyncResumesAtActivation_PostActivation`, has been resolved and its corresponding issue closed ([#20944](https://github.com/ethereum-optimism/optimism/issues/20944)). The root cause was identified as `VerifiedBlockAtL1` and `LatestVerifiedL2Block` silently swallowing read errors, leading to incorrect cold-start behavior. The fix ensures these errors are propagated, improving test stability.
