# ethereum-optimism/optimism Daily Update (Mar 8, 2026)
## OVERVIEW 
Today's development focused on integrating ZK proof features, fixing a critical bug in `op-supernode` related to L1 block verification, and streamlining output game creation in e2e tests.

## KEY TECHNICAL DEVELOPMENTS

### ZK Proof System Integration
A new feature flag for the ZK proof system has been registered within the `contracts-bedrock` feature system, laying the groundwork for future zero-knowledge proof capabilities. This is currently a draft PR under review.
- [#19388](https://github.com/ethereum-optimism/optimism/pull/19388)

### `op-supernode` Stability Improvement
A bug in `op-supernode` was fixed where `VerifiedBlockAtL1` would incorrectly iterate with a zero `FinalizedL1` value during startup, leading to potential issues. The fix introduces an early return for this scenario.
- [#19405](https://github.com/ethereum-optimism/optimism/pull/19405)

### E2E Test Simplification for Output Games
The process of creating output games in end-to-end tests has been simplified by automatically deriving the `rootClaim` parameter. This change removes the need to manually specify `rootClaim` in several test functions and introduces options for invalid or custom output roots.
- [#19294](https://github.com/ethereum-optimism/optimism/pull/19294)
