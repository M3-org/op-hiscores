# ethereum-optimism/optimism Daily Update (May 16, 2026)
## OVERVIEW 
Today's development focused on enhancing documentation for node operators, specifically adding a configuration guide for op-supernode. Two new pull requests were opened, and one issue related to network configuration was closed. A new critical issue regarding a potential state-persistent partial DoS was also reported.

## KEY TECHNICAL DEVELOPMENTS

### Documentation for Node Operators
A new configuration guide for `op-supernode` was added, providing essential information for node operators deploying it as the consensus layer. This enhancement improves the discoverability of `op-supernode` documentation for its target audience. ([#20748](https://github.com/ethereum-optimism/optimism/pull/20748))

## NEWLY OPENED PULL REQUESTS
- A pull request was opened to disallow renouncing `SystemConfig` ownership, which could be a security-related change. ([#20819](https://github.com/ethereum-optimism/optimism/pull/20819))
- Another pull request was opened to update clock and air gap defaults within the proofs system. ([#20818](https://github.com/ethereum-optimism/optimism/pull/20818))

## CLOSED ISSUES

### Network Configuration Resolution
The issue regarding "base-mainnet" not being present in `op-node` networks was closed. The user initially reported that `base-mainnet` was missing in `op-node` v1.18.0 and had to downgrade to v1.17.0 to resolve it. The issue was closed after the user confirmed they were able to run `reth` and a consensus node using the base repo. ([#20810](https://github.com/ethereum-optimism/optimism/issues/20810))

## NEW ISSUES

### Potential State-Persistent Partial DoS Vulnerability
A new issue was opened detailing a potential state-persistent partial DoS vulnerability in `OptimismPortal2`. This vulnerability could occur via high-gas deposits where the `ResourceMetering` gas burn exceeds the L1 block gas limit. The disclosure was made public after prior discussion with OP Labs security. ([#20820](https://github.com/ethereum-optimism/optimism/issues/20820))
