# ethereum-optimism/optimism Daily Update (Jan 16, 2026)
## OVERVIEW 
Today's development focused on enhancing interop testing with EIP-2935, improving `op-supernode` metrics, and updating Kona dependencies. A significant number of new issues were opened to track L2 contract upgrades.

## KEY TECHNICAL DEVELOPMENTS

### Interoperability Testing and EIP-2935 Integration
A new interop program was added to `op-e2e` to verify canonical data for blocks far behind the current tip, utilizing EIP-2935 for sublinear lookups. This ensures efficient historical block queries, crucial for the interop program's functionality.
- Added interop program utilizing EIP-2935 action test ([#18781](https://github.com/ethereum-optimism/optimism/pull/18781))

### `op-supernode` Metrics Enhancement
The `op-supernode` now multiplexes metrics by `chain_id` labels and serves them at a single endpoint, improving how virtual node metrics are handled and simplifying scraping.
- Multiplexed `op-supernode` metrics by `chain_id` label and served at a single endpoint ([#18750](https://github.com/ethereum-optimism/optimism/pull/18750))

### Kona Dependency Updates
Dependencies for Kona were updated, and the latest changes from the `op-rs/kona` repository were pulled into the monorepo.
- Updated Kona dependencies ([#18813](https://github.com/ethereum-optimism/optimism/pull/18813))
- Pulled latest changes from Kona ([#18802](https://github.com/ethereum-optimism/optimism/pull/18802))
