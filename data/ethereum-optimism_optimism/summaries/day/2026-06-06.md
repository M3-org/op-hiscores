# ethereum-optimism/optimism Daily Update (Jun 6, 2026)
## OVERVIEW 
Today's development focused on updating documentation to remove stale references and enhancing testing infrastructure by switching to op-reth for sequencing in acceptance tests, reflecting the deprecation of op-geth.

## KEY TECHNICAL DEVELOPMENTS

### Documentation Updates for op-reth
Documentation was updated to remove outdated references to `--proofs-history.prune-interval` in op-reth, ensuring accuracy for node operators. ([#20937](https://github.com/ethereum-optimism/optimism/pull/20937))

### Enhanced Testing with op-reth
The acceptance test suite was updated to sequence on op-reth for Karst+ blocks, deprecating op-geth which no longer supports building or importing these blocks. This ensures continued robust testing of the Superchain. ([#21188](https://github.com/ethereum-optimism/optimism/pull/21188))

## NEWLY OPENED PULL REQUESTS
- A new pull request [#21269](https://github.com/ethereum-optimism/optimism/pull/21269) was opened to fix Kona host witness fetches by retrying via the `get_preimage` loop instead of `debug_dbGet`.
- Another pull request [#21268](https://github.com/ethereum-optimism/optimism/pull/21268) was opened to address an issue in op-challenger by tearing down the VM process group on timeout.

The issue concerning the switch to op-reth-only sequencing for Karst+ in op-acceptance-tests has been closed. This reflects the deprecation of op-geth for these blocks. ([#21182](https://github.com/ethereum-optimism/optimism/issues/21182))
