# ethereum-optimism/optimism Daily Update (Apr 9, 2026)

## OVERVIEW 
Today's development focused on infrastructure improvements, including CircleCI configuration updates and the removal of the `OptimismPortalInterop` contract. A dependency bump for `op-geth` was also completed.

## KEY TECHNICAL DEVELOPMENTS

### Infrastructure and CI/CD Enhancements
Updates were made to the CircleCI workflow to include a `circleci-api-token` context for specific jobs, enhancing CI/CD capabilities [#19960](https://github.com/ethereum-optimism/optimism/pull/19960).

### Contract Refactoring and Cleanup
The `OptimismPortalInterop` contract and all its associated references were deleted, streamlining the codebase [#19956](https://github.com/ethereum-optimism/optimism/pull/19956).

### Dependency Updates
The `op-geth` dependency was bumped to version `v1.101702.1-rc.1` [#19992](https://github.com/ethereum-optimism/optimism/pull/19992).

## NEWLY OPENED PULL REQUESTS
Thirteen new pull requests were opened today, covering a range of fixes, features, and documentation updates. These include fixes for L2CM audit findings [#20007](https://github.com/ethereum-optimism/optimism/pull/20007), Kona-related fixes for L1 origin timestamp and precompile versions [#20004](https://github.com/ethereum-optimism/optimism/pull/20004), [#20003](https://github.com/ethereum.optimism/optimism/pull/20003), and an error handling improvement for unknown batch types [#20000](https://github.com/ethereum-optimism/optimism/pull/20000). New features include block builder failsafe and interop filter integration for `op-reth` [#20001](https://github.com/ethereum-optimism/optimism/pull/20001), a `rollup_config_override` feature for custom max sequencer drift [#19994](https://github.com/ethereum-optimism/optimism/pull/19994), and component release check scripts [#19991](https://github.com/ethereum-optimism/optimism/pull/19991). Documentation was updated with a deprecation notice for Req/Res CL sync [#19998](https://github.com/ethereum-optimism/optimism/pull/19998).

## CLOSED ISSUES

The issue tracking the deletion of the `OptimismPortalInterop` contract was closed today [#19709](https://github.com/ethereum-optimism/optimism/issues/19709). This task involved removing the contract, its interface, tests, and all references after its features were merged into `OptimismPortal2`.
