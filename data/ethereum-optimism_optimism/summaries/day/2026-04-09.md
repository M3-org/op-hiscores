# ethereum-optimism/optimism Daily Update (Apr 9, 2026)
## OVERVIEW 
Today's development focused on infrastructure improvements, including CircleCI configuration updates and dependency bumps, alongside significant progress in contract cleanup with the deletion of `OptimismPortalInterop`.

## KEY TECHNICAL DEVELOPMENTS

### Infrastructure & Dependency Updates
A CircleCI workflow was updated to include a necessary API token for specific jobs, enhancing CI/CD processes [#19960](https://github.com/ethereum-optimism/optimism/pull/19960). Additionally, the `op-geth` dependency was bumped to `v1.101702.1-rc.1` [#19992](https://github.com/ethereum-optimism/optimism/pull/19992).

### Contract Refactoring and Cleanup
The `OptimismPortalInterop` contract and all its references were deleted, streamlining the codebase and removing deprecated components [#19956](https://github.com/ethereum-optimism/optimism/pull/19956). This involved extensive changes across `contracts-bedrock` and `op-deployer/pkg`.
