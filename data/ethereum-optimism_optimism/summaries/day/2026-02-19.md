# ethereum-optimism/optimism Daily Update (Feb 19, 2026)
## OVERVIEW
Today's development focused on refining interop message handling, enhancing testing for cross-chain messages, and updating core dependencies, alongside significant infrastructure improvements for Rust binaries and Supernode configuration.

## KEY TECHNICAL DEVELOPMENTS

### Interop Message Handling Refinements
The DSL for interop message handling was refactored to introduce dedicated `InitMessage` and `ExecMessage` structs, improving API ergonomics and type safety. This change streamlines how interop messages are managed within the system. ([#19227](https://github.com/ethereum-optimism/optimism/pull/19227))

### Enhanced Interop Message Testing
New acceptance tests were added to validate interop messages, including migrating existing fault proof tests to the acceptance test suite and enabling Kona-proofs. This strengthens the robustness of cross-chain message validation. ([#19229](https://github.com/ethereum-optimism/optimism/pull/19229))

### Core Dependency and Infrastructure Updates
Several updates were made to core dependencies, including updating to Reth 1.11.0 and releasing op-reth v1.11.0. Additionally, the CI/CD pipeline was improved to post Rust binary Docker images to GCP, and the Supernode's interop activation timestamp handling was updated to use pointers for better differentiation. ([#19240](https://github.com/ethereum-optimism/optimism/pull/19240), [#19247](https://github.com/ethereum-optimism/optimism/pull/19247), [#19246](https://github.com/ethereum-optimism/optimism/pull/19246), [#19244](https://github.com/ethereum-optimism/optimism/pull/19244))
