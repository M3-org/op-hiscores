# ethereum-optimism/optimism Daily Update (Apr 20, 2026)
## OVERVIEW 
Today's development focused on enhancing Superchain interoperability with new log backfill features and critical bug fixes for Kona's `CrossL2Inbox` deployment. Significant CI/CD improvements were also implemented, alongside progress in fault proof testing.

## KEY TECHNICAL DEVELOPMENTS

### Superchain Interoperability & Supernode Enhancements
- Introduced a new feature in `op-supernode` to enable interop log backfill depth and validation gating, allowing pre-ingestion of logs from a specified depth to the local safe head. This includes new configuration options and logic for timestamp-to-block number conversion. ([#19973](https://github.com/ethereum-optimism/optimism/pull/19973))

### Kona Bug Fixes for Interop Activation
- Resolved a state divergence issue in Kona by conditionally deploying `CrossL2Inbox` transactions based on the number of dependent chains, ensuring consistency with `op-node` during single-chain Interop activation. ([#20147](https://github.com/ethereum-optimism/optimism/pull/20147))
- Fixed an error in the Kona proof driver where `is_interop_active()` was incorrectly passed a block number instead of a block timestamp, which could lead to premature Interop activation. ([#20162](https://github.com/ethereum-optimism/optimism/pull/20162))

### CI/CD and Testing Infrastructure Improvements
- Pinned the `mise` version in the `docker-build-prep` GitHub Action to prevent build failures related to `just` installation. ([#20170](https://github.com/ethereum-optimism/optimism/pull/20170))
- Refactored CircleCI configuration to streamline gate jobs, replacing multiple `ci-gate-skip` jobs with a single, always-succeeding `ci-gate` job. ([#20190](https://github.com/ethereum-optimism/optimism/pull/20190))
- Unmarked several Interop fault proof tests as flaky, indicating improved stability and reliability of these tests. ([#20159](https://github.com/ethereum-optimism/optimism/pull/20159))
- Added a GitHub Actions workflow to verify the provenance attestation of the `ci-base-clang` image, enhancing supply chain security for Rust jobs. ([#20171](https://github.com/ethereum-optimism/optimism/pull/20171))
- Updated `op-acceptance-tests` to allow overriding `-count` and `-timeout` parameters in `just test` commands, providing more flexibility for test execution and flake triage. ([#20161](https://github.com/ethereum-optimism/optimism/pull/20161))
- Pinned the `ci-base-clang` image for Rust jobs in CircleCI and removed runtime `apt-install` steps, improving build consistency and speed. ([#20135](https://github.com/ethereum-optimism/optimism/pull/20135))
