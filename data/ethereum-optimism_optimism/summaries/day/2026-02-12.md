## ACTIVE ISSUES
### Kona Hint Format Discussion
Discussion continues on [#19125](https://github.com/ethereum-optimism/optimism/issues/19125) regarding changing the Kona hint format from string serialization to a binary format. The primary motivation is to "make things right" rather than solely for performance, though performance improvements are anticipated. A key challenge is maintaining backward compatibility, as the host program must continue to support string versions for existing games. The proposer is open to approaches that preserve compatibility.

### Multiple Sequencer RPC Endpoints for Transaction Forwarding
The discussion on [#763](https://github.com/ethereum-optimism/optimism/issues/763) revolves around supporting multiple sequencer RPC endpoints for `op-geth` with automatic failover. While some argue for infrastructure-level redundancy as ideal, the proponent highlights that even shared CDN layers can fail, and this change adds optional client-side failover for defense-in-depth. The proposed change is fully backward compatible and aims to prevent user-facing outages caused by single endpoint failures.
