# ethereum-optimism/optimism Daily Update (Jan 27, 2026)
## OVERVIEW 
Today's development focused on significant feature additions, including core filtering logic for interop, withdrawal command updates for super proposals, and the migration of `alloy-op-evm` and `op-reth` to the monorepo.

## KEY TECHNICAL DEVELOPMENTS

### Interoperability and Withdrawal Enhancements
- Implemented core filtering logic for `op-interop-filter` to enhance cross-chain interactions ([#18604](https://github.com/ethereum-optimism/optimism/pull/18604)).
- Updated the withdrawal command to support proving withdrawals using specific output roots in super proposals, removing the need for a supervisor-rpc ([#18733](https://github.com/ethereum-optimism/optimism/pull/18733)).
- Established a basic pattern for Interop Activity within `op-supernode` ([#18728](https://github.com/ethereum-optimism/optimism/pull/18728)).

### Monorepo Migrations and Integrations
- Ported `alloy-op-evm` to the monorepo, including CI migration ([#18826](https://github.com/ethereum-optimism/optimism/pull/18826)).
- Migrated `op-reth` to the monorepo, following a similar pattern to previous migrations ([#18917](https://github.com/ethereum-optimism/optimism/pull/18917)).
- Integrated `op-validator` with `op-deployer` for automatic validation after deployments ([#18934](https://github.com/ethereum-optimism/optimism/pull/18934)).

### Supernode and Proposer Updates
- Updated `op-supernode` chain container interfaces, including changes to `SafeBlockAtTimestamp` and removal of SafeDB accessors ([#18727](https://github.com/ethereum-optimism/optimism/pull/18727)).
- Added support for fetching proposals via `op-supernode` RPC in `op-proposer`, initially for programmatic configuration ([#18940](https://github.com/ethereum-optimism/optimism/pull/18940)).

## CLOSED ISSUES

### System Configuration and Monorepo Migration
- The allowance for `SystemConfig::isCustomGasToken` override for OPCMv2 has been removed ([#18502](https://github.com/ethereum-optimism/optimism/issues/18502)). This was a temporary measure until U18 ships.
