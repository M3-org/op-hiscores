# ethereum-optimism/optimism Daily Update (Apr 29, 2026)
## OVERVIEW 
Today's development focused on enhancing the `op-conductor`'s leader election mechanism, integrating post-execution block processing and SDM warming inspectors in `alloy-op-evm`, and refining interop configuration. Significant bug fixes addressed `kona`'s chain list and dependency loading, and `op-supernode`'s interop startup. Documentation was updated to reflect `op-geth` decoupling and interop architecture changes.

## KEY TECHNICAL DEVELOPMENTS

### Enhanced Conductor Leadership and EVM Processing
The `op-conductor` now includes an optional round-robin leader transfer mechanism to improve leader loop switching ([#18697](https://github.com/ethereum-optimism/optimism/pull/18697)). Concurrently, `alloy-op-evm` received a significant feature addition with a post-execution block executor and an SDM warming inspector, impacting various `op-reth` and `kona` components ([#20213](https://github.com/ethereum-optimism/optimism/pull/20213)).

### Interoperability Configuration and Bug Fixes
A new `UseL2CM` toggle was added to `interopgen.L2Config` to thread into `devFeatureBitmapForL2Genesis`, enabling better control over L2 Contract Manager features ([#20433](https://github.com/ethereum-optimism/optimism/pull/20433)). Several critical bugs related to `kona`'s chain list and dependency set loading were resolved, ensuring alignment with registry data and proper interop functionality ([#20406](https://github.com/ethereum-optimism/optimism/pull/20406), [#20377](https://github.com/ethereum-optimism/optimism/pull/20377), [#20417](https://github.com/ethereum-optimism/optimism/pull/20417)). Additionally, `op-supernode` now requires `SafeDB-ready` interop startup, improving stability ([#20407](https://github.com/ethereum-optimism/optimism/pull/20407)).

### Monorepo Refactoring and Documentation Updates
Efforts to decouple `op-geth` dependencies continued with the extraction of `superchain` and `eip1559` packages into `op-core` ([#20314](https://github.com/ethereum-optimism/optimism/pull/20314), [#20312](https://github.com/ethereum-optimism/optimism/pull/20312)). Documentation was updated to reflect the `op-geth` decoupling analysis ([#19767](https://github.com/ethereum-optimism/optimism/pull/19767)) and to remove outdated `op-supervisor` references from interop guides ([#20302](https://github.com/ethereum-optimism/optimism/pull/20302)).
