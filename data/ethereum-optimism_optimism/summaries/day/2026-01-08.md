# ethereum-optimism/optimism Daily Update (Jan 8, 2026)
## OVERVIEW 
Today's development focused on critical bug fixes in the batcher, significant cleanup by removing unused Asterisc contracts, and a migration of the dispute monitor to new supernode APIs, enhancing the Superchain ecosystem's robustness.

## KEY TECHNICAL DEVELOPMENTS

### Batcher Stability and Compression Improvements
A critical bug in the `op-batcher` was fixed, addressing an issue where the batcher would submit empty batches in a loop when using shadow compressor and Brotli. This fix improves the stability and efficiency of batch submission.
- Fixes: [#18485](https://github.com/ethereum-optimism/optimism/pull/18485)

### Superchain Interoperability and Dispute Monitoring
The `op-dispute-mon` component was updated to utilize `op-supernode` instead of `op-supervisor` for super roots. This change aligns with ongoing efforts to enhance cross-chain interoperability and improve the dispute game mechanism within the Superchain.
- Updates: [#18711](https://github.com/ethereum-optimism/optimism/pull/18711)

### Codebase Cleanup and Maintenance
Unused Asterisc contracts and their associated deployment scripts were removed from the codebase. This cleanup reduces technical debt and streamlines the project by eliminating components that are no longer planned for deployment. Additionally, git submodules were standardized to use HTTPS for consistency.
- Removals: [#18689](https://github.com/ethereum-optimism/optimism/pull/18689)
- Infrastructure: [#18690](https://github.com/ethereum-optimism/optimism/pull/18690)

## NEWLY OPENED PULL REQUESTS
