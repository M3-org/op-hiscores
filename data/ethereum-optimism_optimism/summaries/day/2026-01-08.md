# ethereum-optimism/optimism Daily Update (Jan 8, 2026)
## OVERVIEW 
Today's development focused on critical bug fixes in the op-batcher, significant cleanup by removing unused Asterisc contracts, and a migration of op-dispute-mon to supernode APIs, enhancing the Superchain ecosystem's infrastructure.

## KEY TECHNICAL DEVELOPMENTS

### Batcher Stability and Compression Improvements
A critical bug in the `op-batcher` was fixed, addressing an issue where the batcher would submit empty batches in a loop when using shadow compressor and Brotli. This fix improves the stability and efficiency of batch submission.
- [#18485](https://github.com/ethereum-optimism/optimism/pull/18485)

### Infrastructure Modernization and Cleanup
Significant work was done to remove the Asterisc contracts and associated deployment scripts, as they are no longer planned for use. Additionally, git submodules were standardized to use HTTPS for consistency. The `op-dispute-mon` component was also updated to utilize `op-supernode` instead of `op-supervisor` for super roots, reflecting ongoing architectural improvements.
- [#18689](https://github.com/ethereum-optimism/optimism/pull/18689)
- [#18690](https://github.com/ethereum-optimism/optimism/pull/18690)
