# ethereum-optimism/optimism Daily Update (Mar 10, 2026)
## OVERVIEW
Today's development focused on enhancing CI/CD pipelines for Rust components, fixing critical bugs related to EIP-4844 transactions and sequencer selection, and scaffolding for Kona as the default game type. Several clean-up tasks and new feature developments were also initiated.

## KEY TECHNICAL DEVELOPMENTS

### CI/CD Pipeline Enhancements and Rust Integration
Significant work was done to improve the CI/CD pipeline, particularly for Rust-based components. This included adding required gate jobs for Rust CI [#19453](https://github.com/ethereum-optimism/optimism/pull/19453), running acceptance tests against the Rust stack (Kona/op-reth) [#19222](https://github.com/ethereum-optimism/optimism/pull/19222), and optimizing CI by skipping `kona-build-release` when no Rust files are changed [#19459](https://github.com/ethereum-optimism/optimism/pull/19459). A fix was also implemented for a `SIGPIPE` error in the `kona-build-release` skip logic [#19467](https://github.com/ethereum-optimism/optimism/pull/19467).

### Bug Fixes in Derivation and Devstack
Several critical bugs were addressed, including accepting EIP-4844 type-3 batcher transactions in `CalldataSource` within Kona's derive module [#19355](https://github.com/ethereum-optimism/optimism/pull/19355). The `op-devstack` was fixed to correctly select the sequencer EL node in flashblocks presets [#19458](https://github.com/ethereum-optimism/optimism/pull/19458). Additionally, a fix was implemented to capture `vm-compat` findings JSON as a CI artifact, preventing truncation of important analysis data [#19442](https://github.com/ethereum-optimism/optimism/pull/19442).

### Kona Default Game Type Scaffolding and Clean-up
Initial scaffolding was added to make Kona the default respected game type [#19117](https://github.com/ethereum-optimism/optimism/pull/19117). Alongside this, dead code related to `EthereumDataSourceVariant` was removed from Kona's derive module [#19341](https://github.com/ethereum-optimism/optimism/pull/19341), and remnants of `kona-supervisor` were removed from the codebase [#19470](https://github.com/ethereum-optimism/optimism/pull/19470).

## CLOSED ISSUES

### Kona Codebase Cleanup
The issue regarding the orphaned `sources/variant.rs` file in `kona-derive` [#19340](https://github.com/ethereum-optimism/optimism/issues/19340), which referenced a non-existent `AsyncIterator` and stale API, has been closed. This cleanup task was identified and addressed to remove dead code.

### EIP-4844 Transaction Handling Fix
A critical finding where `CalldataSource` silently dropped EIP-4844 (type 3) batcher transactions pre-Ecotone [#19352](https://github.com/ethereum-optimism/optimism/issues/19352) has been resolved. This issue, identified as consensus-critical, was fixed to ensure proper handling of these transaction types.

## NEW ISSUES

### Legacy Interface Calls in L2ContractsManager
A new issue has been opened to address the removal of legacy interface methods in `_loadFullConfig()` within `L2ContractsManager` [#19468](https://github.com/ethereum-optimism/optimism/issues/19468). These methods are currently used for compatibility with production predeploys and should be updated after the Karst Upgrade.
