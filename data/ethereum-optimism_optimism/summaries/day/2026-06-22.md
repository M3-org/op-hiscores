# ethereum-optimism/optimism Daily Update (Jun 22, 2026)
## OVERVIEW 
Today, significant progress was made with the integration of experimental zkVM-based fault proofs for OP Stack state transitions. Several bug fixes were implemented across contracts and documentation, and the Go toolchain was updated.

## KEY TECHNICAL DEVELOPMENTS

### zkVM-based Fault Proofs Integration
- Integrated **kona-sp1**, an experimental zkVM-based fault proof system for OP Stack state transitions, into the monorepo under `rust/kona/sp1/` ([#21489](https://github.com/ethereum-optimism/optimism/pull/21489)).

### Contract and Protocol Enhancements
- Fixed the `VerifyOPCM_Run_Test.test_runSingle_succeeds` to ensure Super dispute game contracts are only skipped when the Super-root games feature is disabled ([#21393](https://github.com/ethereum-optimism/optimism/pull/21393)).
- Bumped the `brotli-decompressor` version to `5.0.1` in Kona protocol to resolve a missing `br` fix ([#21505](https://github.com/ethereum-optimism/optimism/pull/21505)).

### Developer Tooling and Infrastructure Updates
- Enabled `superchain-configs` for `reth-optimism-evm` tests to fix compilation errors ([#21497](https://github.com/ethereum-optimism/optimism/pull/21497)).
- Decoupled the monorepo from `op-geth`'s `superchain` Go package, making `op-core/superchain` the sole superchain package ([#21487](https://github.com/ethereum-optimism/optimism/pull/21487)).
- Updated the Go toolchain to `1.26.4` across `mise.toml`, `go.mod`, and Go Docker images, and fixed related documentation ([#21452](https://github.com/ethereum-optimism/optimism/pull/21452)).
- Ported `op-reth`'s superchain-config archive generation from bash to a Rust `build.rs` and decommitted the 9MB binary ([#21482](https://github.com/ethereum-optimism/optimism/pull/21482)).

### Documentation and Testing Improvements
- Consolidated multiple Mintlify bot release-notes PRs and fixed "Latest" tags in release documentation ([#21511](https://github.com/ethereum-optimism/optimism/pull/21511)).
- Refreshed release notes for `kona-client`, `kona-host`, and `proxyd`, adding v1.6.0 releases ([#21509](https://github.com/ethereum-optimism/optimism/pull/21509)).
- Documented the `op-core/superchain` bundle build/CI prerequisite for `//go:embed`ed `superchain-configs.zip` ([#21496](https://github.com/ethereum-optimism/optimism/pull/21496)).
- Added a unit test in `reth-optimism-evm` to construct, execute, and verify an EIP-1559 value transfer on `OP_DEV` ([#21204](https://github.com/ethereum-optimism/optimism/pull/21204)).
