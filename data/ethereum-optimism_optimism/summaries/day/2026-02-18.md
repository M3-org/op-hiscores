# ethereum-optimism/optimism Daily Update (Feb 18, 2026)
## OVERVIEW 
Today's development focused on significant updates to `op-reth`, including porting historical proofs and updating dependencies. Key bug fixes addressed interop header lookup and CI workflow issues. Progress was also made on `op-supernode` wiring and blob handling in `kona`.

## KEY TECHNICAL DEVELOPMENTS

### `op-reth` Enhancements and Dependency Updates
A major feature was added to `op-reth` by porting historical proofs from `op-rs/op-reth` ([#19191](https://github.com/ethereum-optimism/optimism/pull/19191)). This involved a substantial update to `reth` to revision `2c5d00f` and bumping Alloy dependencies ([#19194](https://github.com/ethereum-optimism/optimism/pull/19194), [#19237](https://github.com/ethereum-optimism/optimism/pull/19237)).

### Interoperability and Supernode Improvements
Bug fixes were implemented for `kona-proofs` to correctly handle interop header_by_number lookups for blocks within the current history window ([#19230](https://github.com/ethereum-optimism/optimism/pull/19230)). Additionally, `op-supernode` saw wiring updates for `superAuthority` ([#19110](https://github.com/ethereum-optimism/optimism/pull/19110)), and `kona` removed `IndexedBlobHash` usage to simplify blob handling ([#19081](https://github.com/ethereum-optimism/optimism/pull/19081)).

### CI and Testing Infrastructure
A critical bug in the CI workflow was fixed, addressing incorrect references to prestate builds in the Rust workflow ([#19228](https://github.com/ethereum-optimism/optimism/pull/19228)). A new test was added to `devstack` to verify interop Fault Proofs trace extension activation ([#19221](https://github.com/ethereum-optimism/optimism/pull/19221)).

## NEW ISSUES

### Interop Upgrade Transactions Migration
A new issue has been opened to migrate Interop upgrade transactions to the NUT bundle approach ([#19239](https://github.com/ethereum-optimism/optimism/issues/19239)). This migration is necessary to account for upgrade gas, as Interop currently uses a legacy hardcoded upgrade transaction pattern.

## ACTIVE ISSUES

### `op-reth` Database Read Transaction Memory Leak
The issue [#19212](https://github.com/ethereum-optimism/optimism/issues/19212) reports that `op-reth` is experiencing a memory leak due to database read transactions remaining open for too long. This issue is actively affecting Base mainnet archive nodes, causing them to consume all available memory. The latest comment confirms that this problem is recurring across all affected nodes.
