# ethereum-optimism/optimism Daily Update (Mar 17, 2026)
## OVERVIEW 
Today's development focused heavily on stabilizing the Optimism ecosystem by addressing numerous flaky tests and refining core components. Key efforts included fixing race conditions in interop tests, hardening the `RetryProxy`, and improving supernode stability.

## KEY TECHNICAL DEVELOPMENTS

### Supernode Stability and Interoperability Fixes
Several critical bug fixes were implemented to enhance the stability and correctness of the `op-supernode`. These include preventing synthetic payload rejections during engine rewinds ([#19605](https://github.com/ethereum-optimism/optimism/pull/19605)), resolving shutdown hangs due to Start/Stop races ([#19576](https://github.com/ethereum-optimism/optimism/pull/19576)), and ensuring all chains' virtual nodes are frozen before invalidation rewinds to prevent race conditions ([#19571](https://github.com/ethereum-optimism/optimism/pull/19571)).

### Flaky Test Stabilization Across Components
A significant portion of the day's work involved addressing and fixing numerous flaky tests across various Optimism components. This included resolving nonce race conditions in `op-e2e` interop action tests ([#19595](https://github.com/ethereum-optimism/optimism/pull/19595)), stabilizing `TestImplementations` by hardening `RetryProxy` timeouts ([#19593](https://github.com/ethereum-optimism/optimism/pull/19593)), fixing `TestBreakTimestampInvariant` by ensuring proper sync propagation ([#19585](https://github.com/ethereum-optimism/optimism/pull/19585)), and stabilizing `TestSubProcess` in `op-devstack` ([#19580](https://github.com/ethereum-optimism/optimism/pull/19580)). The `op-batcher` also saw a fix for the flaky `TestChannelManager_Memory` ([#19579](https://github.com/ethereum-optimism/optimism/pull/19579)).

### CI/CD and Build System Improvements
Efforts were made to improve the CI/CD pipeline and build processes. This included storing JUnit results as artifacts for better test failure debugging ([#19581](https://github.com/ethereum-optimism/optimism/pull/19581)), migrating the `op-deployer` Docker build to GitHub Actions ([#19530](https://github.com/ethereum-optimism/optimism/pull/19530)), and migrating `rust/op-reth` Makefiles to `just` ([#19525](https://github.com/ethereum-optimism/optimism/pull/19525), [#19596](https://github.com/ethereum-optimism/optimism/pull/19596)). Additionally, JUnit XML test results are now captured for rust-e2e jobs ([#19548](https://github.com/ethereum-optimism/optimism/pull/19548)).

### EVM Code Refactoring
The EVM code saw a significant refactoring effort, moving OP-specific EVM implementations into newtypes within `alloy-op-evm`. This involved introducing `OpTx` and `OpTxError` wrappers and relocating spec ID mapping and `EvmEnv` constructors ([#19536](https://github.com/ethereum-optimism/optimism/pull/19536)).

## CLOSED ISSUES

### Flaky Test Resolution
Several long-standing flaky tests were investigated and closed today. This includes `TestBreakTimestampInvariant` ([#18137](https://github.com/ethereum-optimism/optimism/issues/18137)), which had two independent flake causes related to nonce races and missing sync propagation. `TestExpiredMessage` ([#19588](https://github.com/ethereum-optimism/optimism/issues/19588)) and `TestExecMsgDifferTxIndex` ([#19589](https://github.com/ethereum-optimism/optimism/issues/19589)) were also closed, both attributed to nonce race conditions. `TestImplementations` ([#19583](https://github.com/ethereum-optimism/optimism/issues/19583)) and `TestSubProcess` ([#19587](https://github.com/ethereum-optimism/optimism/issues/19587)) were closed after fixes to their underlying race conditions and timeouts. `TestChannelManager_Memory` ([#19590](https://github.com/ethereum-optimism/optimism/issues/19590)) was closed after a fix addressing memory allocation measurement.

### Supernode and Interop Enhancements
An issue regarding the `superroot_atTimestamp` API reporting derived L1 instead of verified L1 was closed ([#18651](https://github.com/ethereum-optimism/optimism/issues/18651)). Additionally, the `TestSupernodeSameTimestampCycle` flaky test was closed ([#19559](https://github.com/ethereum-optimism/optimism/issues/19559)), and a request to add a passthrough mode to the interop filter was completed and closed ([#19565](https://github.com/ethereum-optimism/optimism/issues/19565)).

### CI/CD and Build System Migrations
The migration of the `op-deployer` Docker build to GitHub Actions was successfully completed and the tracking issue closed ([#19208](https://github.com/ethereum-optimism/optimism/issues/19208)).

### Precompile and Blob Archiver Issues
An investigation into Glamsterdam gas pricing impacts on precompile acceleration was closed ([#19375](https://github.com/ethereum-optimism/optimism/issues/19375]), with further work tracked in a separate issue. A newly opened issue regarding the `blob-archiver` not supporting the `/eth/v1/beacon/blobs/` endpoint was quickly closed, with the problem identified as belonging to the `blob-archiver` repository ([#19623](https://github.com/ethereum-optimism/optimism/issues/19623)).
