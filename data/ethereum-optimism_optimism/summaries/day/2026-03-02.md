# ethereum-optimism/optimism Daily Update (Mar 2, 2026)
## OVERVIEW
Today's development focused on critical bug fixes across `op-supernode`, `op-interop-filter`, and `contracts-bedrock`, alongside enhancements to fault proof testing. Key improvements include performance optimizations for cross-validation and robust reorg recovery mechanisms.

## KEY TECHNICAL DEVELOPMENTS

### Supernode and Interop Filter Stability
Several bug fixes were implemented to enhance the stability and performance of the `op-supernode` and `op-interop-filter` components. This includes addressing an initial block seal issue in `op-supernode` ([#19308]), improving cross-validation performance, and refining reorg detection in `op-interop-filter` ([#19304]). A critical fix also ensures correct L1 inclusion block validation in `op-supernode` ([#19343]).

### Contracts and Kona Node Reliability
Improvements were made to the `contracts-bedrock` CI process by removing artifact pulling and utilizing unoptimized builds for tests, which resolves issues with stale artifacts and non-deterministic resolutions ([#19332]). For the `kona-node`, a fix was introduced to map `BlockNotFound` errors to `ResetError` for better reorg recovery, preventing indefinite stalling ([#19344]). Additionally, `kona/protocol/derive` now correctly handles "blob not found" scenarios to prevent safe head stalls ([#19328]).

### Enhanced Fault Proof Testing
New smoke tests were added to validate super fault proofs in single-chain interop and preinterop scenarios, utilizing `op-supernode` to ensure sanity checks for the dependency set containing only one L2 chain ([#19299]).

## CLOSED ISSUES

The issue concerning Flashblocks support within Geth ([#756]) has been closed due to the deprecation of `op-geth`, rendering the feature no longer relevant for the project.
