# ethereum-optimism/optimism Daily Update (Mar 11, 2026)
## OVERVIEW 
Today's development focused on critical bug fixes in the Kona derivation pipeline, refactoring acceptance tests for improved efficiency, and enhancing Supernode functionality. Several issues related to pipeline stability and P2P configuration were resolved.

## KEY TECHNICAL DEVELOPMENTS

### Kona Derivation Pipeline Stability Improvements
Significant progress was made in stabilizing the Kona derivation pipeline. This included fixing issues where blob under-fills caused critical errors, now returning a `Reset` error instead ([#19362](https://github.com/ethereum-optimism/optimism/pull/19362)). Bounds checks were added to span batch decode functions to prevent panics on truncated input ([#19361](https://github.com/ethereum-optimism/optimism/pull/19361)), and a critical fix ensured the `origin` field is copied during `BatchQueue` to `BatchValidator` transitions at Holocene activation ([#19360](https://github.com/ethereum-optimism/optimism/pull/19360)). Additionally, system config update failures in `L1Traversal` were made non-fatal ([#19358](https://github.com/ethereum-optimism/optimism/pull/19358)).

### Acceptance Testing and CI Enhancements
The `op-devstack` acceptance testing framework was refactored to simplify direct preset constructors and enable per-test isolated environments ([#19452](https://github.com/ethereum-optimism/optimism/pull/19452)). Manual pipeline dispatch in CI was also fixed by adding passthrough parameters, addressing issues introduced by a previous change ([#19462](https://github.com/ethereum-optimism/optimism/pull/19462)).

### Supernode and P2P Configuration Updates
The `op-challenger` vm runner was updated to replace the supervisor with the supernode, leveraging a new `superroot_syncStatus` RPC endpoint for aggregate sync status ([#19438](https://github.com/ethereum-optimism/optimism/pull/19438)). P2P configuration for supernode follow mode CLs was also added to `op-devstack` ([#19439](https://github.com/ethereum-optimism/optimism/pull/19439)).

### Kona Derivation Pipeline Bug Resolutions
Several critical bugs in the Kona derivation pipeline were addressed. This includes fixing a fatal error when system config updates failed ([#19353](https://github.com/ethereum-optimism/optimism/issues/19353)), ensuring the `origin` field is correctly copied during `BatchProvider` transitions ([#19356](https://github.com/ethereum-optimism/optimism/issues/19356)), and preventing permanent pipeline halts due to blob under-fills ([#19359](https://github.com/ethereum-optimism/optimism/issues/19359)).

### Supernode and P2P Functionality
Issues related to Supernode functionality and P2P connections were resolved. The `op-challenger` vm-runner was updated to utilize the Supernode ([#18669](https://github.com/ethereum-optimism/optimism/issues/18669)), and a new `SyncStatus` API was introduced for the `op-supernode` ([#18947](https://github.com/ethereum-optimism/optimism/issues/18947)). A fix was also implemented for L2 CL P2P connection in light CLs in follow-mode ([#19379](https://github.com/ethereum-optimism/optimism/issues/19379)).
