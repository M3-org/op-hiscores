# ethereum-optimism/optimism Daily Update (Aug 6, 2026)
## OVERVIEW 
Today's development focused on significant documentation enhancements, code refactoring for receipt handling, and various infrastructure improvements across the Optimism monorepo.

## KEY TECHNICAL DEVELOPMENTS

### Documentation Improvements & CLI Updates
Multiple documentation updates were implemented, including adding a fault proofs reference page, regenerating the `op-reth` CLI reference to v2.4.1, and correcting facts related to `kona-node` and `op-batcher` configurations. The `op-reth` CLI also saw the removal of the unsupported `--minimal` option, a breaking change.
[#21838](https://github.com/ethereum-optimism/optimism/pull/21838), [#22193](https://github.com/ethereum-optimism/optimism/pull/22193), [#22310](https://github.com/ethereum-optimism/optimism/pull/22310), [#22309](https://github.com/ethereum-optimism/optimism/pull/22309), [#22302](https://github.com/ethereum-optimism/optimism/pull/22302), [#22109](https://github.com/ethereum-optimism/optimism/pull/22109)

### Core Code Refactoring and Cleanup
Significant code refactoring was performed on `op-core`, `op-service`, and `op-chain-ops` to clean up receipt wrapping constructors and codecs, following reviews of the `op-geth` decoupling stack. Additionally, TODOs referencing an old issue in `op-node` were removed.
[#22295](https://github.com/ethereum-optimism/optimism/pull/22295), [#22292](https://github.com/ethereum-optimism/optimism/pull/22292)

### Infrastructure and Testing Enhancements
Improvements were made to the CI/CD pipeline, including paging protocol-oncall for `go-tests-full` develop failures and building the superchain bundle in `go-release`. `op-reth` e2e tests were updated to use `RUST_BINARY_PATH_OP_RETH`, and `busybox` and `apk-tools` were added to all APKO images for better debugging and package management.
[#22212](https://github.com/ethereum-optimism/optimism/pull/22212), [#22233](https://github.com/ethereum-optimism/optimism/pull/22233), [#22290](https://github.com/ethereum-optimism/optimism/pull/22290), [#22287](https://github.com/ethereum-optimism/optimism/pull/22287)

### Dispute Monitoring and Proposer Updates
The `op-dispute-mon` received an update to normalize fault bond snapshots, streamlining the monitoring process. The `kona-sp1-proposer` gained a fast finality mode, allowing it to prove games without waiting for a challenge, and its super root RPC configuration was renamed for clarity.
[#22226](https://github.com/ethereum-optimism/optimism/pull/22226), [#22173](https://github.com/ethereum-optimism/optimism/pull/22173), [#22308](https://github.com/ethereum-optimism/optimism/pull/22308)
