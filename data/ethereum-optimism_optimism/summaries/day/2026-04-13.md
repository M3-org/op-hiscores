# ethereum-optimism/optimism Daily Update (Apr 13, 2026)
## OVERVIEW 
Today's development focused on enhancing the `op-node` with EL-sync retraction capabilities, refining `op-core` and `op-deployer` for better dependency management, and addressing critical bug fixes in `kona` related to L2CM audit findings and precompile versions. Documentation was also improved, and new tests were added for the dispute game factory.

## KEY TECHNICAL DEVELOPMENTS

### Enhanced EL-Sync and Dependency Management
The `op-node` now includes a new feature to offset derived safe/finalized states during EL-sync, improving retraction capabilities and ensuring ancestor-based safety. Additionally, a new `devfeatures` package was added to `op-core`, resolving a cyclic dependency issue in `op-deployer`.
- [#19972](https://github.com/ethereum-optimism/optimism/pull/19972)
- [#19970](https://github.com/ethereum-optimism/optimism/pull/19970)

### Critical Bug Fixes for L2CM and Kona
Several important bug fixes were implemented, including addressing audit findings in the L2 Contracts Manager (L2CM) to ensure proper upgrade sequencing. `kona` received fixes to use the correct L1 origin timestamp for brotli activation checks, preventing consensus deviations, and to utilize accurate precompile versions for Jovian and post-Jovian specifications.

Documentation was updated to fix broken links and stale references across various files, including `CONTRIBUTING.md` and `README.md` files for `kontrol`, `kona`, and `op-reth`. A deprecation notice was also added to the `op-program` README, directing users to `kona-client`. New tests were introduced for the zk dispute game factory and registry, and existing superroot proofs tests were unskipped in `op-acceptance-tests`.
