# ethereum-optimism/optimism Daily Update (Mar 22, 2026)

## OVERVIEW 
Today's development focused on enhancing the reliability of acceptance tests by replacing time-based delays with deterministic block advancements. A new pull request addresses a MIPS64-specific bug, and a new issue offers free Base L2 developer APIs for testing.

## KEY TECHNICAL DEVELOPMENTS

### Enhanced Acceptance Test Reliability
Improvements were made to the `op-acceptance-tests` by replacing `time.Sleep` with deterministic block advancement in `UnsafeChainNotStalling` helpers, ensuring more reliable and consistent test execution. This change affects several test files related to `depreqres` and `syncmodereqressync`. ([#19683](https://github.com/ethereum-optimism/optimism/pull/19683))

## NEWLY OPENED PULL REQUESTS
A new pull request, [#19717](https://github.com/ethereum-optimism/optimism/pull/19717), was opened to fix a bug that masks `rs` to 32 bits before `clz/clo` count loops on MIPS64 architectures.
