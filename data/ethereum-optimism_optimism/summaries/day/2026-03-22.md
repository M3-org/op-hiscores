# ethereum-optimism/optimism Daily Update (Mar 22, 2026)
## OVERVIEW 
Today's development focused on enhancing the reliability of acceptance tests by replacing time-based delays with deterministic block advancements. New pull requests aim to improve test tracking and address MIPS64 architecture-specific fixes. A new issue was opened offering free Base L2 developer APIs for testing.

## KEY TECHNICAL DEVELOPMENTS

### Acceptance Test Reliability Improvements
Significant work was done to improve the reliability of acceptance tests. The `time.Sleep` function in `UnsafeChainNotStalling` helpers was replaced with deterministic `Advanced()` block counting, ensuring more consistent and reliable test execution. This change affects several test files within `op-acceptance-tests`. ([#19683](https://github.com/ethereum-optimism/optimism/pull/19683))

## NEWLY OPENED PULL REQUESTS

- A bug fix pull request, [#19717](https://github.com/ethereum-optimism/optimism/pull/19717), was opened to address an issue where `rs` needs to be masked to 32 bits before `clz`/`clo` count loops on MIPS64 architecture.
