# ethereum-optimism/optimism Daily Update (Feb 13, 2026)
## OVERVIEW 
Today's development focused on enhancing L2 deployment capabilities with a new conditional deployer, improving fault proof testing infrastructure, and unifying Rust documentation. Several new pull requests were opened, addressing various technical improvements and updates.

## KEY TECHNICAL DEVELOPMENTS

### Enhanced L2 Deployment and Interoperability
A significant feature was added to introduce a Conditional L2 Deployer, enabling non-reverting deterministic deployments even with address collisions during network upgrade transactions. This improves the robustness of L2 deployments within the Superchain ecosystem ([#18864](https://github.com/ethereum-optimism/optimism/pull/18864)).

### Improved Fault Proof Testing and Devstack
Efforts were made to port the `TestInteropFaultProofs` action test to a supernode devstack, enhancing the acceptance testing framework. This also involved restoring the Kona prestate build script for easier local development ([#19163](https://github.com/ethereum-optimism/optimism/pull/19163)). Additionally, a coordinated interop pause was added to the DSL for acceptance testing, allowing for more precise testing scenarios ([#19179](https://github.com/ethereum-optimism/optimism/pull/19179)).

### Rust Documentation and Build Process Streamlining
The documentation for Kona, op-reth, and op-alloy was unified into a single site, improving developer experience and accessibility ([#19101](https://github.com/ethereum-optimism/optimism/pull/19101)). The build process for Cannon was also optimized to use local monorepo sources instead of cloning a pinned tag, streamlining prestate generation for Kona ([#19183](https://github.com/ethereum-optimism/optimism/pull/19183)).
