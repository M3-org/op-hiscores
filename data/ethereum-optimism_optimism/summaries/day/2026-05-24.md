## ACTIVE ISSUES

### Flaky Test: `TestSupernodeResyncResumesAtActivation_PostActivation` ([#20944](https://github.com/ethereum-optimism/optimism/issues/20944))
The test continues to be flaky, with a new assertion failure related to the cold-start backfill producing a `firstSealedBlock.Timestamp` equal to `FirstVerifiableTimestamp()`, violating a strict-less-than handoff invariant. A draft fix has been proposed in PR [#21002](https://github.com/ethereum-optimism/optimism/pull/21002). The root cause was identified as `VerifiedBlockAtL1` and `LatestVerifiedL2Block` silently swallowing non-`ErrNotFound` errors, leading to the chain container interpreting transient unavailability as a cold-start. The fix involves propagating read errors and allowing `super_authority.FinalizedL2Head` / `FullyVerifiedL2Head` to signal fallback to locally-derived heads on verifier errors. Follow-up actions include addressing op-reth's acceptance of non-monotonic `forkchoiceUpdated` finalized blocks.

### Dev Tooling: Support for deployment factories ([#12](https://github.com/ethereum-optimism/optimism/issues/12))
Discussions are ongoing regarding the implementation of create-factory dependency recognition and build-time verification in the dependency graph system. The proposed approach involves three phases: research and schema design for a `FactoryDependency` link type, detection and indexing of factory-child relationships via transaction traces, and integration into the dependency graph with verification gates. Deliverables include a schema PR, a factory indexer, verification integration, documentation, and a test suite, with an estimated completion of 11 days.

### Onchain Builders: Expand user metrics beyond Farcaster IDs ([#13](https://github.com/ethereum-optimism/optimism/issues/13))
A concrete multi-source user metric proposal has been put forward, suggesting a blended user score incorporating attestation tiers (KYC-linked addresses), CEX-linked addresses, and organic onchain activity. Sybil resistance would be applied via graph clustering and minimum unique contract interactions. The approach involves researching and implementing data pipelines for these sources, building heuristic models for non-KYC users, and using Dune and Flipside for data aggregation. Deliverables include a research report, SQL queries, a Sybil heuristics script, and final recommendations, with an estimated completion of 5-7 days.
