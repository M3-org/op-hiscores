# ethereum-optimism/optimism Daily Update (Mar 14, 2026)
## OVERVIEW 
Today's development focused on a critical bug fix in the Kona derivation pipeline, ensuring system configuration update failures are non-fatal. Several new pull requests were opened, addressing CI improvements and dependency updates, alongside new issues for migrating Makefiles to justfiles and enhancing rust-e2e test reporting.

## KEY TECHNICAL DEVELOPMENTS

### Derivation Pipeline Stability
A critical bug in the Kona derivation pipeline was fixed, preventing system configuration update failures from halting the derivation process. This ensures the `StatefulAttributesBuilder` can gracefully handle such errors, improving the robustness of the protocol. ([#19503](https://github.com/ethereum-optimism/optimism/pull/19503))

## NEWLY OPENED PULL REQUESTS
Three new pull requests were opened today: one to split `ReorgTriggered` into exact and relaxed variants for `op-devstack` ([#19549](https://github.com/ethereum-optimism/optimism/pull/19549)), another to capture JUnit XML test results for rust-e2e CI jobs ([#19548](https://github.com/ethereum-optimism/optimism/pull/19548)), and a dependency bump for `pyjwt` in `/ops/check-changed` ([#19545](https://github.com/ethereum-optimism/optimism/pull/19545)).

## CLOSED ISSUES

### Kona Derivation Pipeline Bug Resolution
The issue concerning system configuration update errors in `StatefulAttributesBuilder` returning Critical instead of being ignored has been closed. This directly relates to the bug fix implemented today, making these failures non-fatal. ([#19512](https://github.com/ethereum-optimism/optimism/issues/19512))

## NEW ISSUES

### Build System Modernization
A new issue has been opened to migrate all Makefiles in the monorepo to justfiles, with existing Makefiles becoming deprecation shims that warn and forward to `just`. This aims to streamline the build process. ([#19546](https://github.com/ethereum-optimism/optimism/issues/19546))

### CI Test Reporting Enhancement
An issue was created to capture JUnit XML test results for rust-e2e CI jobs. This will provide per-test timing data and improve visibility into test performance and failures. ([#19547](https://github.com/ethereum-optimism/optimism/issues/19547))
