# ethereum-optimism/optimism Daily Update (Jan 11, 2026)

## OVERVIEW 
The day saw significant progress in the `optimism` repository with the removal of a Go 1.24 feature flag, enabling `SysGetRandom` support, and the addition of a configurable timeout for VM execution in the `op-challenger`.

## KEY TECHNICAL DEVELOPMENTS

### Cannon MIPSVM Enhancements
The `cannon/mipsevm` module received updates, including the removal of the `SupportWorkingSysGetRandom` feature flag, which permanently enables `SysGetRandom` support. This change streamlines the MIPSVM's interaction with system randomness. ([#18624](https://github.com/ethereum-optimism/optimism/pull/18624))

### VM Runner Stability Improvements
A configurable timeout has been added to the `vm-runner` within `op-challenger`. This enhancement prevents the runner from hanging indefinitely during VM execution, improving the stability and reliability of trace generation. ([#18594](https://github.com/ethereum-optimism/optimism/pull/18594))
