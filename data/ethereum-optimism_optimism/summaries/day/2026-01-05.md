### Interoperability and Dispute Game Interface Extension
Issue [#18516](https://github.com/ethereum-optimism/optimism/issues/18516) discusses extending the `IDisputeGame` interface to include `rootClaim(uint256 l2ChainId)`. The latest comments indicate that the issue was reopened by @ajsutton due to remaining TODOs in the code referencing it. @stevennevins has committed to addressing these outstanding items. This enhancement is crucial for future interoperability within the Superchain.

### L2 Reorg Due to L1 Reorg in Kona
Issue [#18676](https://github.com/ethereum-optimism/optimism/issues/18676) addresses a critical problem in Kona where L2 reorgs are not properly handled during L1 reorgs. @pcw109550 provided a detailed root cause analysis, identifying three key issues: L1 Origin Selector caching, missing L1 Canonical Validation at L1 Origin, and the lack of proper reset during block building in Kona compared to `op-node`. Possible fixes include strengthening Kona's L1 origin selector, adding unit tests for L1 inconsistency, revising reset logic, and enabling more comprehensive acceptance tests targeting Kona.

### `eth_simulatev1` Issue
Issue [#739](https://github.com/ethereum-optimism/optimism/issues/739) reports an `eth_simulatev1` issue returning "error calculating DA footprint: missing deposit transaction" since the Jovian fork. @RealJohnnyTime emphasized the criticality of this bug for backrunning strategies on OP Stack-based EVM chains. @ajsutton believes that https://github.com/ethereum-optimism/op-geth/pull/732 is intended to fix this problem.
