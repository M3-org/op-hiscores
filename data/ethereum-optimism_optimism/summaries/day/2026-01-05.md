## ACTIVE ISSUES

### L1 Reorg Handling in Kona Node
Discussion on [#18676](https://github.com/ethereum-optimism/optimism/issues/18676) highlighted several root causes for L2 reorgs due to L1 reorgs in the Kona node. The L1 Origin Selector was found to be caching stale values during L1 reorgs, and there's a lack of L1 canonical validation at the L1 Origin. Additionally, the Kona node lacks a proper reset mechanism during block building when L1 inconsistencies are detected, unlike `op-node`. Possible fixes include strengthening Kona's L1 origin selector to mirror `op-node`'s, adding unit tests for L1 inconsistency cases, revising Kona's reset logic, and enabling more monorepo acceptance tests targeting Kona.

### `eth_simulatev1` Issue
Issue [#739](https://github.com/ethereum-optimism/optimism/issues/739) continues to be active, with recent comments indicating that `eth_simulatev1` returns an error regarding a missing deposit transaction since the Jovian fork. This is critical for backrunning strategies on OP Stack-based EVM chains. A potential fix is being tracked in `op-geth` pull request [#732](https://github.com/ethereum-optimism/op-geth/pull/732).

### `IDisputeGame` Interface Extension
Issue [#18516](https://github.com/ethereum-optimism/optimism/issues/18516), concerning the addition of `rootClaim(uint256 l2ChainId)` to the `IDisputeGame` interface, was reopened. This is in preparation for interop to allow retrieval of the Claim for a particular L2 chain ID. The issue was reopened due to existing TODOs in the code referencing it, and work is underway to address these.
