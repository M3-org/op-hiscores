# ethereum-optimism/optimism Daily Update (Jan 14, 2026)
## OVERVIEW 
Today's development focused on enhancing testing for deployment processes, updating critical configuration parameters, and improving CI/CD reliability.

## KEY TECHNICAL DEVELOPMENTS

### Enhanced Deployment and OPChain Testing
Additional test cases and natspec comments were added for `DeployImplementations.s.sol` and `makeDCI` to ensure correct `DeployOPChainInput` generation and overall robustness of the deployment process. This work is captured in [#18725](https://github.com/ethereum-optimism/optimism/pull/18725).

### Configuration Updates and CI/CD Improvements
Critical updates were made to the fees depositor address and minimum withdrawal amounts, addressing a missing commit from a previous version. The CI configuration was also updated to retry snapshot clean tasks, improving build reliability. Additionally, `golangci-lint` was updated to v2, with new checks initially disabled to manage the upgrade process. These changes are detailed in [#18736](https://github.com/ethereum-optimism/optimism/pull/18736), [#18659](https://github.com/ethereum-optimism/optimism/pull/18659), and [#18778](https://github.com/ethereum-optimism/optimism/pull/18778).

### Code Quality and Security Checks
A new semgrep rule was introduced to enforce a consistent naming convention for immutable variables within `OPContractsManagerV2`, ensuring they are prefixed with `opcM` for better identification and integration with the `VerifyOPCM` script. This is documented in [#18679](https://github.com/ethereum-optimism/optimism/pull/18679).

## NEWLY OPENED PULL REQUESTS
Six new pull requests were opened today, primarily focusing on porting and integrating the Kona project, with [#18790](https://github.com/ethereum-optimism/optimism/pull/18790) and [#18789](https://github.com/ethereum-optimism/optimism/pull/18789) explicitly mentioning "Kona". Other PRs include [#18785](https://github.com/ethereum-optimism/optimism/pull/18785) to avoid fallback artifact downloads, a draft test for Kona surgery [#18783](https://github.com/ethereum-optimism/optimism/pull/18783), and two related to `op-e2e` for interop testing and fixing blob endpoints [#18781](https://github.com/ethereum-optimism/optimism/pull/18781), [#18780](https://github.com/ethereum-optimism/optimism/pull/18780).
