# ethereum-optimism/optimism Daily Update (Apr 24, 2026)
## OVERVIEW 
Today's development focused on significant feature additions to `op-node` and `op-reth`, including L2CM toggles and EIP-7910 support. Critical bug fixes addressed RPC timeouts and CI flakiness, alongside substantial work on interop testing and super dispute game coverage.

## KEY TECHNICAL DEVELOPMENTS

### Core Protocol Enhancements & Feature Toggles
New features were introduced to enhance the core protocol, including a L2CM feature toggle for the Karst NUT bundle in `op-node` ([#19888](https://github.com/ethereum-optimism/optimism/pull/19888)). Additionally, `op-reth` now registers the `eth_config` RPC endpoint (EIP-7910) ([#20158](https://github.com/ethereum-optimism/optimism/pull/20158)), and `op-revm` received an update to revm 38 ([#20300](https://github.com/ethereum-optimism/optimism/pull/20300)).

### Interoperability and Dispute Game Improvements
Significant progress was made in bolstering interoperability and dispute game functionality. This includes adding pre-genesis super dispute game coverage to `op-acceptance` tests ([#20287](https://github.com/ethereum-optimism/optimism/pull/20287)) and routing single-chain interop super-games through the `OPCMv2.upgrade` entrypoint ([#20248](https://github.com/ethereum-optimism/optimism/pull/20248)). A new test was also added to guard negotiated eth wire protocol versions in `op-reth` ([#20156](https://github.com/ethereum-optimism/optimism/pull/20156)).

### Stability and CI Reliability Fixes
Several bug fixes targeted system stability and CI reliability. The `op-reth` supervisor RPC timeout default was increased to 2 seconds to prevent flakiness ([#20296](https://github.com/ethereum-optimism/optimism/pull/20296)). The `op-devstack` preset CrossSafe budget was extended for ELSync mode ([#20343](https://github.com/ethereum-optimism/optimism/pull/20343)), and the `rust-doctest` CI job was upgraded to a `2xlarge` instance to prevent OOM errors ([#20337](https://github.com/ethereum-optimism/optimism/pull/20337)).
