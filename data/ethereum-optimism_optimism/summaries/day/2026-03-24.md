# ethereum-optimism/optimism Daily Update (Mar 24, 2026)

## OVERVIEW 
Today's development focused on critical bug fixes in Kona, enhancing testing for EIP-2935 and de-flaking existing tests, and infrastructure improvements for CI/CD. Several long-standing flaky tests were also closed after thorough investigation and confirmation of fixes.

## KEY TECHNICAL DEVELOPMENTS

### Kona Bug Fixes and Prestate Improvements
Two critical bugs in Kona were addressed, including a fix for the `kona-prestate` metadata file naming convention to ensure proper recognition by `vm-runner` ([#19732](https://github.com/ethereum-optimism/optimism/pull/19732)). Additionally, an incorrect `target-c-int-width` in the MIPS64 target specification was corrected from 64 to 32, overriding the baked-in target spec in `cannon-builder:v1.0.0` ([#19730](https://github.com/ethereum-optimism/optimism/pull/19730)).

### Enhanced Testing and CI/CD Stability
New tests were added to improve the robustness of Kona's proof interop, specifically a multi-iteration EIP-2935 test to cover cases where the target block is beyond the 8,191-block history window ([#19738](https://github.com/ethereum-optimism/optimism/pull/19738)). The `TestCLELDivergence` acceptance test was also de-flaked to improve CI reliability ([#19733](https://github.com/ethereum-optimism/optimism/pull/19733)). Furthermore, a new CI gate job was introduced to streamline and stabilize GitHub required status checks for the `develop` branch ([#19535](https://github.com/ethereum-optimism/optimism/pull/19535)).

### Infrastructure Upgrades
The `op-challenger` base image was upgraded to Ubuntu 24.04 to align with Kona's requirement for an upgraded glibc version ([#19734](https://github.com/ethereum-optimism/optimism/pull/19734)).

## ACTIVE ISSUES

### Flaky Acceptance Tests: Database and EL Sync
Investigation continues for flaky tests related to database preservation and truncation during CL/EL resync, specifically `TestPreserveDatabaseOnCLResync`, `TestTruncateDatabaseOnELResync`, and `TestCLUnsafeNotRewoundOnInvalidDuringELSync` ([#19661](https://github.com/ethereum-optimism/optimism/issues/19661)). Two of the three tests appear fixed with 113 consecutive passes, but `TestTruncateDatabaseOnELResync` requires more data.

### Flaky Test: `TestCLELDivergence`
The `TestCLELDivergence` test continues to be a focus, with a recent PR ([#19733](https://github.com/ethereum-optimism/optimism/pull/19733)) aiming to fix it ([#19681](https://github.com/ethereum-optimism/optimism/issues/19681)). Previous discussions highlighted that the test's expectation of CL-EL divergence persistence might be incorrect if the derivation pipeline resetting the unsafe head is expected behavior. The latest comment indicates that the fix will need time to be confirmed.

### Interop Phase 3: Removing Chains From Shared Dispute Games
Discussion on Interop Phase 3 focuses on the ability to remove a chain from a shared dispute game ([#19692](https://github.com/ethereum-optimism/optimism/issues/19692)). Clarification was provided that this specifically means support in the proofs system for removing chains from the interop set, not solving all related interop problems.

### Feature: op-reth Interop Tx Pool Filter and Reorg Eviction
Progress on implementing interop-related transaction pool features in `op-reth` continues ([#19411](https://github.com/ethereum-optimism/optimism/issues/19411)). A new upstream Reth issue has been opened to enable supernode's rewind operations to work correctly under `op-reth`.
