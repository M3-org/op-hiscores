# ethereum-optimism/optimism Daily Update (May 19, 2026)

## OVERVIEW

Today's development focused on enhancing Superchain interoperability with new RPC namespaces and refined activity startup, alongside critical bug fixes for ZK Game remediations and OPCM release tag filtering. Documentation was significantly updated, and CI/CD pipelines were optimized for efficiency.

## KEY TECHNICAL DEVELOPMENTS

### Superchain Interoperability & Node Enhancements
Significant progress was made in improving Superchain interoperability. This includes exposing per-call committed transactions in `op-reth/payload` ([#20740](https://github.com/ethereum-optimism/optimism/pull/20740)), adding a new `interop_` RPC namespace and migrating `op-reth` ([#20778](https://github.com/ethereum-optimism/optimism/pull/20778)), and reworking `op-supernode` interop activity startup for better determinism ([#20823](https://github.com/ethereum-optimism/optimism/pull/20823)). A fix was also implemented to stabilize the first SafeDB snapshot during interop cold-start ([#20855](https://github.com/ethereum-optimism/optimism/pull/20855)).

### Critical Bug Fixes & Protocol Security
Several crucial bug fixes were deployed to enhance protocol security and stability. This includes remediations for ZK Dispute Game internal review findings ([#20548](https://github.com/ethereum-optimism/optimism/pull/20548)), filtering prerelease OPCM release tags ([#20815](https://github.com/ethereum-optimism/optimism/pull/20815)), and ensuring the INTEROP runtime flag is only flipped at genesis when scheduled ([#20812](https://github.com/ethereum-optimism/optimism/pull/20812)). A fix was also implemented to split the super authority finalized cache in `op-node` ([#20872](https://github.com/ethereum-optimism/optimism/pull/20872)).

### Documentation & CI/CD Improvements
Documentation received substantial updates, including a tutorial for upgrading chains to super-roots ([#20499](https://github.com/ethereum-optimism/optimism/pull/20499)), a runbook for merging chains into a shared dispute game ([#20510](https://github.com/ethereum-optimism/optimism/pull/20510)), and clarifications on historical proofs for permissioned chains ([#20595](https://github.com/ethereum-optimism/optimism/pull/20595), [#20875](https://github.com/ethereum-optimism/optimism/pull/20875)). CI/CD pipelines were hardened for docs-only fast paths ([#20859](https://github.com/ethereum-optimism/optimism/pull/20859)) and redundant build jobs were removed ([#20857](https://github.com/ethereum-optimism/optimism/pull/20857)).

## CLOSED ISSUES

### Interop Hard Fork & Dispute Game Merges
Several issues related to the Interop hard fork and merging chains into shared dispute games have been closed. This includes the implementation of the interop hard fork using L2CM in `kona-node` and `op-node` ([#20082](https://github.com/ethereum-optimism/optimism/issues/20082)), the second phase of Interop to merge chains into a shared dispute game ([#19691](https://github.com/ethereum-optimism/optimism/issues/19691)), and related tasks for all chains to use SuperDisputeGame ([#19698](https://github.com/ethereum-optimism/optimism/issues/19698), [#19704](https://github.com/ethereum-optimism/optimism/issues/19704)). A runbook for merging chains into a shared SuperDisputeGame was also completed ([#19714](https://github.com/ethereum-optimism/optimism/issues/19714)).

### RPC Namespace & Supervisor Removal
The transition from the `supervisor` RPC namespace to a dedicated `interop` filter namespace has been completed ([#20005](https://github.com/ethereum-optimism/optimism/issues/20005)). This change is part of the ongoing effort to remove the `op-supervisor` component.

### Withdrawal & OPCM Migrator Improvements
Issues concerning withdrawal commands and the `OPContractsManagerMigrator` have been addressed. This includes updating the withdrawal `op-chain-ops` command for U16a ([#17470](https://github.com/ethereum-optimism/optimism/issues/17470)), avoiding mocking in `test_addGameType_permissionedSuper_succeeds` ([#17928](https://github.com/ethereum-optimism/optimism/issues/17928)), and resolving an issue where chain B's `SystemConfig.delayedWETH` was not repointed during shared-DGF migration ([#20502](https://github.com/ethereum-optimism/optimism/issues/20502)). A template wrapping `OPContractsManagerMigrator.migrate` was also added ([#20503](https://github.com/ethereum-optimism/optimism/issues/20503)).
