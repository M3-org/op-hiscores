# ethereum-optimism/optimism Daily Update (Jul 6, 2026)
## OVERVIEW 
Today's development focused on critical bug fixes, enhancing testing infrastructure, and updating contract logic for post-U19 network states. A memory leak in `op-reth` was resolved, and scheduled tests were moved to a daily cadence for improved feedback.

## KEY TECHNICAL DEVELOPMENTS

### Infrastructure & Testing Improvements
Significant work was done to enhance the project's testing and CI infrastructure. Scheduled tests were moved from a weekly to a daily cadence to provide more frequent feedback on changes [#21595](https://github.com/ethereum-optimism/optimism/pull/21595). Additionally, a new script was introduced to validate CircleCI schedule triggers, preventing configuration drift [#21575](https://github.com/ethereum-optimism/optimism/pull/21575).

### Bug Fixes in `op-reth`
A critical memory leak in `op-reth` was addressed. The fix ensures that Prometheus metric buckets are properly drained during `op-proofs` CLI backfills, preventing unbounded RSS growth [#21596](https://github.com/ethereum-optimism/optimism/pull/21596).

### Contracts Bedrock Updates for U19
The `contracts-bedrock` package was updated to correctly handle the disabled Cannon fork state following the U19 upgrade. This includes adjustments to the fork test harness to reflect the deprecation of the legacy CANNON permissionless game on OP/Ink [#21621](https://github.com/ethereum-optimism/optimism/pull/21621).
