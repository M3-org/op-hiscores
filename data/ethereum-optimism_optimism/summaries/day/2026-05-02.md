# ethereum-optimism/optimism Daily Update (May 2, 2026)
## OVERVIEW 
Today's development focused on enhancing `op-supernode` with new Prometheus metrics for interop SLI qualification, alongside new pull requests addressing `op-revm` fixes, `op-challenger` routing, and documentation. Several new issues were opened concerning `OPContractsManagerMigrator` and `op-challenger` prestate configurations.

## KEY TECHNICAL DEVELOPMENTS

### Supernode Interoperability Metrics
New Prometheus metrics were added to `op-supernode` to qualify interop quality gates, specifically for SLI-SN-4 through SLI-SN-8. These metrics include a histogram for verification latency and other chain rewind related data. ([#20443](https://github.com/ethereum-optimism/optimism/pull/20443))

## NEWLY OPENED PULL REQUESTS
- A fix for `op-revm` was opened to ensure Bedrock deposits bump the nonce on Halt. ([#20504](https://github.com/ethereum-optimism/optimism/pull/20504))
- A pull request was submitted to route `SuperPermissionedGameType` through `cannon-kona` in `op-challenger`. ([#20501](https://github.com/ethereum-optimism/optimism/pull/20501))
- New documentation was added for an output→super-root upgrade tutorial, currently unlinked. ([#20499](https://github.com/ethereum-optimism/optimism/pull/20499))
