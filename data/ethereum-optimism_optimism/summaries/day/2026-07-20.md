# ethereum-optimism/optimism Daily Update (Jul 20, 2026)

## OVERVIEW 
Today's development focused on critical bug fixes in `op-challenger` and `kona` for improved dispute game functionality and transaction handling. Documentation was enhanced, and CI processes were updated to mandate scoped commits.

## KEY TECHNICAL DEVELOPMENTS

### `op-challenger` Enhancements and Bug Fixes
The `op-challenger` received a crucial bug fix to advance anchors for finalized `SuperPermissionedDisputeGame` games, ensuring proper lifecycle management without enabling playability for game type 5. This change separates lifecycle support from trace playability and registers lifecycle bindings. Additionally, Cannon was removed from the default game types, with Cannon Kona remaining the sole default.
- [#21811](https://github.com/ethereum-optimism/optimism/pull/21811)
- [#21912](https://github.com/ethereum-optimism/optimism/pull/21912)

### `kona` Transaction and Gossip Handling Improvements
Several fixes were implemented in `kona` to preserve span-batch transaction type prefixes, ensuring that physical EIP-2718 prefix presence is maintained during parsing. This prevents reinterpretation of payloads as prefixless legacy transactions. Invalid gossip messages are now metered, and warnings have been downgraded to debug logs to prevent spamming. Furthermore, invalid span-batch transaction types are now deferred to the typed decoder.
- [#21808](https://github.com/ethereum-optimism/optimism/pull/21808)
- [#21804](https://github.com/ethereum-optimism/optimism/pull/21804)
- [#21850](https://github.com/ethereum-optimism/optimism/pull/21850)

### Documentation and CI Process Updates
Documentation was significantly enhanced with a persona router homepage and a repaired `create-l2-rollup` tutorial, updating references from `op-geth` to `op-reth`. The CI process now mandates scoped commits and enforces this via CI checks, improving commit hygiene. Dependency versions were also bumped to patched versions across JS docs and Rust workspaces to address security advisories.
- [#21848](https://github.com/ethereum-optimism/optimism/pull/21848)
- [#21899](https://github.com/ethereum-optimism/optimism/pull/21899)
- [#21855](https://github.com/ethereum-optimism/optimism/pull/21855)
- [#21896](https://github.com/ethereum-optimism/optimism/pull/21896)

### `op-devstack` and `op-node` Refinements
The `op-devstack` now discovers OS-assigned service ports, using port 0 for Kona metrics and rollup-boost RPC in `sysgo` and then discovering actual bound addresses from structured startup logs. This removes race-prone local port preallocation. In `op-node`, remaining one-off fork symbols were swapped to `op-core`, ensuring byte-identical behavior and wire format compatibility.
- [#21872](https://github.com/ethereum-optimism/optimism/pull/21872)
- [#21904](https://github.com/ethereum-optimism/optimism/pull/21904)
