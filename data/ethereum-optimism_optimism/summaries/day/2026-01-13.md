# ethereum-optimism/optimism Daily Update (Jan 13, 2026)
## OVERVIEW 
Today's development focused on enhancing CI processes with weekly upgrade test block updates and adding JWT authentication to the op-interop-filter admin API. Significant work was also done on contract test improvements and the removal of L2OutputOracle support.

## KEY TECHNICAL DEVELOPMENTS

### CI/CD and Testing Enhancements
Improvements were made to the CI pipeline, including a new feature to update upgrade test blocks weekly, ensuring more current testing environments ([#18634](https://github.com/ethereum-optimism/optimism/pull/18634)). A fix was also implemented to ensure `solc` is correctly installed for contract tests, addressing a "text file busy" issue ([#18753](https://github.com/ethereum-optimism/optimism/pull/18753)). Additionally, `MintManager` tests were converted to fuzz tests for broader coverage ([#18744](https://github.com/ethereum-optimism/optimism/pull/18744)).

### Interoperability and Security Updates
The `op-interop-filter` now includes JWT authentication for its admin API, enhancing security for administrative functions ([#18771](https://github.com/ethereum-optimism/optimism/pull/18771)).

### Protocol Simplification and Upgrades
Support for the L2OutputOracle has been removed from the `op-proposer` to simplify its logic ([#18706](https://github.com/ethereum-optimism/optimism/pull/18706)). The project also saw an upgrade to `op-geth` across all components ([#18767](https://github.com/ethereum-optimism/optimism/pull/18767)).
