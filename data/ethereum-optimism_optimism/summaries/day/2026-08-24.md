# ethereum-optimism/optimism Daily Update (Aug 24, 2026)
## OVERVIEW 
Today's development focused on refining the `op-deployer` with a reduced default genesis time offset and enforcing a minimum, alongside adding a regression test for `alloy-op-evm`. Documentation was also updated to include a new RPC provider.

## KEY TECHNICAL DEVELOPMENTS

### `op-deployer` Genesis Time Configuration
The default genesis time offset for `op-deployer` has been reduced from 6 hours to 3 hours, and a new minimum offset of 1 hour is now enforced. This change resolves a long-standing TODO related to benchmarking L2 deployment times. ([#22512](https://github.com/ethereum-optimism/optimism/pull/22512))

### `alloy-op-evm` Regression Testing
A regression test was added to `alloy-op-evm` to address a specific producer-policy residual ("Leak B") related to dropped state-invalid transactions. This is a test-only change with no impact on production behavior. ([#22427](https://github.com/ethereum-optimism/optimism/pull/22427))

### RPC Provider Documentation Update
The documentation for OP Stack production RPC providers has been updated to include node101, listing the mainnets it currently supports: OP Mainnet, Base, Unichain, and World. ([#22556](https://github.com/ethereum-optimism/optimism/pull/22556))
