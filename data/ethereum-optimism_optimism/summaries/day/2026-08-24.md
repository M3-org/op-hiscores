# ethereum-optimism/optimism Daily Update (Aug 24, 2026)
## OVERVIEW 
Today's development focused on refining the `op-deployer` with a reduced default genesis time offset and enforcing a minimum, alongside adding a regression test for `alloy-op-evm`. Documentation was also updated to include a new RPC provider.

## KEY TECHNICAL DEVELOPMENTS

### `op-deployer` Genesis Time Configuration
The default genesis time offset in `op-deployer` has been reduced from 6 hours to 3 hours, and a new minimum offset of 1 hour is now enforced. This change resolves a long-standing TODO related to benchmarking L2 deployment times. ([#22512](https://github.com/ethereum-optimism/optimism/pull/22512))

### `alloy-op-evm` Regression Testing
A regression test was added to `alloy-op-evm` to address a specific residual "Leak B" in the State-Dependent Mining (SDM) producer policy, particularly concerning dropped state-invalid transactions. This is a test-only change with no production behavior modification. ([#22427](https://github.com/ethereum-optimism/optimism/pull/22427))

### RPC Provider Documentation Update
The documentation for OP Stack production RPC providers has been updated to include node101, listing its support for OP Mainnet, Base, Unichain, and World. ([#22556](https://github.com/optimism/optimism/pull/22556))

## ACTIVE ISSUES

### Revisit SDM Operator Documentation
Discussion on [#21545](https://github.com/ethereum-optimism/optimism/issues/21545) indicates significant progress in addressing the documentation for State-Dependent Mining (SDM) operator options. The latest comment confirms that both environment variable support and release-related documentation points are now resolvable. Specifically:
- **Environment Variables**: All SDM operator options for `op-reth` are now supported via environment variables and are documented. The landscape has simplified with the removal of `op-rbuilder` and `rollup-boost`, leaving `op-reth` as the sole component with an SDM operator option.
- **Release Documentation**: The documentation now correctly links the SDM guide's mention of the Lagoon hardfork to its registry page, replacing the previously planned but unrelated Upgrade 20 link. A reverse link from the Lagoon page to the SDM guide will be added once SDM ships and the guide is unhidden.
