# ethereum-optimism/optimism Weekly Report (Mar 1 - 7, 2026)

## 🚀 Highlights
This week focused on hardening the **Kona** derivation pipeline and advancing the **Superchain** interoperability framework through critical bug fixes and protocol refinements. Significant effort was directed toward preparing for the **Karst** and **Glamsterdam** upgrades, specifically addressing gas pricing impacts on fault proofs and integrating NUT bundle execution. Developers also streamlined the CI/CD pipeline and refactored the `op-devstack` to improve the contributor experience and system modularity.

## 🛠️ Key Developments

### Kona Derivation & Protocol Robustness
Extensive work was performed to ensure the Kona stack aligns with OP Stack specifications and handles edge cases in data availability.
*   **Error Handling & Reorgs:** Fixed a critical issue where `BlobSource` wrapped all errors as "Temporary," causing the loss of "Reset" classifications during L1 reorgs ([#19357](https://github.com/ethereum-optimism/optimism/pull/19357)).
*   **Pipeline Refinements:** Addressed several consensus-critical anomalies, including blob under-fill/over-fill checks ([#19362](https://github.com/ethereum-optimism/optimism/pull/19362)), proper origin field copying during the Holocene transition ([#19360](https://github.com/ethereum-optimism/optimism/pull/19360)), and support for EIP-4844 type-3 batcher transactions ([#19355](https://github.com/ethereum-optimism/optimism/pull/19355)).
*   **Code Cleanup:** Removed the orphaned `EthereumDataSourceVariant` file and dead code in `kona-derive` to reduce technical debt ([#19341](https://github.com/ethereum-optimism/optimism/pull/19341)).

### Interoperability & Supernode Stability
Improvements to the `op-supernode` and interop-related contracts focused on lifecycle management and security.
*   **Lifecycle Fixes:** Resolved a shutdown hang in the `op-supernode` chain container by adding cancellation checks in the `Start()` loop ([#19365](https://github.com/ethereum-optimism/optimism/pull/19365)) and addressed race conditions in virtual node transitions ([#19387](https://github.com/ethereum-optimism/optimism/pull/19387)).
*   **Contract Security:** Enhanced the `OPContractsManagerMigrator` by requiring the `OPTIMISM_PORTAL_INTEROP` flag for migrations and adding custom error handling ([#19285](https://github.com/ethereum-optimism/optimism/pull/19285)).
*   **Sync Reliability:** Improved `op-node` follow-source mode to correctly copy `LocalSafeL2` status from upstream nodes ([#19330](https://github.com/ethereum-optimism/optimism/pull/19330)).

### Infrastructure & Tooling
*   **Devstack Refactor:** Implemented Phase 5 of the ID type system refactor, introducing a `ComponentRegistry` for generic access to network components ([#18876](https://github.com/ethereum-optimism/optimism/pull/18876)).
*   **CI/CD Optimization:** Removed GCS-based artifact caching in `contracts-bedrock` to prevent non-deterministic builds ([#19332](https://github.com/ethereum-optimism/optimism/pull/19332)) and integrated the `cannon-builder` Docker image into the standard CI flow ([#19295](https://github.com/ethereum-optimism/optimism/pull/19295)).
*   **AI-Assisted Development:** Introduced new review rules for "Non-Idempotent Initializers" to improve automated code quality checks for smart contracts ([#19273](https://github.com/ethereum-optimism/optimism/pull/19273)).

## 🐛 Issues & Triage

### Closed Issues
*   **L2CM Implementation:** Successfully closed several tracking issues for the **L2 Contracts Manager (L2CM)**, including the `ConditionalDeployer` ([#18828](https://github.com/ethereum-optimism/optimism/issues/18828)) and the overarching L2 upgrade implementation task ([#18843](https://github.com/ethereum-optimism/optimism/issues/18843)).
*   **Kona Stability:** Resolved issues where blob fetching failures led to safe head stalls ([#18716](https://github.com/ethereum-optimism/optimism/issues/18716)).

### New & Active Issues
*   **Glamsterdam Gas Pricing:** A high-priority investigation is underway regarding EIP-8037's impact on gas costs. Increased costs for precompiles could potentially break existing fault proofs, necessitating updates to `PreimageOracle` gas constants ([#19380](https://github.com/ethereum-optimism/optimism/issues/19380), [#19381](https://github.com/ethereum-optimism/optimism/issues/19381)).
*   **L2CM Storage Concerns:** New discussions emerged regarding the risk of storage variable collisions between `L2ContractsManager` and `L2ProxyAdmin`, which could lead to administrative lockouts ([#19391](https://github.com/ethereum-optimism/optimism/issues/19391)).
*   **Flashblocks Connectivity:** Multiple users reported 429 rate limits and handshake failures when attempting to connect to the flashblocks websocket endpoint ([#19366](https://github.com/ethereum-optimism/optimism/issues/19366), [#19382](https://github.com/ethereum-optimism/optimism/issues/19382)).

## 💬 Community & Collaboration
The week saw heavy collaboration between core maintainers and contributors on the **Kona** derivation pipeline, with multiple contributors (including *Moses-main*, *ajsutton*, and *sebastianst*) coordinating on consensus-critical fixes. There is an active dialogue regarding the "intended behavior" of EL sync and finalized block marking, indicating a rigorous peer-review process for protocol-level changes.
