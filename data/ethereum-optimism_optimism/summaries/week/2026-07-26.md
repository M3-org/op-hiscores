# ethereum-optimism/optimism Weekly Report (Jul 26 - 1, 2026)

## 🚀 Highlights
This week focused on hardening the infrastructure for the Superchain ecosystem, with significant progress in interoperability migration and contract upgrade mechanisms. Key achievements include the default activation of the `SUPER_ROOT_GAMES_MIGRATION` and the porting of the `kona-sp1-proposer` to the monorepo. Development efforts prioritized protocol stability, resolving several critical flaky tests in `op-node` and `op-reth`, while simultaneously optimizing CI/CD pipelines for faster Rust builds and automated vulnerability management.

## 🛠️ Key Developments

### Protocol & Interoperability
*   **Super Root Migration:** Enabled `SUPER_ROOT_GAMES_MIGRATION` by default in Foundry test configurations, ensuring the contracts feature matrix includes explicit opt-out rows ([#21689](https://github.com/ethereum-optimism/optimism/pull/21689)).
*   **Contract Upgrade Refinement:** Addressed complexities in Bedrock contract upgrades, specifically resolving `ProxyAdmin` instances during upgrades to ensure shared components are correctly updated across interoperable chains ([#22034](https://github.com/ethereum-optimism/optimism/pull/22034), [#22033](https://github.com/ethereum-optimism/optimism/pull/22033)).
*   **Kona & Fault Proofs:** Successfully ported the `kona-sp1-proposer` from `succinctlabs/op-succinct` into the monorepo ([#22018](https://github.com/ethereum-optimism/optimism/pull/22018)) and optimized `kona` prestate builds ([#22058](https://github.com/ethereum-optimism/optimism/pull/22058)).

### Node & RPC Stability
*   **op-node & op-supernode:** Hardened the sequencer by rejecting stale build starts ([#21913](https://github.com/ethereum-optimism/optimism/pull/21913)) and ensuring the supernode fails startup if the deny list is inaccessible ([#21997](https://github.com/ethereum-optimism/optimism/pull/21997)).
*   **op-reth Enhancements:** Improved RPC functionality by forwarding `eth_getBlockReceipts` to historical endpoints ([#21955](https://github.com/ethereum-optimism/optimism/pull/21955)) and making forwarded transaction pool admission opt-in ([#22053](https://github.com/ethereum-optimism/optimism/pull/22053)).

### Tooling & Deployment
*   **op-deployer Hardening:** Improved resilience for live deployments by hardening RPC and gas handling ([#22032](https://github.com/ethereum-optimism/optimism/pull/22032)) and activating the Karst upgrade at genesis by default ([#22048](https://github.com/ethereum-optimism/optimism/pull/22048)).
*   **CI/CD Optimization:** Implemented faster linkers, split builds for `op-reth` and `kona`, and introduced a diff-aware dependency review gate to enhance security and build speed ([#22042](https://github.com/ethereum-optimism/optimism/pull/22042), [#22079](https://github.com/ethereum-optimism/optimism/pull/22079)).

## 🐛 Issues & Triage

### Closed Issues
*   **Flaky Test Resolution:** Successfully resolved long-standing flakiness in `TestSupernodeLightSequencerInteropInvalidMessageReplacement` by fixing stale build start logic ([#21635](https://github.com/ethereum-optimism/optimism/issues/21635)) and addressed hangs in `op-deployer` forge tests ([#22010](https://github.com/ethereum-optimism/optimism/issues/22010)).
*   **Feature Completion:** Closed issues regarding the addition of starting anchor roots to deployer inputs ([#20912](https://github.com/ethereum-optimism/optimism/issues/20912)) and support for super-root game types 5 and 9 ([#21711](https://github.com/ethereum-optimism/optimism/issues/21711)).

### New & Active Issues
*   **Proposer Configuration:** A new initiative was launched to auto-configure the proposer using the `--network` flag by reading the Dispute Game Factory address directly from the superchain registry ([#22051](https://github.com/ethereum-optimism/optimism/issues/22051)).
*   **EL Sync Stalls:** Investigation continues into `TestUnsafeChainNotStalling_CLSync` flakiness, with evidence pointing toward an Execution Layer (EL) peer-management defect rather than a test budget issue ([#21041](https://github.com/ethereum-optimism/optimism/issues/21041)).
*   **Vulnerability Management:** Introduced a Renovate CVE Dashboard to centralize the tracking of detected dependency vulnerabilities ([#22070](https://github.com/ethereum-optimism/optimism/issues/22070)).

## 💬 Community & Collaboration
The week saw heavy collaboration on the technical specifications for post-interop-migration upgrades. Maintainers engaged in a detailed architectural debate regarding `ProxyAdmin` resolution, weighing gas efficiency against the risk of silent upgrade failures. Security remained a collaborative priority, evidenced by the integration of Lumi audit reports for core Go and Rust components and a flurry of dependency updates (including `quinn-proto` and `webtransport-go`) to address security advisories. Documentation also saw a major overhaul to improve the "Get Started" experience for new developers and operators.
