# ethereum-optimism/ethereum-optimism.github.io Weekly Report (Mar 29 - Apr 4, 2026)

## 🚀 Highlights
This week focused on maintaining the economic and technical integrity of the Optimism ecosystem through tokenomics updates and protocol refinements. Key activities included an update to the OP token circulating supply and the expansion of supported assets on Base and Optimism. On the technical front, developers made progress on the dispute game infrastructure and finalized critical design decisions regarding transaction pool behavior during network reorganizations to ensure protocol safety.

## 🛠️ Key Developments

### Tokenomics & Asset Integration
Efforts this week centered on ensuring accurate ecosystem data and expanding the variety of available assets across the Superchain.
*   **Circulating Supply Update:** The circulating supply of OP tokens was officially updated to 2,136,461,507 ([#1297](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1297)).
*   **New Token Listings:** Pull requests were submitted to integrate new assets, including wREAL8 (Wrapped REAL8) for both Base and Optimism ([#1298](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1298)) and the WRP (Warp) token specifically for Base ([#1296](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1296)).

### Protocol Infrastructure
Technical refinements were made to the components responsible for network security and cross-chain execution.
*   **Kona Integration:** Developers successfully updated the host arguments in the Kona super executor for `op-challenger`, improving the integration and testing environment for fault proofs ([#18287](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18287)).

## 🐛 Issues & Triage

### Closed Issues
*   **Dispute Game Migration:** An issue regarding the migration of FaultDisputeGame chains to SuperDisputeGame was closed as a duplicate, streamlining the tracking of the transition to the Superchain's unified dispute model ([#19013](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19013)).
*   **Challenger Fixes:** Resolved configuration issues within the `op-challenger` executor to ensure stable execution of dispute games ([#18287](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18287)).

### Active Issues & Discussions
*   **Interop Transaction Safety:** A significant technical discussion is ongoing regarding how the transaction pool handles interoperability (interop) transactions during a chain reorganization (reorg). The current consensus for `op-reth` is to prioritize safety by dropping all interop transactions during a reorg rather than attempting re-verification. This simplified approach provides stronger safety guarantees, though developers noted that re-verification logic may be revisited in the future ([#19351](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19351)).

## 💬 Community & Collaboration
The week's activity reflects a high degree of coordination between protocol developers and ecosystem partners. The discussion surrounding interop transaction pool behavior ([#19351](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19351)) highlights the collaborative effort to balance technical simplicity with the rigorous safety requirements of the Superchain. Additionally, the submission of new token pull requests indicates ongoing engagement from external projects looking to deploy on Optimism and Base.
