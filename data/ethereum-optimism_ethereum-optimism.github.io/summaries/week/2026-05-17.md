# ethereum-optimism/ethereum-optimism.github.io Weekly Report (May 17 - 23, 2026)

## 🚀 Highlights
This week focused on refining the Interop hard fork infrastructure and stabilizing the testing environment through aggressive flaky test mitigation. Significant progress was made in resolving architectural discrepancies, notably fixing Brotli channel divergence between Kona and `op-node` and refactoring RPC namespaces to support interop filters. The ecosystem also continued its steady expansion with several new token listings on Base and Ethereum mainnets. While some migration-related tasks were consolidated or closed as duplicates, the team successfully transitioned dispute game tests to the `op-acceptance-tests` suite, marking a step forward in testing maturity.

## 🛠️ Key Developments

### Ecosystem Expansion & Token Listings
The project continues to broaden its supported asset base through several pull requests aimed at updating token metadata for both Base and Ethereum mainnets.
*   **Base Mainnet:** Added support for DELX Protocol ([#1315](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1315)) and MyAI (MYAI) ([#1317](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1317)).
*   **Ethereum Mainnet:** Added token data for K9 and PUPCUP (World Pup Coin) ([#1316](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1316)).

### Interop & Protocol Refinement
Technical efforts were concentrated on the Interop hard fork implementation and streamlining the communication interfaces between nodes.
*   **RPC Namespace Refactoring:** The supervisor RPC namespace was successfully replaced with the interop filter namespace ([#20005](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20005)).
*   **Brotli Channel Alignment:** Resolved a critical disagreement between Kona and `op-node` regarding Brotli channels, with follow-up work scheduled for upstream fixes ([#19333](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19333)).
*   **Payload Execution:** An investigation into `debug_executePayload` concluded that the code remains a necessary fast-path for `op-reth` and will not be removed ([#20879](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20879)).

## 🐛 Issues & Triage

### Closed Issues
*   **Testing Migration:** Remaining dispute game tests were successfully migrated from `op-e2e` to `op-acceptance-tests` ([#20814](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20814)).
*   **Consolidation:** Several issues regarding migration commands ([#17470](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/17470)), Super game type testing ([#17928](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/17928)), and `OPContractsManager` templates ([#20502](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20502), [#20503](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20503)) were closed as they were either superseded by unified proving or identified as duplicates.
*   **Documentation:** An issue regarding interop tx pool eviction was closed after determining the behavior in `op-reth` did not require additional documentation ([#19351](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19351)).

### New & Active Issues
*   **Flaky Test Stabilization:** Significant effort is being directed at intermittent CI failures. Root causes were identified for `TestChallengerCountersPreGenesisGame` (timing collisions with wall-clock migration) and `TestELSyncSafeRetractedByOffset` (potential configuration issues with `OffsetELSafe`). Fixes are currently in progress ([#20869](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20869), [#20334](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20334)).
*   **Devnet Progress:** Work continues on deploying internal test networks for Interop proofs. The team is currently awaiting `glamsterdam-devnet-4` images to attempt a full infrastructure devnet spin-up ([#20489](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20489), [#20691](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20691)).
*   **Blockers:** SDM integration with flashblocks remains blocked by dependency issue #20599 ([#20175](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20175)).
