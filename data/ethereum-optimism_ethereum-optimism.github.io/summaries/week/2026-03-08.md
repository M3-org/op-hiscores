# ethereum-optimism/ethereum-optimism.github.io Weekly Report (Mar 8 - 14, 2026)

## 🚀 Highlights
This week’s activity focused on expanding the Base ecosystem through new token integrations and addressing critical stability concerns within the `op-node` infrastructure. While the repository saw a steady stream of pull requests for asset listings, significant community discussion centered on technical debt, specifically regarding repository bloat and its impact on developer experience. Developers also prioritized triaging a high-severity crash loop in the protocol's deposit handling logic to ensure network reliability.

## 🛠️ Key Developments
While no major technical features were finalized during this period, the primary focus was on ecosystem expansion and documentation accuracy.

### Base Ecosystem Expansion
The project continues to facilitate the growth of the Base network by integrating new assets. Several pull requests were initiated to update token lists:
*   **Token Listings:** New requests were opened to add ELON (Dogelon Mars) [#1284](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1284), WLNT [#1286](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1286), and AMOND [#1285](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1285) to the Base ecosystem.

### Documentation & Configuration
Efforts are underway to correct discrepancies in protocol configuration guides:
*   **Batcher Configuration:** Work began on PR #2000 to fix a mismatch in the `max-blocks-per-span-batch` description, which currently erroneously displays information for transaction depth checks [#1933](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/1933).

## 🐛 Issues & Triage
The week was marked by the identification of a critical protocol bug and ongoing concerns regarding the project's development environment.

### New & Active Issues
*   **Critical `op-node` Crash Loop:** A high-priority issue was opened regarding a permanent node crash loop triggered by `DepositsOnlyPayloadAttributesRequestEvent` errors [#19509](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19509). Maintainers are currently evaluating a proposed fix and testing strategy to ensure the solution is sufficiently broad to prevent recurrence.
*   **Repository Bloat:** Discussion intensified regarding the size of the `optimism` repository, which has reached over 1GB. This bloat causes significant delays in cloning (reported at over 2 hours) and complicates dependency management for Rust crates. This remains a significant blocker for developer onboarding and CI efficiency [#19241](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19241).

## 💬 Community & Collaboration
Collaboration this week was characterized by active technical triage and feedback on protocol stability. The discussion surrounding the `op-node` crash loop involved critical peer review of proposed tests, with contributors like **ajsutton** and **Claude** debating the necessary scope for the fix. Additionally, the community is actively pushing for better repository maintenance, as seen in the discussions on issue [#19241](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19241), where contributors are advocating for prioritized cleanup of the `.git` directory to improve the overall developer experience.
