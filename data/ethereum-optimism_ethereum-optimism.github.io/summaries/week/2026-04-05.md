# ethereum-optimism/ethereum-optimism.github.io Weekly Report (Apr 5 - 11, 2026)

## 🚀 Highlights
This week focused on addressing critical protocol vulnerabilities and expanding the Superchain ecosystem's asset support. Significant attention was directed toward a high-priority DoS vulnerability in the `kona-protocol` batch decoder, with a community-led fix currently in development. Additionally, developers continued to investigate persistent state root mismatches affecting `op-reth` on Base Mainnet, identifying potential upstream dependencies. On the ecosystem front, new token integrations are underway to support yield-bearing stablecoins on Base.

## 🛠️ Key Developments
While no pull requests were finalized during this specific reporting window, work commenced on expanding the ecosystem's financial tooling:

### Ecosystem Asset Integration
*   **Base Token Expansion:** A new pull request ([#1300](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1300)) was initiated to add the BRLE token to the repository. BRLE is a BRL-pegged yield stablecoin by EFIX, aimed at increasing liquidity and utility within the Base network.

## 🐛 Issues & Triage
The week was dominated by deep-dive investigations into protocol-level stability and security.

### New & Active Issues
*   **Critical DoS Vulnerability in `kona-protocol` ([#19334](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19334)):** Discussion intensified regarding a vulnerability in the batch decoder that could lead to a Denial of Service. Contributor `zhuzhushiwojia` has stepped forward to lead the remediation, proposing a shift from `panic!()` calls to robust error handling and graceful propagation. A fix, including comprehensive tests for malformed data, is expected within the coming days.
*   **State Root Mismatches in `op-reth` ([#19532](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19532)):** Investigation continues into recurring state root mismatches on Base Mainnet. This week, contributors identified a potential link to upstream issues in the `paradigmxyz/reth` repository (specifically issues #23309 and #22973), suggesting the bug may be rooted in the underlying execution client's deterministic logic.

## 💬 Community & Collaboration
The week demonstrated strong community engagement in protocol security. The proactive involvement of independent developers like `zhuzhushiwojia` in tackling critical DoS vulnerabilities highlights a healthy, decentralized contributor base capable of responding to high-stakes technical challenges. Furthermore, the collaborative debugging of the `op-reth` state root issue shows active cross-project coordination, as contributors trace local bugs back to upstream dependencies in the broader Ethereum execution client ecosystem.
