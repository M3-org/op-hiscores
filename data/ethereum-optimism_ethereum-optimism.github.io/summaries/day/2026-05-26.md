## ACTIVE ISSUES

### Investigating `op-reth` SIGBUS Crash and Infinite Retry Loop
Discussion on [#20934](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20934) continues regarding a `SIGBUS` crash and infinite retry loop in the `proofs-history exex` during deep FCU rewinds. The issue was reopened as the core problem, particularly point 2 (SIGBUS crash), remains unresolved. A hypothesis suggests that `File::set_len(ftruncate)` might be truncating static-file mmap pages while another thread is reading them, leading to `SIGBUS`. The team is awaiting input from the Reth core team on this hypothesis.

### L2CM Feature Flag Drift Prevention
Issue [#20340](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20340) discusses preventing silent drift between feature flag definitions and the CI matrix. The decision was made to document all necessary updates when adding new dev or system features, with this documentation to be placed as comments in `DevFeatures.sol` and `devFeatures.go`.

### Flaky Test Investigation: `TestUnsafeChainNotStalling_CLSync` Regression
The investigation into the flaky `TestUnsafeChainNotStalling_CLSync` test family in [#21041](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/21041) revealed that the issue is not a test budget bug but rather an `op-reth` Engine API stall. Evidence from CI logs showed the L2CL-b verifier stalled at block 40, with `engine_newPayloadV3` / `forkchoiceUpdated` RPC calls timing out repeatedly. This suggests the bug lies within the `op-reth` Engine API or the `op-node` ⇄ `op-reth` Engine handshake. The team is now investigating if a recent fix ([#21012](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/21012)) for a similar issue will resolve this flakiness.
