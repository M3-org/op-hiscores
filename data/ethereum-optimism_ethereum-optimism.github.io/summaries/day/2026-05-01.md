## ACTIVE ISSUES

- **Fatal Panic in StateRootTask during op-reth Upgrade**: Discussions continued on a critical issue where upgrading `op-reth` from 1.x to 2.x causes a fatal panic in `StateRootTask` or `Parallel` strategies. The latest update confirms that the `--engine.legacy-state-root` flag does not resolve the panic, as both parallel trie code paths share the same `alloy-trie-0.9.5` bug. The crash block is not specific, suggesting non-deterministic triggering during parallel trie computation against 1.x database state ([#20462](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20462)).
- **op-supernode: Incorrect L1 Verification Logic**: A new issue was opened highlighting that `op-supernode`'s `VerifiedRequiredL1` function incorrectly uses the minimum of per-chain `verifiedL1` values instead of the maximum. This affects how `SuperRootResponseData.VerifiedRequiredL1` is published ([#20481](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20481)).
