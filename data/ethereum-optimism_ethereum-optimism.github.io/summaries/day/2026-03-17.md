## ACTIVE ISSUES

### op-node: Initial EL Sync UX and Correctness [#17631](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/17631)
Discussion continued regarding the `op-node`'s behavior of marking the initial EL sync target as finalized, even if not truly finalized. A proposal was made to continue EL sync to the unsafe head and use a different finalization gadget (command line flag, trusted checkpoint provider, or L1 lookup) to set the finalized head. The potential for this bug to be triggered during sequencing with EL, especially with light CL, was highlighted. The deprecation of `op-geth` was noted as potentially simplifying the issue for `op-reth`.

### [tracking]: Review kona-interop block hash oracle [#18288](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18288)
The remaining task for this issue is to ensure an integration/acceptance test exists to verify that block lookups prior to the current history window function correctly.
