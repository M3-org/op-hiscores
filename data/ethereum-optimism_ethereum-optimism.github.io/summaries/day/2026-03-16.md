## ACTIVE ISSUES

### op-reth Memory Leak Investigation
Discussion continued on [#19212](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19212) regarding `op-reth` database read transactions causing memory leaks. A user reported experiencing the same issue on World Chain v1.10.1, leading to node crashes. The user also noted that they had upgraded to `1.11.0` but encountered other issues, prompting a downgrade to `1.10.2`, and subsequently switched to the Base fork of `op-reth` for their Base nodes. The issue has been observed intermittently across different `op-reth` versions.

### op-supernode Acceptance Test Reinstatement
Further context was provided for [#19403](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19403), which tracks the reinstatement of `interop/activation/...` tests in `op-supernode/acceptance-tests`. A useful test was highlighted as a potential extension point, and it was noted that the test setup/teardown code itself contributes to problems when tests fail, as teardown can hang.

### op-reth State Root Mismatch on Base Mainnet
The issue of recurring state root mismatches on Base mainnet, leading to permanent sync stalls and fatal crashes in `op-reth` archive nodes, was discussed in [#19532](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19532). A user confirmed experiencing the same issue on custom chains like Manta Pacific. A maintainer suggested that since Base recently forked the OP Stack, the issue should be opened on the Base repository and linked back for tracking.
