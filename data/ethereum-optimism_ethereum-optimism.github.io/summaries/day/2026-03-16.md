### op-reth Memory Leak Investigations
Discussions continued on [#19212](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19212) regarding `op-reth` database read transactions causing memory leaks. A user reported experiencing the issue on World Chain v1.10.1, leading to node crashes. They noted that an upgrade to v1.11.0 introduced other issues, prompting a downgrade to v1.10.2, and subsequently a switch to the Base fork of `op-reth` for their Base nodes. The user also mentioned that the issue has not reoccurred since their initial report.

### op-supernode Acceptance Test Reinstatement

### op-reth State Root Mismatch on Base Mainnet
The issue of recurring state root mismatches on Base mainnet, leading to sync stalls and crashes, was actively discussed in [#19532](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19532). A user confirmed experiencing the same issue on custom chains like Manta Pacific. A maintainer suggested that Base has recently forked the OP Stack and advised opening the issue on the Base repository, linking it back for continued discussion.
