## CLOSED ISSUES

### Documentation for Gas Configuration
The issue [#1944](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/1944), concerning a guide on how to change gas config values post-Holocene, was closed with a link to the new documentation: https://docs.optimism.io/chain-operators/guides/management/gas-target-limit.

### Acceptance Tests on Glamsterdam Devnet
The issue [#18755](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18755), regarding running acceptance tests against the first glamsterdam devnet (bal-devnet-1), was closed. Challenges encountered included lack of custom L1 support in tooling, inconsistent RPC responses, and premature devnet failure due to misconfiguration. Follow-up steps are outlined in a new issue.

## NEW ISSUES

### OPCM v2 Support Expansion
A new issue, [#18942](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18942), was opened to add support for OPCM v2 to packages other than `op-deployer`, noting that while `op-deployer` now has functional commands, other packages require updates.

## ACTIVE ISSUES

### op-deployer: Transaction Gas Limit Too High
Discussion on [#17912](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/17912) continues, with a recent comment from RISHABHAGRAWALZRA asking if the issue is fixed and which `op-deployer` version to use for alt-da. Previously, `sbvegan` confirmed the issue is due to the Fusaka hardfork's transaction gas limit cap (EIP-7825) and suggested using `v0.5.0*` of `op-deployer`, though it's a release candidate and untested post-Fusaka.

### op-batcher: Stay in Sync with op-node Rollup Config
On [#18178](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18178), `geoknee` suggested treating an outdated rollup config as a critical error and restarting the batcher to automatically reload the config. Earlier discussions proposed making the operator explicitly provide the rollup config to the batcher or having the active endpoint provider signal when the config changes.

### Sequencer-Defined Metering Design Doc
The scope of [#360](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/360) has been expanded to include the initial Proof of Concept (PoC), which is currently blocking the design document. The initial devnet deployment is planned for January 30, 2026, after which the design can be evaluated and basic benchmarking performed.
