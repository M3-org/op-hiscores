## NEW ISSUES

### Breaking Change in `StorageKeys` Value
A new issue, [#780](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/780), was opened regarding a breaking change in `StorageKeys` value (`null` instead of `[]`) in `op-geth` version `v1.101701.0`. This change is attributed to the `SortedFunc` in Go's `slices` package returning `nil` for empty arrays.
