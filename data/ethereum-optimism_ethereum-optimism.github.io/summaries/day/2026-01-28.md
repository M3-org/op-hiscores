## ACTIVE ISSUES

### Enhancing `op-supernode` SyncStatus API
Discussions on [#18947](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18947) clarified the requirements for the `op-supernode` SyncStatus API. The interface should include the `op-node` SyncStatus for every chain, the sync status of every verification activity, and for interop activity, the latest verified timestamp and the current L1. Additionally, the SyncStatus should report on the latest verified L2 to simplify acceptance testing.

### Addressing EIP-1559 Parameters Decoding in `op-alloy`
Issue [#18951](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18951) is being actively discussed, with a developer expressing interest in taking on the task of fixing EIP-1559 parameters decoding in `op-alloy` to properly catch zero elasticities early.

### Proving Withdrawals with Chain-Specific Root Claim
The issue [#18517](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18517) regarding proving withdrawals using a chain-specific root claim was moved to the backlog. While `OptimismPortalInterop` changes are complete, updating `OptimismPortal2` is dependent on the U19 execution and the FaultDisputeGames supporting the new `rootClaimByChainId` method. This phased approach is necessary to ensure continuous withdrawal functionality post-upgrade.
