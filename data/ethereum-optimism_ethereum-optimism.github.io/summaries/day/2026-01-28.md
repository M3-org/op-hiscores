## ACTIVE ISSUES

### Enhancing `op-supernode` SyncStatus API
Discussions on [#18947](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18947) focused on defining the `op-supernode` SyncStatus API. It was decided that the interface should include the `op-node` SyncStatus of every chain and the sync status of every verification activity. For interop activity, this includes the latest verified timestamp and the current L1. Additionally, the SyncStatus should report on the latest verified L2 to simplify acceptance testing.

### Addressing EIP-1559 Parameters Decoding in `op-alloy`
Issue [#18951](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18951) is tracking the need to properly catch zero elasticities during EIP-1559 parameters decoding at the `op-alloy` level to ensure early failure. A community member expressed interest in taking on this task.

### Proving Withdrawals with Chain-Specific Root Claim
The issue [#18517](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18517) regarding `OptimismPortal2.proveWithdrawalTransaction` using `IDisputeGame.rootClaim(uint256)` was moved to the backlog. While `OptimismPortalInterop` changes are complete, updating `OptimismPortal2` must wait until U19 is executed. This is to ensure withdrawals continue to function immediately after the upgrade and to avoid users waiting an additional week for the newly upgraded FaultDisputeGame to finalize.
