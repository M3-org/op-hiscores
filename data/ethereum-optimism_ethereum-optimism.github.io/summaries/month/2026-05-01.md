# ethereum-optimism/ethereum-optimism.github.io Monthly Report (May 2026)

## 🚀 Highlights
In May 2026, development efforts focused on refining the infrastructure for the Superchain and Interop releases, with a particular emphasis on protocol stability and configuration accuracy. Key activities included troubleshooting critical `op-reth` upgrade failures and addressing logic errors within `op-supernode` verification. Discussions also centered on aligning smart contract upgrade templates (OPCM) with upcoming Interop requirements, ensuring that prestate configurations are correctly mapped for future protocol versions.

## 🛠️ Key Developments
While the month focused heavily on troubleshooting and architectural planning, the following technical updates were initiated:

### Protocol & Token Integration
*   **Revenue Token Addition:** A new pull request was opened to integrate the ET10 Revenue Token ([#1310](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1310)).
*   **Dependency Maintenance:** Development tools were updated, specifically moving the `@typescript-eslint/parser` from version 4.33.0 to 6.21.0 to maintain modern linting standards ([#1309](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1309)).

## 🐛 Issues & Triage
The month saw significant activity in diagnosing protocol-level bugs and refining the logic for Superchain monitoring.

### Closed Issues
*   **Dispute Monitor Configuration:** Developers resolved a query regarding `op-dispute-mon` capabilities. It was confirmed that a single instance can monitor both CANNON and SUPER_CANNON_KONA games by utilizing both `rollup-rpc` and `supernode-rpc` endpoints, leveraging `op-supernode`'s ability to expose node RPCs ([#20476](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20476)).

### New & Active Issues
*   **Critical op-reth Upgrade Panic:** A high-priority investigation is underway regarding a fatal panic in `StateRootTask` when upgrading `op-reth` from 1.x to 2.x. The issue appears to stem from a bug in `alloy-trie-0.9.5` affecting parallel trie computation, and remains unresolved as standard flags like `--engine.legacy-state-root` have failed to mitigate the crash ([#20462](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20462)).
*   **op-supernode Logic Errors:** A bug was identified in the `VerifiedRequiredL1` function where the system incorrectly calculates the minimum rather than the maximum of per-chain `verifiedL1` values, potentially impacting the accuracy of published `SuperRootResponseData` ([#20481](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/20481)).
*   **OPCM Upgrade Pathing:** Discussions are ongoing regarding `OPCMUpgradeV700.sol` and the potential misconfiguration of `cannonKonaPrestate`. Current consensus suggests targeting these fixes for the V800 upgrade to align with the Interop release requirements ([#1412](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/1412)).
