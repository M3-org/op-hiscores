# ethereum-optimism/ethereum-optimism.github.io Monthly Report (April 2026)

## 🚀 Highlights
In April 2026, development focused heavily on hardening the Superchain infrastructure through rigorous debugging of the interop stack and protocol-level security. Significant efforts were directed toward resolving flaky CI tests in `op-reth` and `op-challenger`, ensuring the reliability of fault dispute games and state verification. The ecosystem also saw continued growth in asset diversity with several new token integrations and a transparent update to the OP token circulating supply, reflecting the ongoing expansion of the Optimism Collective.

## 🛠️ Key Developments

### Tokenomics and Asset Integration
The project maintained its role as a registry for the expanding Superchain ecosystem, processing several token additions and supply updates.
*   **Circulating Supply Update:** The circulating supply of OP tokens was adjusted from 2,117,847,344 to 2,136,461,507 to maintain accurate ecosystem data ([#1297](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1297)).
*   **New Token Listings:** Support was added for several new assets across Base and Optimism, including wREAL8 ([#1298](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1298)), WRP ([#1296](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1296)), TAXGAS ([#1299](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1299)), and the BRLE yield stablecoin ([#1300](https://github.com/ethereum-optimism/ethereum-optimism.github.io/pull/1300)).

### Protocol and Interoperability Refinement
Technical work focused on the underlying mechanics of the interop stack and dispute games.
*   **Challenger Updates:** The `op-challenger` was updated to integrate with the `kona-interop` host, ensuring that fault proof components are compatible with the latest interoperability developments ([#18287](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/18287)).
*   **Interop Transaction Logic:** Developers clarified the safety-first approach for `op-geth` and `op-reth`, confirming that interop executing messages are dropped from the transaction pool during reorgs to maintain strong safety guarantees ([#19351](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19351)).

## 🐛 Issues & Triage

### Closed Issues
*   **Dispute Game Migration:** Redundant tracking for the migration of FaultDisputeGame chains to SuperDisputeGame was consolidated ([#19013](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19013)).

### New & Active Issues
*   **CI Reliability (Flaky Tests):** A major push is underway to fix flaky tests that impede development velocity. Key targets include `TestSuperCannonStepWithPreimage` ([#19892](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19892)), which suffered from resource contention in CI, and `TestExecutePayloadSuccess` ([#19898](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19898)), which revealed a race condition between sequencer funding and validator indexing.
*   **Critical Security & Stability:** 
    *   **Kona-Protocol:** A critical DoS vulnerability in the batch decoder is being addressed. The proposed fix involves replacing `panic!()` calls with robust error handling ([#19334](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19334)).
    *   **State Root Mismatches:** Investigation continues into recurring state root mismatches in `op-reth` on Base mainnet, with potential upstream links to the core Reth repository being explored ([#19532](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19532)).
    *   **Database Integrity:** Issues regarding database preservation and truncation during resyncs (CL/EL) were reopened to address new root causes identified during safe-head matching ([#19661](https://github.com/ethereum-optimism/ethereum-optimism.github.io/issues/19661)).

## 💬 Community & Collaboration
The month was characterized by deep technical collaboration on protocol safety. Notably, community contributors like `zhuzhushiwojia` stepped forward to lead the remediation of the `kona-protocol` DoS vulnerability, providing detailed implementation plans and timelines. There is also active cross-pollination between the Optimism and Reth development communities, as seen in the collaborative debugging of state root mismatches affecting Base mainnet. This synergy highlights the health of the Superchain's open-source contributor base.
