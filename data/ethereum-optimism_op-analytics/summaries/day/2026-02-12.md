## KEY TECHNICAL DEVELOPMENTS

### ClickHouse Stability Improvements
A significant bug fix was implemented to resolve a "concurrent queries within the same session" error in ClickHouse, ensuring more stable and reliable data processing for qualified transactions. This was achieved by creating a new ClickHouse client per thread and safeguarding against empty DataFrames. ([#1794](https://github.com/ethereum-optimism/op-analytics/pull/1794))

### CI/CD Authentication Fix
A critical fix was deployed to address daily CircleCI BigQuery authentication failures. The issue, caused by an overly long `google.subject` in OIDC v2 tokens, was resolved by prioritizing the shorter OIDC v1 token. ([#1793](https://github.com/ethereum-optimism/op-analytics/pull/1793))

## ACTIVE ISSUES

### Kona Hint Format Optimization
Discussion continues on issue [#19125](https://github.com/ethereum-optimism/op-analytics/issues/19125) regarding changing the Kona hint format from string serialization to a binary format. The latest comments highlight a debate on the necessity and benefits of this change. While the proposer aims for "making things right" and potential performance improvements, concerns about backward compatibility and the actual performance impact are being raised. It's noted that the host program must continue to support string versions due to existing games, and the immediate benefits of a binary version are questioned if it doesn't offer significant performance gains.

### Multi-Sequencer RPC Endpoint Support
The discussion on issue [#763](https://github.com/ethereum-optimism/op-analytics/issues/763) revolves around supporting multiple sequencer RPC endpoints for transaction forwarding with automatic failover. The latest comments emphasize the importance of infrastructure-level redundancy, with a contributor arguing that even shared CDN layers can fail, making client-side failover across different CDNs/regions a valuable defense-in-depth. The proposed change is fully backward compatible and aims to prevent outages caused by single endpoint failures, offering reliability improvements for operators who need redundancy.
