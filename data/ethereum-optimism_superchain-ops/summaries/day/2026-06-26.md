## ACTIVE ISSUES

### op-node: Fix compatibility with EIP-4444 enabled L1 node ([#13570](https://github.com/ethereum-optimism/superchain-ops/issues/13570))
A recent comment from Creamers158 on June 26, 2026, asks if the fix for `op-reth v2.3.2` should also be applied to `opnode v1.19.1` for `CheckL2GenesisBlockHash`, indicating ongoing concerns about compatibility with pruned L1 history. The issue describes `op-node` failing when the Rollup L1 Genesis Blockhash is unavailable due to EIP-4444.

### Flaky Test: `TestReorgUnsafeHead` ([#20198](https://github.com/ethereum-optimism/superchain-ops/issues/20198))
On June 26, 2026, geoknee provided a new CI run context for this flaky test, showing an error where the expected head reorg did not occur, with the head hash remaining identical before and after the expected reorg. This suggests the test is waiting for an event that isn't consistently triggered. Previous comments from May 29 and 30, 2026, by wwared and ajsutton, identified a root cause related to stale EL reads under load and proposed a fix in PR #21112, which was validated to resolve the issue in many cases. However, the latest failure indicates that the fix might not be comprehensive or new conditions are causing the flake.
