# ethereum-optimism/superchain-ops Daily Update (Mar 13, 2026)
## OVERVIEW 
Today's development focused on updating dispute game templates to align with U18 OPCM breaking changes. Several issues related to derivation pipeline error handling and Rust documentation hosting were closed.

## KEY TECHNICAL DEVELOPMENTS

### Dispute Game Template Updates
The `addGameType` and `setDisputeGame` templates were updated to reflect breaking changes introduced in U18 OPCM, specifically regarding implied proxies. This ensures compatibility with the latest OPCM specifications. ([#1378](https://github.com/ethereum-optimism/superchain-ops/pull/1378))

## NEWLY OPENED PULL REQUESTS
A new pull request, [#1382](https://github.com/ethereum-optimism/superchain-ops/pull/1382), was opened to address canceling upgrade tasks.

## CLOSED ISSUES

### Derivation Pipeline Robustness
An audit of the derivation pipeline's external-input error handling was completed, ensuring that malformed or bad L1 inputs do not halt derivation and are instead dropped. ([#19491](https://github.com/ethereum-optimism/superchain-ops/issues/19491))

### Batch Queue Behavior
An issue concerning span batch extraction failure in `BatchQueue` returning `Critical` instead of flushing was closed. The decision was made to preserve historical behavior for invalid batch data. ([#19511](https://github.com/ethereum-optimism/superchain-ops/issues/19511))

### Rust Documentation Hosting
The issue regarding Rust Docs Hosting was closed, with the work now captured within the broader docs migration project. ([#1985](https://github.com/ethereum-optimism/superchain-ops/issues/1985))

## NEW ISSUES
No new issues were reported today.

## ACTIVE ISSUES

The issue [#19212](https://github.com/ethereum-optimism/superchain-ops/issues/19212) concerning an `op-reth` database read transaction causing memory leaks is still active. A new comment from 0xForerunner indicates that World Chain v1.10.1 also experienced this issue, leading to node crashes.
