### op-interop-filter: Verdict RPC Blocking
- **Issue:** The `op-interop-filter`'s verdict RPC can block behind the ingester write lock, leading to fail-closed timeouts during slow ingestion ([#21943](https://github.com/ethereum-optimism/superchain-ops/issues/21943)).
- **Latest Update (Aug 12, 2026):** Another occurrence of this defect was observed in `TestInteropFilter_IngressRejectsInvalid` on `memory-all-opn-op-reth-fusaka`. The test failed because `checkAccessList` received no response within the `DEFAULT_REQUEST_TIMEOUT`, resulting in "interop quorum not reached." This behavior is consistent with the verdict path blocking behind the ingester write lock, as the filter component was silent for approximately 2.5 seconds during the query window. If fixed, the transaction would have received a definitive parse error rejection quickly.
