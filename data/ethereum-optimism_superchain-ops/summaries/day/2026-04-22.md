## ACTIVE ISSUES

### Kona Interop Block Access Review
Discussion continues on reviewing access of internally created blocks within `kona-interop` ([#19266](https://github.com/ethereum-optimism/superchain-ops/issues/19266)). The latest comments clarify that while the specific issue of re-querying replaced non-canonical blocks is not a concern, a separate issue was discovered: when a block replacement occurs, its generated receipts are not stored, which can lead to consolidation failures if other messages reference the deposit-only block. A test is being written to confirm this.

### SDM Specifications
The issue regarding adding SDM specifications to `specs.optimism.io` ([#20182](https://github.com/ethereum-optimism/superchain-ops/issues/20182)) received a new comment referencing a pull request in the `design-docs` repository, indicating progress on this front.

### Flaky Test: `TestSequencingWindowExpiry`
Investigation into the flaky `TestSequencingWindowExpiry` test ([#20212](https://github.com/ethereum-optimism/superchain-ops/issues/20212)) revealed a root cause related to a race condition between two writers in `OpProofsExEx`. A draft fix has been opened, which involves adding a write lock to `OpProofsExEx` to eliminate the fatal race. Follow-up actions include addressing the lack of a regression test and a potential state-machine smell with `sync_target_tx`.

### SDM: Move PoC2 Functionality
A comment on the issue to move PoC2 functionality into `develop` ([#20216](https://github.com/ethereum-optimism/superchain-ops/issues/20216)) points to a pull request that will be reviewed, indicating active development.

### Missing Docker Image Tags
An issue was raised regarding missing finalized Docker image tags for `op-reth v2.1.0`, `op-node v1.16.13`, and `kona-node v1.3.0` ([#20228](https://github.com/ethereum-optimism/superchain-ops/issues/20228)). The latest comment explains that the build failed for the finalized tags and advises using the `-rc.1`-suffixed Docker images as a quick fix, which were built from the same commit. The release notes have been updated, and a fix is expected in the next release later this week.
