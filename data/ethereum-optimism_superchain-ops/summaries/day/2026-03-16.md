## ACTIVE ISSUES

### `op-reth` Memory Leak and Sync Stalls
Discussions continued on [#19212](https://github.com/ethereum-optimism/superchain-ops/issues/19212) regarding `op-reth`'s "database read transaction open for too long" warning leading to memory leaks. A user reported experiencing this on World Chain v1.10.1, causing node crashes. The original reporter noted that while they upgraded to `1.11.0`, they encountered other issues and downgraded, eventually switching to a Base fork of `op-reth` for their Base nodes. They also mentioned the issue has occurred twice, with a significant gap between occurrences.

Issue [#19532](https://github.com/ethereum-optimism/superchain-ops/issues/19532) highlights recurring state root mismatches in `op-reth` on Base mainnet, leading to permanent sync stalls and fatal crashes. A user confirmed experiencing the same issue on custom chains like Manta Pacific. An Optimism contributor suggested that since Base recently forked the OP Stack, the issue might be specific to their implementation and recommended opening an issue on the Base repository for further investigation.

### `op-supernode` Acceptance Tests
On [#19403](https://github.com/ethereum-optimism/superchain-ops/issues/19403), which tracks the reinstatement of `interop/activation/...` tests for `op-supernode/acceptance-tests`, a contributor provided additional context.
