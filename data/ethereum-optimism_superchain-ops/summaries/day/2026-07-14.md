## ACTIVE ISSUES

*   **RPC Default Binding Address Discussion**
    *   Issue [#16487](https://github.com/ethereum-optimism/superchain-ops/issues/16487) regarding defaulting RPC to `127.0.0.1` was closed as "not planned." The rationale is that `0.0.0.0` is the correct default for Docker images to ensure reachability, and accidental public exposure is better handled by keeping privileged APIs opt-in rather than by the bind address. Operators can still explicitly set `--rpc.addr=127.0.0.1`.

*   **Kona Host Game Soundness Review**
    *   Issue [#18430](https://github.com/ethereum-optimism/superchain-ops/issues/18430) was reopened due to a remaining TODO in the codebase (`rust/kona/sp1/crates/host/src/fetcher.rs:168`) referencing this issue, specifically regarding adding retries for all requests. This indicates that the initial closure was premature as related work is still pending.

*   **Reth-Optimism-Node Integration Test Flakiness**
    *   Issue [#20973](https://github.com/ethereum-optimism/superchain-ops/issues/20973) continues to track a recurring `SIGSEGV` during teardown of the `peers_negotiate_eth_69` test. Recent comments confirm the flake's recurrence, even on unrelated code changes, causing CI failures. The issue is characterized by the test passing but the binary crashing on drop, suggesting a non-deterministic teardown behavior. A suspected root cause points to a race condition during runtime teardown due to `spawn_critical_os_thread` not being properly joined.

*   **Op-e2e Pre-Regolith Tests and Reth System Tx Return Type**
    *   Issue [#21451](https://github.com/ethereum-optimism/superchain-ops/issues/21451) is being folded into issue #21744, which aims to retire the in-process op-geth L2 EL in op-e2e system tests. The pre-Regolith tests are identified as blocking the deletion of `ELKindOpGeth` and will likely be resolved by their removal, requiring bedrock/regolith co-activation. The issue remains open until the work in #21744 is completed.
