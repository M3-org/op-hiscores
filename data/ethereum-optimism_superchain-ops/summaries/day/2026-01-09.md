# ethereum-optimism/superchain-ops Daily Update (Jan 9, 2026)
## OVERVIEW 
The day saw a critical bug fix addressing incorrect struct field ordering in TOML/JSON parsing, preventing ABI encoding issues. Several acceptance tests related to flashblocks and sequencer failover were closed, deemed to require infrastructure manipulation outside the current scope.

## KEY TECHNICAL DEVELOPMENTS

### Preventing ABI Encoding Errors
A bug fix was implemented to address an issue where Foundry's parsing functions (`parseRaw()`, `parseToml()`, `parseJson()`) alphabetically ordered struct fields, leading to incorrect `abi.decode()` assignments if Solidity struct fields were not in alphabetical order. A new lint rule was added to detect non-alphabetical struct field ordering in TOML/JSON parsing to prevent this issue. ([#1335](https://github.com/ethereum-optimism/superchain-ops/pull/1335))
