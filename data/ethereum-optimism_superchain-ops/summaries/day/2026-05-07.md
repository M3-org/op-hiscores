## ACTIVE ISSUES

### Kona and op-node Brotli Channel Disagreement ([#19333](https://github.com/ethereum-optimism/superchain-ops/issues/19333))
Discussion continues on the divergence between Kona and `op-node` regarding brotli-compressed channels. The latest comments highlight that the Rust `brotli` crate used by Kona is not spec-compliant on certain corrupted inputs, silently accepting them and producing wrong output bytes. This is a consensus-relevant issue as a malicious batcher could craft streams that Go nodes reject but Kona accepts, leading to incorrect batches. An updated path forward proposes landing a Kona wrapper-bug fix to eliminate most divergences, and then switching Kona to a brotli decoder that matches the C reference for the remaining corruption-only cases. The investigation also clarified that both Go libraries behave identically, and a library swap is not necessary if the wrapper fix is applied and the Rust crate's behavior on corrupted inputs is addressed.
