## ACTIVE ISSUES

- **Optimism Sepolia Intrinsic Gas Too High**: Issue [#21457](https://github.com/ethereum-optimism/superchain-ops/issues/21457) was closed today. The latest comment from geoknee confirms that the fix has been merged and is part of the `op-reth/v2.3.3` release. Previous comments from yuercl detailed the bug, noting that `eth_estimateGas` returned "intrinsic gas too high" on OP Sepolia after the Karst update, and that sending with an explicit `gasLimit` succeeded.
- **op-reth: update revm dependency**: Issue [#21524](https://github.com/ethereum-optimism/superchain-ops/issues/21524) remains open. The latest comment from sebastianst indicates that the issue is assigned to @joshklop, but the new release for the `revm` dependency is not yet out. The team plans to revisit this periodically until the release is available.
- **Flaky Test: `TestSupernodeLightSequencerInteropInvalidMessageReplacement`**: Issue [#21635](https://github.com/ethereum-optimism/superchain-ops/issues/21635) was opened today. The latest comment from ajsutton provides a detailed root cause analysis and a proposed fix. The flakiness is attributed to ordering issues between `follow-source` processing, `op-reth` importing/reorging, and queued sequencer build work. The fix involves forcing resets for active sequencers on upstream local-safe advance/divergence and clearing stale sequencer build state.
- **Re-enable or retire fuzzing**: Issue [#21636](https://github.com/ethereum-optimism/superchain-ops/issues/21636) was opened today. The latest comment from geoknee provides a comprehensive audit of existing Go fuzz tests. The decision is to retire all six current PR-time fuzz jobs due to their low value (cold-start exploration, no persisted corpus, sparse seeds) and to keep the fuzz functions running as deterministic seed tests in normal unit-test jobs. A nightly job for fuzzing is only recommended as a scoped follow-up with a committed seed corpus, meaningful fuzz time, and crash-artifact persistence.
