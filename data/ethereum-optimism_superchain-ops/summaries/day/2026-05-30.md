## ACTIVE ISSUES
### Flaky Test: `TestReorgUnsafeHead`
Discussions continued on the flaky `TestReorgUnsafeHead` issue [#20198](https://github.com/ethereum-optimism/superchain-ops/issues/20198). A new CI occurrence of the flake was reported, with the error indicating that the expected unsafe-head reorg never triggered within the 30-attempt window. This occurred while working on a separate change, confirming it as an unrelated flake. Previously, a root cause was identified and a fix was opened in a separate pull request, explaining that the test was picking the next block's parent by reading a mutable and potentially stale EL label, leading to the reorg being silently undone. The proposed fix involves using the `ReorgExact` DSL poll to wait for the divergence height to reorg and then taking the confirmed conflicting block as the explicit parent, along with using `ReorgExact` for the final assertion. Validation showed significant improvement with this fix.
