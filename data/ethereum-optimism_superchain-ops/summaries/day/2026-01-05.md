## ACTIVE ISSUES

### L2 Reorg Due to L1 Reorg
Discussion on [#18676](https://github.com/ethereum-optimism/superchain-ops/issues/18676) highlighted a critical issue in Kona where L2 reorgs can occur due to L1 reorgs. A detailed root cause analysis identified three main problems: L1 Origin Selector caching becoming stale, missing L1 Canonical Validation at L1 Origin, and the absence of a proper reset mechanism during block building in Kona compared to `op-node`. Possible fixes include strengthening Kona's L1 origin selector, adding unit tests for L1 inconsistency cases, revising Kona's reset logic, and enabling more monorepo acceptance tests targeting Kona.

### `eth_simulatev1` Issue
The issue [#739](https://github.com/ethereum-optimism/superchain-ops/issues/739), concerning `eth_simulatev1` returning "error calculating DA footprint: missing deposit transaction" since the Jovian fork, received an update. It was noted that https://github.com/ethereum-optimism/op-geth/pull/732 is aiming to address this critical problem, which impacts transaction simulation in backrunning strategies on OP Stack-based EVM chains.

### `IDisputeGame` Interface Extension
Issue [#18516](https://github.com/ethereum-optimism/superchain-ops/issues/18516), which proposes adding `rootClaim(uint256 l2ChainId)` to the `IDisputeGame` interface for cross-chain interoperability, was reopened. This is due to existing TODOs in the codebase referencing this issue, indicating that further work is required to fully implement and integrate this functionality.
