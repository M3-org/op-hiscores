# ethereum-optimism/superchain-ops Daily Update (Mar 20, 2026)
## OVERVIEW 
Today's development focused on critical bug fixes related to fee vault implementations and the addition of new tasks for Arena-Z fee vault updates. Significant progress was also made in addressing persistent CI flakiness and non-terminating jobs.

A critical bug was fixed in the Arena-Z fee vault implementation, replacing a non-canonical deployment with a bytecode-verified version to correct a typo in a revert string ([#1388](https://github.com/ethereum-optimism/superchain-ops/pull/1388)). ### Resolution of CI Job Non-Termination
The recurring issue of non-terminating CI jobs, specifically `memory-all-opn-op-geth`, was closed today ([#19563](https://github.com/ethereum-optimism/superchain-ops/issues/19563)). ## ACTIVE ISSUES

### Flaky Test: TestCLELDivergence ([#19681](https://github.com/ethereum-optimism/superchain-ops/issues/19681))
Investigation into the `TestCLELDivergence` flake suggests it might be a real bug rather than just a flaky test. The core issue is that the test expects the CL's unsafe head to persist at a target block despite the EL returning `SYNCING`, indicating a stable divergence. However, the derivation pipeline intermittently resets the `StatusTracker`'s `UnsafeL2` back to `startNum+1` due to a `ResetEvent`. The discussion revolves around whether this reset is the correct behavior or if it points to a bug in the reset logic, which the test is catching unreliably. A proposed fix that removes `SyncStatus` polling is being considered, but concerns exist that it might mask a genuine bug if the reset behavior is incorrect.

### Op-Reth: Recurring State Root Mismatch ([#19532](https://github.com/ethereum-optimism/superchain-ops/issues/19532))
The issue of recurring "mismatched block state root" errors causing permanent sync stalls and fatal crashes for `op-reth` archive nodes on Base mainnet remains active. A recent comment suggests a potential link to a known issue in `paradigmxyz/reth` ([#22973](https://github.com/paradigmxyz/reth/issues/22973)). Another comment from March 16th advised opening the issue on the Base repository, as Base has forked the OP Stack, to track if it's a general issue. A user also confirmed experiencing the same issue on custom chains like Manta Pacific.
