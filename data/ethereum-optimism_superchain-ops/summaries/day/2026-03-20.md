# ethereum-optimism/superchain-ops Daily Update (Mar 20, 2026)
## OVERVIEW 
Today's development focused on critical bug fixes related to fee vault implementations and the addition of new tasks for fee recipient updates. Significant progress was also made in addressing persistent CI flakiness and non-terminating jobs, with root cause analyses and proposed fixes.

## KEY TECHNICAL DEVELOPMENTS

### Fee Vault Implementation Fixes and Updates
A critical bug in the Arena-Z fee vault implementation was addressed by replacing a non-canonical source deployment with a bytecode-verified version, correcting a typo in a revert string. This ensures the integrity and correct functioning of fee handling. Additionally, new tasks were introduced to facilitate fee recipient updates for Arena-Z on both Sepolia and Mainnet, leveraging existing templates for efficiency.

## ACTIVE ISSUES

### Persistent Flakiness in Supernode Interop Tests
The issue [#19677](https://github.com/ethereum-optimism/superchain-ops/issues/19677) reports a flaky test, `TestSupernodeInteropInvalidMessageReplacement`, which has shown multiple occurrences in CI. The latest comment confirms another flake in CI job 4640180, with the failure "Condition never satisfied" related to reset detection. This indicates an ongoing challenge in the stability of supernode interop tests.

### Flaky Test: CL-EL Divergence
Issue [#19681](https://github.com/ethereum-optimism/superchain-ops/issues/19681) details a flaky test, `TestCLELDivergence`, where the L2CLB unsafe head does not consistently expose the target block. An investigation update suggests this might be a real bug rather than just flakiness. The core problem lies in the event system processing `UnsafeUpdateEvent` and `ResetEvent` within a single drain cycle, making an intermediate state unobservable. A key question for the team is whether the reset behavior is correct, as it contradicts the test's expectation of a stable CL-EL divergence.

### Op-Reth State Root Mismatch on Base Mainnet
Issue [#19532](https://github.com/ethereum-optimism/superchain-ops/issues/19532) describes recurring "mismatched block state root" errors in op-reth archive nodes on Base mainnet, leading to permanent sync stalls and crashes. The latest comment suggests a potential link to a known issue in the `paradigmxyz/reth` repository. Previous comments also confirm similar issues on custom chains and recommend opening the issue with the Base team for further investigation, indicating a broader concern with op-reth stability.
