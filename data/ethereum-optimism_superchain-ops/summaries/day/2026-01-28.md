# ethereum-optimism/superchain-ops Daily Update (Jan 28, 2026)
## OVERVIEW 
The day saw significant activity in preparing for future upgrades and refining development processes. Key efforts included adding a rehearsal for signer removal, upgrading Foundry dependencies, and establishing simulation requirements for task PR submissions. Several issues related to protocol upgrades and artifact management were closed.

## KEY TECHNICAL DEVELOPMENTS

## NEWLY OPENED PULL REQUESTS
- **OPSC Rehearsal and Foundry Upgrade**: A new pull request, [#1359](https://github.com/ethereum-optimism/superchain-ops/pull/1359), was opened to add an OPSC Rehearsal for removing a signer. Additionally, [#1358](https://github.com/ethereum-optimism/superchain-ops/pull/1358) proposes an upgrade of Foundry dependencies to v1.4.3.

- **Artifact Resource Locator Resolved**: Issue [#18633](https://github.com/ethereum-optimism/superchain-ops/issues/18633), which aimed to add a Resource Locator for v7_0_0 artifacts, was closed as the referenced file was later deleted.

## ACTIVE ISSUES

- **op-supernode: Introduce SyncStatus API** ([#18947](https://github.com/ethereum-optimism/superchain-ops/issues/18947)): Discussions on this issue focused on defining the scope of the SyncStatus API. It was decided that the interface should include the `op-node` SyncStatus for every chain, the sync status of every verification activity, and for interop activity, the latest verified timestamp and the current L1. The latest verified L2 should also be reported to simplify acceptance testing.
- **contracts: Prove withdrawals using chain-specific root claim** ([#18517](https://github.com/ethereum-optimism/superchain-ops/issues/18517)): The discussion revolved around the dependency on the U19 upgrade and the `FaultDisputeGames` supporting a new `rootClaimByChainId(uint256)` method. It was decided to move this issue to the backlog as the `OptimismPortal2` cannot be updated until U19 is executed, and the upgrade must be separate from the `FaultDisputeGame` upgrade to ensure continuous withdrawal functionality.
- **op-alloy: Fix EIP-1559 params decoding** ([#18951](https://github.com/ethereum-optimism/superchain-ops/issues/18951)): The issue aims to properly catch zero elasticities during EIP-1559 parameter decoding at the `op-alloy` level. A contributor expressed interest in taking on this task.
