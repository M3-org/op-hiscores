# ethereum-optimism/superchain-ops Daily Update (Jan 23, 2026)
## OVERVIEW 
The day's development focused on a critical bug fix for the SuperchainAddressRegistry to support op-contracts v6.0.0, alongside enhancements to the `just sign-stack` command for improved security. An OPSC R1 welcome rehearsal was also added.

## KEY TECHNICAL DEVELOPMENTS

### Superchain Address Registry Update
A bug fix was implemented in the `SuperchainAddressRegistry.sol` to support `op-contracts v6.0.0 gameArgs` and mark a specific U18-uni sepolia task as executed. This involved a significant refactor to simplify the code. ([#1353](https://github.com/ethereum-optimism/superchain-ops/pull/1353))

### Enhanced Signing Security
The `just sign-stack` command was updated to include a check ensuring the signer is an owner of the safe, mirroring the existing check in `just sign` for improved security. ([#1354](https://github.com/ethereum-optimism/superchain-ops/pull/1354))

### Rehearsal Configuration
A new rehearsal configuration was added for the OPSC R1 welcome, scheduled for January 2026. ([#1350](https://github.com/ethereum-optimism/superchain-ops/pull/1350))

## NEWLY OPENED PULL REQUESTS
- A new feature pull request, [#1356](https://github.com/ethereum-optimism/superchain-ops/pull/1356), was opened to add a betanet task for revshare.

## CLOSED ISSUES
- **L1 Beacon Client Logging**: Issue [#17749](https://github.com/ethereum-optimism/superchain-ops/issues/17749) regarding emitting a log when the L1 beacon client falls back to a sidecar endpoint was closed. The resolution indicates that the fallback mechanism itself might be removed.

## NEW ISSUES
No new issues were reported for this day.

## ACTIVE ISSUES

### Kona Integration of op-succinct Changes
Issue [#18457](https://github.com/ethereum-optimism/superchain-ops/issues/18457) concerns integrating `op-succinct` changes into Kona. The latest comment indicates that this task is being moved back to the backlog, as the `kona-sp1` PR in `op-rs` requires rebasement on the monorepo.

### Devstack Supernode Support for op-challenger
Issue [#18911](https://github.com/ethereum-optimism/superchain-ops/issues/18911) tracks the effort to update the `op-challenger` setup in devstack to utilize the supernode, with configurability for gradual migration. The latest comment notes that this task is dependent on issue #18920.
