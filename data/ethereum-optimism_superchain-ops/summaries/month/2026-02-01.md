# ethereum-optimism/superchain-ops Monthly Report (February 2026)

## 🚀 Highlights
In February 2026, development focused heavily on refining the operational readiness of the Superchain through critical network upgrades and security rehearsals. Significant progress was made in standardizing task submission workflows and preparing for the Optimism Security Council's third rehearsal involving nested upgrade scenarios. Technical discussions centered on the architectural alignment of `op-supernode` and the nuances of Execution Layer (EL) synchronization, reflecting a concerted effort to harden protocol security and cross-chain interoperability.

## 🛠️ Key Developments

### Network Upgrades & Betanet Functionality
A primary focus this month was the deployment and configuration of the U18 upgrade across various testnets.
*   **RevShare Integration:** Added new tasks for Sepolia to upgrade and configure RevShare functionality for the `revshare-beta-1` chain, including comprehensive validation documents and TOML configurations ([#1365](https://github.com/ethereum-optimism/superchain-ops/pull/1365)).
*   **Soneium Minato Support:** Initiated Sepolia task 065 to implement the U18 upgrade on the Soneium Minato testnet ([#1370](https://github.com/ethereum-optimism/superchain-ops/pull/1370)).
*   **General Maintenance:** Introduced general Sepolia tasks and a new template for handling multiple rotations ([#1369](https://github.com/ethereum-optimism/superchain-ops/pull/1369), [#1368](https://github.com/ethereum-optimism/superchain-ops/pull/1368)).

### Security & Governance Operations
Operational security remains a top priority, with specific efforts directed toward rehearsal and process standardization.
*   **Security Council Rehearsals:** Prepared environment files, address registries, and configurations for the Security Council’s third rehearsal, specifically testing nested upgrade scenarios ([#1367](https://github.com/ethereum-optimism/superchain-ops/pull/1367)).
*   **Task Submission Standards:** Updated `NEW_TASK_GUIDE.md` to include a "Before Submitting Your Task for Review" section. This mandates specific simulation requirements for task authors to ensure higher quality and safety in underwritten tasks ([#1357](https://github.com/ethereum-optimism/superchain-ops/pull/1357)).

## 🐛 Issues & Triage

### Closed Issues
*   **`op-supernode` L1 Polling:** Resolved a critical issue where HTTP L1 URLs were disabling polling, which previously prevented virtual nodes from receiving L1 head updates ([#19012](https://github.com/ethereum-optimism/superchain-ops/issues/19012)).
*   **Interop Proof Tests:** Briefly reopened and re-closed issues regarding skipped acceptance tests for interop proofs to verify "TODO" checker automation and track backlog items for explicit output root support ([#18616](https://github.com/ethereum-optimism/superchain-ops/issues/18616)).

### New & Active Issues
*   **`op-supernode` Architecture:** Ongoing debate regarding "Safe Label Adjusting" ([#18976](https://github.com/ethereum-optimism/superchain-ops/issues/18976)). The community is weighing whether the `op-supernode` should directly control EL labels or if the Consensus Layer (CL) should remain the sole controller to avoid stateful conflicts. Additionally, a new discussion was opened regarding the utility of returning "Unsafe SuperRoots" when verified data is unavailable ([#19059](https://github.com/ethereum-optimism/superchain-ops/issues/19059)).
*   **EL Sync Correctness:** Significant technical discussion persists regarding `op-node` behavior during initial sync. Developers are addressing a bug where the EL might consider a block finalized before derivation is fully verified ([#17631](https://github.com/ethereum-optimism/superchain-ops/issues/17631)).
*   **Infrastructure & Tooling:** Investigation continues into CI failures caused by RPC "block out of range" errors during fork testing ([#17688](https://github.com/ethereum-optimism/superchain-ops/issues/17688)) and a `BlockNotFoundError` in the ETH bridge tutorial suggesting a gap in Viem’s withdrawal validation ([#1956](https://github.com/ethereum-optimism/superchain-ops/issues/1956)).
