# ethereum-optimism/docs Daily Update (Apr 6, 2026)
## OVERVIEW 
The documentation repository was deprecated today, with all content moved to a new location. Several issues related to supernode L1 reorg handling were closed, and new flaky test reports emerged.

## KEY TECHNICAL DEVELOPMENTS

### Documentation Repository Deprecation
The `docs` repository has been deprecated, and all documentation content has been moved to a new location within the `optimism` repository. This change streamlines the documentation process and centralizes resources. ([#2019](https://github.com/ethereum-optimism/docs/pull/2019))

## CLOSED ISSUES

### Supernode L1 Reorg Handling Improvements
Several issues concerning the supernode's behavior during L1 reorgs have been resolved. These include clearing verifications and denied blocks on L1 reorgs ([#19245](https://github.com/ethereum-optimism/docs/issues/19245)), pruning the interop database ([#19287](https://github.com/ethereum-optimism/docs/issues/19287)), and pruning the denylist ([#19289](https://github.com/ethereum-optimism/docs/issues/19289)). These improvements enhance the supernode's consistency and reliability during blockchain reorganizations, primarily addressed by the implementation of WAL (Write-Ahead Logging).
