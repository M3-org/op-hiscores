## ACTIVE ISSUES

### op-deployer Transaction Gas Limit
Discussion on [#17912](https://github.com/ethereum-optimism/docs/issues/17912) continued regarding `op-deployer:v0.2.6` failing to deploy contracts due to "transaction gas limit too high." The latest comment from @RISHABHAGRAWALZRA asks if the issue is fixed and which `op-deployer` version to use for alt-da. Previous comments confirmed the issue is due to the EIP-7825 transaction gas limit cap and suggested using `v0.5.0*` for the latest contract release, though it's still a release candidate.

### op-batcher Rollup Config Synchronization
The discussion on [#18178](https://github.com/ethereum-optimism/docs/issues/18178) focuses on the `op-batcher` not re-fetching the rollup config after startup, leading to potential desynchronization. @geoknee suggested treating this as a critical error and restarting the process, allowing the batcher to reload the config. Earlier suggestions included making the operator explicitly provide the rollup config to the batcher or having the active endpoint provider signal when the active endpoint changes to trigger a reload.

### Sequencer-Defined Metering Design Doc
Issue [#360](https://github.com/ethereum-optimism/docs/issues/360) saw an update from @joshklop, expanding the scope to include the initial Proof of Concept (PoC) as it's currently blocking the design document. The initial devnet deployment is planned for January 30, 2026, after which the design can be evaluated and basic benchmarking performed.
