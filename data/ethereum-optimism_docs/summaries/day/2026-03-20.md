## ACTIVE ISSUES

**Flaky Test: TestSupernodeInteropInvalidMessageReplacement**
Issue [#19677](https://github.com/ethereum-optimism/docs/issues/19677) reports a flaky test, `TestSupernodeInteropInvalidMessageReplacement`, in `op-acceptance-tests/tests/supernode/interop/reorg`. The latest comment confirms another flake occurrence in CI job [4640180](https://app.circleci.com/pipelines/github/ethereum-optimism/optimism/120267/workflows/3af4e577-a6d0-4c64-84df-fd56653c305e/jobs/4640180), with the failure "Condition never satisfied" related to reset detection.

**Flaky Test: TestCLELDivergence**
Issue [#19681](https://github.com/ethereum-optimism/docs/issues/19681) highlights a flaky test, `TestCLELDivergence`, where the L2CLB unsafe head did not expose the target block. The latest comment provides an in-depth investigation, suggesting this might be a real bug rather than just a flake. The core problem lies in the event system processing `UnsafeUpdateEvent` and `ResetEvent` within a single drain cycle, making an intermediate state unobservable. A key question for the team is whether the reset behavior in step 3 of the event processing is correct, as it contradicts the test's expectation of a stable CL-EL divergence.

**Op-Reth State Root Mismatch**
Issue [#19532](https://github.com/ethereum-optimism/docs/issues/19532) describes recurring "mismatched block state root" errors in `op-reth` archive nodes on Base mainnet, leading to permanent sync stalls and fatal crashes. The latest comment suggests a potential link to `paradigmxyz/reth#22973`. Previous comments confirm similar issues on custom chains and recommend opening an issue with Base for further investigation.
