## ACTIVE ISSUES

### Flaky Test: TestCLELDivergence
Issue [#19681](https://github.com/ethereum-optimism/docs/issues/19681) discusses a flaky test `TestCLELDivergence`. The latest comment from `ajsutton` provides an in-depth investigation update, suggesting it might be a real bug rather than just a flaky test. The core finding is a divergence between the CL and EL, where the CL's unsafe head is reset despite the EL returning `SYNCING`. The discussion questions whether this reset behavior is correct, as the test expects the divergence to persist. A proposed fix that removes `SyncStatus` polling is noted, with concerns that it might mask a real bug if the reset logic is indeed flawed.

### op-reth State Root Mismatch
Issue [#19532](https://github.com/ethereum-optimism/docs/issues/19532) reports recurring state root mismatches in `op-reth` on Base mainnet, leading to sync stalls and crashes. The latest comment from `ngotchac` suggests a potential link to a `reth` issue ([paradigmxyz/reth#22973](https://github.com/paradigmxyz/reth/issues/22973)). Previous comments confirm similar issues on custom chains and advise opening the issue on the Base repository for further investigation.

### Flaky Test: TestSupernodeInteropInvalidMessageReplacement
Issue [#19677](https://github.com/ethereum-optimism/docs/issues/19677) reports a flaky test `TestSupernodeInteropInvalidMessageReplacement`. The latest comment from `ajsutton` confirms another flake occurrence in CI, with the failure being "Condition never satisfied" related to a reset not being detected. This test has shown multiple flakes on the `main` workflow.
