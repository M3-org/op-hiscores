## ACTIVE ISSUES

### Kona and op-node Discrepancies
Discussions continued on issues related to Kona and op-node. One issue highlights how Kona and op-node can disagree on brotli channels, with a team member volunteering to investigate ([#19333](https://github.com/ethereum-optimism/docs/issues/19333)). Another issue points out that unknown batch types can cause panics and denial of service in kona-protocol, with a team member also offering to work on a fix ([#19334](https://github.com/ethereum-optimism/docs/issues/19334)). Additionally, a discrepancy in Kona frame parsing against op-node and OP Stack Specs was noted, with a team member requesting more details to address it ([#19335](https://github.com/ethereum-optimism/docs/issues/19335)).

### Kona Source Code Cleanup
An issue concerning orphaned `sources/variant.rs` in `kona-derive` was discussed. A team member offered to fix the issue, but it was noted that a pull request addressing this has already been submitted ([#19340](https://github.com/ethereum-optimism/docs/issues/19340)).

### L2CM Access Control
Discussion on adding `ProxyAdminOwnedBase` access control to predeploy `initialize()` functions in L2CM continued. A suggestion was made to reference the PR that added this functionality to L1 contracts as a guide ([#19313](https://github.com/ethereum-optimism/docs/issues/19313)).
