## ACTIVE ISSUES

### Withdrawal Proofs and Protocol Upgrades
Discussion on [#18517](https://github.com/ethereum-optimism/docs/issues/18517) regarding proving withdrawals using chain-specific root claims indicates that while `OptimismPortalInterop` changes are complete, updating `OptimismPortal2` must wait for the U19 execution. This is to ensure withdrawals continue to function immediately post-upgrade, requiring the `OptimismPortal2` upgrade to occur separately and after `FaultDisputeGames` support the new `rootClaimByChainId(uint256)` method.

### `op-supernode` SyncStatus API Definition
On [#18947](https://github.com/ethereum-optimism/docs/issues/18947), the `SyncStatus` API for `op-supernode` is being defined. The latest comments suggest the interface should include the `op-node` SyncStatus for every chain and the sync status of every verification activity. For interop activity, this includes the latest verified timestamp and the current L1. Additionally, SyncStatus should report on the latest verified L2 to simplify acceptance testing.

### `op-alloy` EIP-1559 Parameter Decoding
Issue [#18951](https://github.com/ethereum-optimism/docs/issues/18951) focuses on fixing EIP-1559 parameter decoding in `op-alloy` to properly catch zero elasticities early. A contributor has expressed interest in taking on this task.
