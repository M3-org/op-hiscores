## ACTIVE ISSUES

### SyncStatus API for op-supernode
Discussion on [#18947](https://github.com/ethereum-optimism/docs/issues/18947) regarding the `op-supernode: Introduce SyncStatus API` continued. The latest comments suggest the correct interface should include the `op-node` SyncStatus of every chain and the sync status of every verification activity. For interop activity, its status should include the latest verified timestamp and the current L1. It was also noted that SyncStatus should report on the latest verified L2 to simplify acceptance tests.

### EIP-1559 Parameters Decoding in op-alloy
On [#18951](https://github.com/ethereum-optimism/docs/issues/18951), which addresses `op-alloy: Fix EIP-1559 params decoding`, a community member expressed interest in taking on the task, indicating ongoing attention to this bug fix.

### Proving Withdrawals with Chain-Specific Root Claim
Issue [#18517](https://github.com/ethereum-optimism/docs/issues/18517), concerning `contracts: Prove withdrawals using chain-specific root claim`, was moved to the backlog. The latest comment explains that while `OptimismPortalInterop` changes are done, `OptimismPortal2` cannot be updated until U19 is executed. This change must be executed well after `FaultDisputeGames` support the new `rootClaimByChainId(uint256)` method to avoid withdrawal delays for users.
