## ACTIVE ISSUES
### L1 Reorg Handling in Kona
Discussion on [#18676](https://github.com/ethereum-optimism/docs/issues/18676) provided a detailed root cause analysis of L2 reorgs due to L1 reorgs in Kona. The analysis identified three key issues: L1 Origin Selector caching not refreshing stale values, missing L1 Canonical Validation at L1 Origin, and the absence of a proper reset mechanism during block building when L1 inconsistency is detected. Possible fixes include strengthening Kona's L1 origin selector, adding unit tests for L1 inconsistency cases, and revising the reset logic.

### `eth_simulatev1` Issue
The issue regarding `eth_simulatev1` returning "error calculating DA footprint: missing deposit transaction" since the Jovian fork ([#739](https://github.com/ethereum-optimism/docs/issues/739)) received an update. It was noted that a pull request ([#732](https://github.com/ethereum-optimism/op-geth/pull/732)) in the `op-geth` repository is aiming to fix this critical problem, which affects transaction simulation in backrunning strategies.

### `IDisputeGame` Interface Extension
Issue [#18516](https://github.com/ethereum-optimism/docs/issues/18516), concerning the addition of `rootClaim(uint256 l2ChainId)` to the `IDisputeGame` interface, was reopened. The reason for reopening is the presence of remaining TODOs in the code referencing this issue, specifically in `ISuperFaultDisputeGame.sol` and `ISuperPermissionedDisputeGame.sol`. The maintainer confirmed they would address these remaining tasks.
