## ACTIVE ISSUES

**Discussion on Binary Hint Format for Kona Hints**
Discussion continued on [#19125](https://github.com/ethereum-optimism/docs/issues/19125) regarding the proposal to use a binary format for Kona hints instead of string serialization. The latest comment from kien-rise acknowledged the need for the host program to continue supporting string versions for backward compatibility with existing games. This followed ajsutton's point that the string encoding works well and simplifies debugging, and that a significant performance benefit would be needed to justify a change with backward compatibility requirements. kien-rise clarified that the motivation was primarily about "making things right" rather than speed, but expected performance improvements.

**Sequencer RPC Endpoint Redundancy**
The discussion on [#763](https://github.com/ethereum-optimism/docs/issues/763) about supporting multiple sequencer RPC endpoints for transaction forwarding saw a new comment from brendontan03. They emphasized that while infrastructure-level redundancy is ideal, client-side failover across different CDNs/regions adds defense-in-depth, citing past Cloudflare outages. This was in response to ajsutton's earlier concern that supporting multiple URLs might be user-unfriendly and that reliability should ideally be built into a single URL by the sequencer operator. brendontan03 also reiterated that the proposed change is fully backward compatible and provides optional reliability improvements.
