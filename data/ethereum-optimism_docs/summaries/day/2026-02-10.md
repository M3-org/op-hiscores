### Support for Multiple Sequencer RPC Endpoints
Discussion on issue [#763](https://github.com/ethereum-optimism/docs/issues/763) revolves around supporting multiple sequencer RPC endpoints for transaction forwarding with automatic failover. While the proposed change is backward compatible and aims to prevent outages caused by single endpoint failures, concerns were raised about the user-friendliness of requiring multiple URLs for reliability. It was suggested that leveraging existing web2 reliability standards for a single URL might be a better approach.
