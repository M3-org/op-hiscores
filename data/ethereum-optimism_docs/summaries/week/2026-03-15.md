# ethereum-optimism/docs Weekly Report (Mar 15 - 21, 2026)

## 🚀 Highlights
This week focused on a significant streamlining of the documentation architecture and a rigorous stabilization of the CI pipeline. Major updates included the removal of outdated SuperchainERC20 and U19 upgrade references to make way for the upcoming Remote Controlled Token (RCT) standard. Parallel to these content updates, the team successfully resolved a high volume of flaky tests and addressed critical synchronization logic within the `op-node` and `op-supernode` components. These efforts collectively improve the developer experience by ensuring documentation accuracy and increasing the reliability of the project's automated testing infrastructure.

## 🛠️ Key Developments

### Documentation Refactoring & Standards Alignment
The documentation underwent a cleanup phase to ensure alignment with the evolving Superchain ecosystem.
*   **Standardization:** Outdated references to SuperchainERC20 were removed in anticipation of the new Remote Controlled Token (RCT) standard ([#2003](https://github.com/ethereum-optimism/docs/pull/2003)).
*   **Deprecation:** Notices for the U19 upgrade and revenue sharing guides were deleted as their technical scope has shifted, reducing maintenance overhead and potential developer confusion ([#2002](https://github.com/ethereum-optimism/docs/pull/2002)).

### CI Stability and Test Infrastructure
A concerted effort was made to address non-deterministic test failures that were impacting development velocity.
*   **Flaky Test Remediation:** Developers investigated and resolved multiple race conditions and timeout issues across the codebase. Key fixes targeted nonce races, sync propagation delays, and environment-specific setup failures ([#18137](https://github.com/ethereum-optimism/docs/issues/18137), [#19588](https://github.com/ethereum-optimism/docs/issues/19588)).
*   **Test Deduplication:** Work began on streamlining the `op-e2e` suite. A new draft PR ([#19622](https://github.com/ethereum-optimism/docs/pull/19622)) removes redundant tests now covered by the shared `superfaultproofs` package, reducing the testing footprint while maintaining coverage.

### Protocol & Node Logic Improvements
Technical refinements were made to the core node software to improve reporting and synchronization accuracy.
*   **Supernode Reporting:** Fixed an issue where `op-supernode` incorrectly reported the current derived L1 instead of the verified L1 ([#18651](https://github.com/ethereum-optimism/docs/issues/18651)).
*   **Interoperability:** Progress continued on the `kona-interop` block hash oracle, with the team focusing on verifying block lookups prior to the current history window ([#18288](https://github.com/ethereum-optimism/docs/issues/18288)).

## 🐛 Issues & Triage

### Closed Issues
*   **Test Stability:** A significant cluster of flaky tests was closed following successful patches, including `TestBreakTimestampInvariant`, `TestExpiredMessage`, and `TestExecMsgDifferTxIndex`.
*   **Gas Pricing Research:** The investigation into Glamsterdam gas pricing impacts on precompile acceleration was concluded, with future optimizations moved to a dedicated tracking issue ([#19375](https://github.com/ethereum-optimism/docs/issues/19375)).

### New & Active Issues
*   **Execution Layer (EL) Sync UX:** A high-priority discussion is ongoing regarding `op-node` marking EL sync targets as finalized prematurely. Contributors are debating the use of trusted checkpoint providers versus arbitrary delays to mitigate risks in light client and interop scenarios ([#17631](https://github.com/ethereum-optimism/docs/issues/17631)).
*   **CI Resource Management:** The team is monitoring a non-terminating CI job (`memory-all-opn-op-geth`) that may be resolved by pending PRs; a re-evaluation is scheduled for the coming days ([#19563](https://github.com/ethereum-optimism/docs/issues/19563)).
*   **New Flakes:** New tracking issues were opened for `TestSupernodeInteropChainLag` and `TestUnsafeChainNotStalling`, indicating continued vigilance regarding CI health ([#19610](https://github.com/ethereum-optimism/docs/issues/19610), [#19608](https://github.com/ethereum-optimism/docs/issues/19608)).
