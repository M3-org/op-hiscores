# ethereum-optimism/docs Weekly Report (Feb 22 - 28, 2026)

## 🚀 Highlights
This week focused on streamlining the documentation lifecycle through the archiving of legacy notices and the preparation of new deprecation guides. Technical discussions centered on refining the operational standards for the Superchain, specifically regarding Superroot Service Level Agreements (SLAs) and post-Holocene batcher logic. While maintenance tasks dominated the pull request activity, the community remains deeply engaged in resolving complex cross-repo technical issues related to protocol upgrades and RPC performance.

## 🛠️ Key Developments

### Documentation Lifecycle & Maintenance
Efforts this week were primarily directed toward keeping the documentation current by removing outdated information and preparing for upcoming software changes.
*   **Legacy Archiving:** The team successfully archived the Upgrade 18 notice. This involved moving the content to an archive directory, implementing necessary redirects, and cleaning up UI callouts to ensure a cleaner user experience ([#1986](https://github.com/ethereum-optimism/docs/pull/1986)).
*   **Deprecation Planning:** New documentation is being drafted to address the deprecation of `op-geth`, ensuring developers have clear guidance on transitioning away from legacy components ([#1988](https://github.com/ethereum-optimism/docs/pull/1988)).

## 🐛 Issues & Triage

### Closed Issues
*   **RPC Performance:** An issue regarding `eth_getLogs` memory exhaustion and general RPC performance was triaged and closed as a duplicate, consolidating the effort into a single tracking thread ([#769](https://github.com/ethereum-optimism/docs/issues/769)).

### New & Active Issues
*   **Superchain Infrastructure (op-supernode):** Significant discussion continues regarding the SLA for the Superroot object. The current consensus suggests that Optimistic Roots should be treated as a "best-effort" service, where missing data is represented by empty values rather than stalling the process ([#19180](https://github.com/ethereum-optimism/docs/issues/19180)).
*   **Protocol Logic (op-batcher):** A bug was identified where `op-batcher` fails to correctly handle post-Holocene ordering when running in concurrent mode. This issue is closely linked to ongoing protocol-level fixes in the main optimism repository ([#18507](https://github.com/ethereum-optimism/docs/issues/18507)).

## 💬 Community & Collaboration
Collaboration this week was characterized by cross-repository coordination. Contributors like **kien-rise** and **axelKingsley** provided critical technical insights that bridge the gap between protocol implementation and documentation. The activity on issues like [#18507](https://github.com/ethereum-optimism/docs/issues/18507) demonstrates a tight feedback loop between the core developers working on the OP Stack and the maintainers of the documentation, ensuring that technical nuances of the Holocene upgrade are accurately captured for the community.
