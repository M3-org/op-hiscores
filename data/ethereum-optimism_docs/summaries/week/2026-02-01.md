# ethereum-optimism/docs Weekly Report (Feb 1 - 7, 2026)

## 🚀 Highlights
This week focused on refining node operations documentation and improving the accuracy of setup guides for the OP Stack. Key efforts included addressing missing configurations in rollup setup tutorials and updating snapshot documentation to reflect the current state of `op-reth`. Technical discussions centered on protocol-level enhancements, specifically regarding Flashblocks support in Geth and the architectural management of safe labels within the `op-supernode`. Additionally, the team completed its monthly performance audit by finalizing metrics reports for January 2026.

## 🛠️ Key Developments
While no major pull requests were merged this week, several critical documentation improvements were initiated to enhance the developer experience:

### Node Operations & Snapshots
Efforts are underway to ensure node operators have access to accurate synchronization data and setup instructions.
*   **Reth Snapshots:** A new pull request was opened to address `op-reth` snapshots, ensuring documentation aligns with current availability ([#1976](https://github.com/ethereum-optimism/docs/pull/1976)).
*   **Rollup Setup Accuracy:** Documentation for rollup setup is being patched to include missing fee vault recipients, a critical step for correct chain deployment ([#1972](https://github.com/ethereum-optimism/docs/pull/1972)).

## 🐛 Issues & Triage
The week saw a mix of administrative cleanup and deep technical troubleshooting regarding cross-chain interactions.

*   **Closed Issues:** The team successfully finalized the January 2026 metrics reporting, closing issues related to tracking pull request and issue response times ([#1967](https://github.com/ethereum-optimism/docs/issues/1967), [#1968](https://github.com/ethereum-optimism/docs/issues/1968)).
*   **New & Active Issues:**
    *   **Documentation Restructuring:** A new issue was opened to relocate the OP Mainnet Node Snapshot page to its correct section and update it with current `op-reth` details ([#1973](https://github.com/ethereum-optimism/docs/issues/1973)).
    *   **Bridge Troubleshooting:** Investigation continues into a `BlockNotFoundError` within the ETH bridge tutorial.     *   **Protocol Architecture:** Significant discussion persists regarding `op-supernode` safe label adjusting. The community is weighing an approach where the Consensus Layer (CL) remains the sole engine controller to manage the complexity of stateful pointers ([#18976](https://github.com/ethereum-optimism/docs/issues/18976)).

## 💬 Community & Collaboration
Collaboration this week was characterized by high-level technical contributions from the community, particularly regarding execution client features. Users are actively advocating for the integration of Flashblocks into `op-geth` to mitigate the high disk space requirements of archive versions of Reth. Notably, contributor **maoueh** shared a custom version of `op-geth` featuring Firehose Live Tracer and Flashblock support, demonstrating proactive community-led development and testing of experimental features ([#756](https://github.com/ethereum-optimism/docs/issues/756)).
