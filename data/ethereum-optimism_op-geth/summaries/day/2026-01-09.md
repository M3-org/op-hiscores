# ethereum-optimism/op-geth Daily Update (Jan 9, 2026)
## OVERVIEW 
The day saw significant updates with the merging of go-ethereum v1.16.5, alongside improvements to code generation checks and EIP-1559 parameter validation. Several acceptance test issues related to flashblocks and sequencer failover were closed.

## KEY TECHNICAL DEVELOPMENTS

*   **Go-Ethereum Core Update**: The repository was updated to merge go-ethereum v1.16.5, incorporating numerous changes across various core components including `cmd/evm`, `core/rawdb`, `cmd/devp2p`, and `core/txpool`. ([#726](https://github.com/ethereum-optimism/op-geth/pull/726))
*   **Code Generation and EIP-1559 Enhancements**: Improvements were made to the `check_generate` script to ensure it considers `eth/ethconfig`, and a new requirement for non-zero elasticity in Holocene EIP-1559 parameters was added and tested. ([#741](https://github.com/ethereum-optimism/op-geth/pull/741), [#743](https://github.com/ethereum-optimism/op-geth/pull/743))

## CLOSED ISSUES

*   **Flashblocks and Sequencer Failover Acceptance Tests**: Several acceptance test issues related to flashblocks, sequencer failover, and rbuilder failures were closed, primarily due to the realization that these tests would require infrastructure manipulation, which was scoped out of op-acceptance-tests. ([#316](https://github.com/ethereum-optimism/op-geth/issues/316), [#314](https://github.com/ethereum-optimism/op-geth/issues/314), [#318](https://github.com/ethereum-optimism/op-geth/issues/318), [#317](https://github.com/ethereum-optimism/op-geth/issues/317), [#350](https://github.com/ethereum-optimism/op-geth/issues/350))

*   **Validation Checks Error**: An issue concerning errors during validation checks on all chains, specifically a "concurrent map read and map write" error, was closed as it is no longer an issue. ([#668](https://github.com/ethereum-optimism/op-geth/issues/668))
