# ethereum-optimism/op-geth Daily Update (Jan 9, 2026)
## OVERVIEW 
Today's development focused on a significant Go-Ethereum merge, updating the codebase to v1.16.5, alongside critical updates to EIP-1559 parameters for Holocene. Several acceptance test issues related to flashblocks and sequencer failover were closed.

## KEY TECHNICAL DEVELOPMENTS

*   **Go-Ethereum Core Update**: The repository underwent a substantial merge of `go-ethereum` v1.16.5, impacting numerous core components including `accounts`, `beacon`, `cmd`, `core`, and `eth` directories. This update brings the `op-geth` codebase in line with the latest upstream `go-ethereum` developments. ([#726](https://github.com/ethereum-optimism/op-geth/pull/726))
*   **EIP-1559 Parameter Enforcement**: A new requirement was introduced for EIP-1559 parameters in Holocene, specifically enforcing a non-zero elasticity. This change includes a new unit test to ensure proper validation. ([#743](https://github.com/ethereum-optimism/op-geth/pull/743))
*   **CI Generation Check Enhancement**: The CI pipeline was updated to include a `check_generate` step, addressing a previous oversight where `eth/ethconfig` was not considered, improving the robustness of code generation checks. ([#741](https://github.com/ethereum-optimism/op-geth/pull/741))

## NEWLY OPENED PULL REQUESTS
No new pull requests were opened today.

## CLOSED ISSUES

*   **Flashblocks and Sequencer Failover Acceptance Tests**: Several acceptance test issues related to flashblocks, sequencer failover, and `rollup-boost` functionality were closed. These issues were deemed to require infrastructure manipulation, which was scoped out of `op-acceptance-tests`. ([#316](https://github.com/ethereum-optimism/op-geth/issues/316), [#314](https://github.com/ethereum-optimism/op-geth/issues/314), [#318](https://github.com/ethereum-optimism/op-geth/issues/318), [#317](https://github.com/ethereum-optimism/op-geth/issues/317), [#350](https://github.com/ethereum-optimism/op-geth/issues/350))
*   **Flashblocks Load Tests**: An acceptance test for flashblocks load testing was closed, with the rationale that it is now scoped under the Benchmarking Milestone for future nightly automations. ([#379](https://github.com/ethereum-optimism/op-geth/issues/379))
*   **Validation Checks Error**: An issue concerning errors during validation checks on all chains, specifically a `concurrent map read and map write` error, was closed as it is no longer an issue. ([#668](https://github.com/ethereum-optimism/op-geth/issues/668))
