## ACTIVE ISSUES

### op-node: On the Initial EL Sync UX and Correctness ([#17631](https://github.com/ethereum-optimism/op-geth/issues/17631))
Discussions continued regarding the behavior of `op-node` marking the reached target as finalized after initial EL Sync, even if the block is not actually finalized. `trianglesphere` noted that snap sync only works if a state snapshot is available and `geth` only stores snapshots within 128 blocks of its tip, making snap sync to the unsafe head necessary. `axelKingsley` suggested that Snap Sync should follow the finalized L2 as a maximum target, then resume full sync for the range from finalization to tip. `sebastianst` agreed that the current behavior is buggy and proposed running derivation from a prior L1 block and then consolidation to verify alignment with the EL-synced unsafe chain. He also suggested fixing the code to only advance the unsafe ref while keeping safe and finalized at genesis, with a plan for the transition.

### Enable skipped acceptance tests for interop proofs ([#18616](https://github.com/ethereum-optimism/op-geth/issues/18616))

This test remains skipped with a note to enable it once the super DG supports explicit output roots. `Inphi` acknowledged that the issue was moved to the backlog but GitHub closed it due to a PR link. `ajsutton` reiterated the need to unskip the test once the super DG supports explicit output roots, as indicated by CI checks.
