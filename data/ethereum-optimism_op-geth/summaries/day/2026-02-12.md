## ACTIVE ISSUES
- **Binary Format for Kona Hints**
  Discussion continued on using a binary format for Kona hints instead of string serialization ([#19125](https://github.com/ethereum-optimism/op-geth/issues/19125)). The latest comment clarifies that the host program must continue to support string versions for backward compatibility with existing games. The initial motivation for the change was primarily about correctness rather than performance, though performance improvements are expected.
- **Support for Multiple Sequencer RPC Endpoints**
  The discussion around supporting multiple sequencer RPC endpoints for transaction forwarding is ongoing ([#763](https://github.com/ethereum-optimism/op-geth/issues/763)). The latest comment emphasizes that while infrastructure-level redundancy is ideal, client-side failover across different CDNs/regions provides defense-in-depth against outages. This change is backward compatible and offers optional support for multiple endpoints to improve reliability for operators.
