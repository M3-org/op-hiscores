## ACTIVE ISSUES

### Database Read Transaction Memory Leak
Discussions continued on the issue [#19212](https://github.com/ethereum-optimism/op-geth/issues/19212), where Base mainnet archive nodes experienced memory leaks due to database read transactions being open for too long. The user reported that the issue has not reoccurred in the last 7 days on v1.10.2, and they plan to upgrade to v1.11.0 soon.
