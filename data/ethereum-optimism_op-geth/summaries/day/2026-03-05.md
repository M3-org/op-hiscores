## ACTIVE ISSUES

### Database Read Transaction Memory Leak
Discussions continued on issue [#19212](https://github.com/ethereum-optimism/op-geth/issues/19212), which reports a memory leak triggered by database read transactions being open for too long in `op-reth`. The latest comments indicate that the issue has not recurred in the last 7 days on `v1.10.2`, and the team is planning to upgrade to `v1.11.0` soon to see if the problem persists.
