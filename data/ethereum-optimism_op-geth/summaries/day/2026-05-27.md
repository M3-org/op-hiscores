# ethereum-optimism/op-geth Daily Update (May 27, 2026)
## OVERVIEW 
Today's focus was on resolving critical issues related to `op-supernode` stability and `op-reth` bootstrapping, alongside ongoing discussions on L2CM integration and feature flag management.

## KEY TECHNICAL DEVELOPMENTS

## NEWLY OPENED PULL REQUESTS
- A new pull request, [#796](https://github.com/ethereum-optimism/op-geth/pull/796), was opened to cherry-pick BAL-related changes from upstream.

## CLOSED ISSUES

### Supernode Stability and Resync Fixes
Several issues related to `op-supernode`'s robustness in handling partial-progress states and resynchronization were closed. This includes fixes for infinite retry loops and improved handling of EL-missing blocks, enhancing the overall stability of the supernode. ([#20929](https://github.com/ethereum-optimism/op-geth/issues/20929), [#20944](https://github.com/ethereum-optimism/op-geth/issues/20944), [#20690](https://github.com/ethereum-optimism/op-geth/issues/20690))

### L2CM Feature Flag Drift Prevention
An issue concerning silent drift between feature flag definitions and the CI matrix for L2CM was closed, with documentation being the chosen solution to manage updates when adding new dev or system features. ([#20340](https://github.com/ethereum-optimism/op-geth/issues/20340))

### op-reth Bootstrap Compatibility
The issue regarding `op-reth`'s minimal Bedrock bootstrap being incompatible with storage v2, causing node panics, was closed. This was resolved by upgrading `op-reth` to a newer version. ([#20821](https://github.com/ethereum-optimism/op-geth/issues/20821))

## NEW ISSUES

### Supernode CL Sync Recovery Stall
A new issue, [#21076](https://github.com/ethereum-optimism/op-geth/issues/21076), was opened to address a problem where `op-supernode/op-reth` CL sync recovery can stall when `SafeDB`/bookkeeping references an EL-missing block.

## ACTIVE ISSUES

### L2CM DevFeatures Removal for Auditor Review ([#20084](https://github.com/ethereum-optimism/op-geth/issues/20084))
The issue, which aims to remove the `DevFeatures` flag system and make L2CM the default codepath, was removed from the L2CM project and is now a general backlog item. The merge is currently delayed until all audit fixes are in.

### Integrate L2CM into L2 Genesis ([#20903](https://github.com/ethereum-optimism/op-geth/issues/20903))
Discussion continues on refactoring `L2ContractsManager` to be the source of truth for predeploy setup at L2 Genesis. The latest comments explore potential implementation strategies, including refactoring `L2Genesis.s.sol` to etch proxies and execute the NUT bundle, and the potential complications of switching `op-deployer` to use snapshotted upgrade bundles for different forks.
