## NEW ISSUES

**Reth Static Files Causing Execution Backlog**
A new issue was reported concerning `reth` static files consolidation leading to an execution backlog and `op-node` payload queue overflow. This is observed when running OP Stack with `reth` as the execution client in a dockerized environment. ([#759](https://github.com/ethereum-optimism/op-geth/issues/759))

## ACTIVE ISSUES

**Historical Proofs Migration**
Discussion continues on migrating historical proofs support from `op-rs/op-reth` into `op-reth`. The issue highlights the importance of maintaining the code in both stable and unstable branches of `op-rs/op-reth` until cyclic dependencies with upstream `reth` are resolved. The issue was assigned to @theochap. ([#18984](https://github.com/ethereum-optimism/op-geth/issues/18984))

**Op-Reth Snapshots for Verifiers/Node Operators**
A comment from @sebastianst suggests that the task of adding `op-reth` snapshots to `https://datadirs.optimism.io` for verifiers/node operators using Reth might be complete. This indicates potential progress on a feature request to provide easier access to `op-reth` snapshots. ([#18473](https://github.com/ethereum-optimism/op-geth/issues/18473))
