## ACTIVE ISSUES
### Persistent Memory Leak in op-reth
Discussion continued on [#19212](https://github.com/ethereum-optimism/op-geth/issues/19212) regarding a memory leak issue in `op-reth` where "The database read transaction has been open for too long triggers memory leak" warning appears, leading to high memory usage and node crashes. A user reported experiencing this on World Chain v1.10.1 and noted that an upgrade to v1.11.0 led to other issues, causing a downgrade. The issue has been observed on Base mainnet archive nodes and has occurred twice, with the first instance on version 1.9.3. The user has since switched to running the Base fork of `op-reth` for their Base nodes.

### Recurring State Root Mismatch on Base Mainnet
Issue [#19532](https://github.com/ethereum-optimism/op-geth/issues/19532) highlights recurring "mismatched block state root" errors on `op-reth` archive nodes on Base mainnet, causing permanent sync stalls and fatal crashes. This bug is reported as deterministic, affecting multiple independent nodes at the same block number. A user confirmed experiencing the same issue on custom chains like Manta Pacific. A maintainer suggested opening the issue on the Base repository, as Base has recently forked the OP Stack, and to link it for follow-up.

### Reinstating Interop Acceptance Tests
On [#19403](https://github.com/ethereum-optimism/op-geth/issues/19403), the discussion revolved around reinstating `op-supernode/acceptance-tests` for interop/activation. A comment noted that the existing test setup/teardown code is part of the problem, as it can hang when tests fail. A useful test that could be extended was also linked.
