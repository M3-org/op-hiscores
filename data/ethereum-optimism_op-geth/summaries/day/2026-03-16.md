## ACTIVE ISSUES
### Persistent Memory Leak in `op-reth`
Discussion continued on [#19212](https://github.com/ethereum-optimism/op-geth/issues/19212) regarding the "The database read transaction has been open for too long triggers memory leak" warning. A user reported experiencing the issue on World Chain v1.10.1, leading to node crashes. The original reporter noted that while they upgraded to v1.11.0, they encountered other issues and downgraded, eventually switching to a Base fork of `op-reth` for their Base nodes. They also mentioned that the issue has not reoccurred since their initial report.

### Recurring State Root Mismatch on Base Mainnet
Issue [#19532](https://github.com/ethereum-optimism/op-geth/issues/19532) highlights recurring "mismatched block state root" errors on `op-reth` archive nodes on Base mainnet, causing permanent sync stalls and fatal crashes. A user confirmed experiencing the same issue on custom chains like Manta Pacific. A maintainer suggested that since Base recently forked the OP Stack, the issue might be specific to their implementation and recommended opening an issue on the Base repository for further investigation.

### Reinstating Interop/Activation Tests
Discussion on [#19403](https://github.com/ethereum-optimism/op-geth/issues/19403) focused on reinstating interop/activation tests. A comment noted that the test setup/teardown code itself is part of the problem, as it can hang when tests fail. A useful existing test was identified as a potential starting point for extension.
