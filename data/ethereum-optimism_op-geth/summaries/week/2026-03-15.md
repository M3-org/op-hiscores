# ethereum-optimism/op-geth Weekly Report (Mar 15 - 21, 2026)

## 🚀 Highlights
This week focused heavily on enhancing the stability of the OP Stack through critical bug fixes in transaction processing and a massive effort to resolve CI/CD flakiness. Significant progress was made in refining interop transaction filtering during reorgs and resolving block finalization issues post-Regolith upgrade. While the team successfully migrated the build system from Makefiles to Justfiles to improve developer experience, new challenges emerged regarding "BAD BLOCK" errors and state root mismatches on Base Mainnet, highlighting ongoing synchronization complexities in production environments.

## 🛠️ Key Developments

### Protocol Correctness & Transaction Processing
Several critical fixes were merged to ensure the integrity of block production and transaction handling:
*   **Interop Reorg Robustness:** Addressed a bug where interop transactions were not correctly dropped during reorgs if a supervisor RPC URL was missing, improving the reliability of the transaction pool ([#776](https://github.com/ethereum-optimism/op-geth/pull/776)).
*   **Post-Regolith Finalization:** Resolved an issue where system transactions caused invalid blocks following the Regolith upgrade, ensuring correct block finalization ([#777](https://github.com/ethereum-optimism/op-geth/pull/777)).
*   **Configuration Accuracy:** Corrected a typo in the `eth/backend` configuration related to the Karst override ([#773](https://github.com/ethereum-optimism/op-geth/pull/773)).

### Build System & Infrastructure
*   **Justfile Migration:** The project successfully completed the migration of all Makefiles to Justfiles across the monorepo. This involved seven PRs and updates to CI scripts, Dockerfiles, and documentation to streamline the build process ([#19546](https://github.com/ethereum-optimism/op-geth/issues/19546)).

### Interoperability & Supernode Progress
*   **Test Coverage:** Efforts to mirror Supervisor test coverage for the Supernode are underway. A batch of tests was deduplicated and moved to the shared `superfaultproofs` package ([#19010](https://github.com/ethereum-optimism/op-geth/issues/19010)).
*   **Kona Integration:** The review of the Kona-interop block hash oracle is nearing completion, with final integration tests for historical block lookups pending ([#18288](https://github.com/ethereum-optimism/op-geth/issues/18288)).

## 🐛 Issues & Triage

### Closed Issues: CI Stability
A major theme this week was the resolution of "flaky" tests that have hindered CI reliability. Key resolutions included:
*   **Timeout Adjustments:** `TestCLIBootstrapForge` was fixed by increasing context timeouts from 60 seconds to 5 minutes to accommodate CI load ([#19627](https://github.com/ethereum-optimism/op-geth/issues/19627)).
*   **Race Conditions:** Multiple tests, including `TestBreakTimestampInvariant` and `TestSuperchain`, were closed after addressing root causes ranging from nonce races to resource contention ([#18137](https://github.com/ethereum-optimism/op-geth/issues/18137), [#19586](https://github.com/ethereum-optimism/op-geth/issues/19586)).

### New & Active Issues: Production Stability
*   **Base Mainnet Anomalies:** Two critical issues were reported on Base: recurring state root mismatches on archive nodes ([#19532](https://github.com/ethereum-optimism/op-geth/issues/19532)) and a "BAD BLOCK, invalid gas used" error during payload processing ([#778](https://github.com/ethereum-optimism/op-geth/issues/778)).
*   **EL Sync UX:** Ongoing debate continues regarding how `op-node` handles finalization after initial Execution Layer (EL) sync. Proposals include implementing a 12-hour delay for the finalized head or using a separate finalization gadget to prevent nodes from marking targets as finalized prematurely ([#17631](https://github.com/ethereum-optimism/op-geth/issues/17631)).
*   **CI Deadlocks:** Investigation continues into the `memory-all-opn-op-geth` job, where a race condition in the `RewindEngine` causes a retry loop when synthetic payloads are rejected ([#19563](https://github.com/ethereum-optimism/op-geth/issues/19563)).

## 💬 Community & Collaboration
The week was characterized by deep technical troubleshooting between maintainers and node operators. Discussions around the `op-reth` memory leaks ([#19212](https://github.com/ethereum-optimism/op-geth/issues/19212)) and Base Mainnet issues show active cross-project collaboration, with maintainers directing specific implementation issues to the relevant Base repositories while providing architectural guidance. The migration to Justfiles also demonstrated a coordinated effort to improve the contributor experience across the entire monorepo.
