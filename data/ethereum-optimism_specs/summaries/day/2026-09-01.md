# ethereum-optimism/specs Daily Update (Sep 1, 2026)
## OVERVIEW 
Today's development focused on refining the protocol specifications, specifically replacing the detailed Flashblocks specification with a more user-friendly Subblocks specification. Several issues related to light node deployment and game proving were also closed.

## KEY TECHNICAL DEVELOPMENTS

### Protocol Specification Refinement
*   Replaced the detailed Flashblocks specification with a minimal, consumer-facing Subblocks specification, including documentation for WebSocket payload format, sequencing guarantees, JSON-RPC behavior, and transaction inclusion implications. ([#933](https://github.com/ethereum-optimism/specs/pull/933))

## NEWLY OPENED PULL REQUESTS

## CLOSED ISSUES

### Subblocks Specification Update
*   The issue to replace the detailed Flashblocks specification with a public-facing Subblocks specification has been closed, aligning with the work completed in PR #933. ([#929](https://github.com/ethereum-optimism/specs/issues/929))

### Lightnode Deployment Progress
*   The issue tracking the re-deployment of Lightnode across the Staging environment has been closed. Significant progress was reported on Sepolia-Devnet-2, Sepolia-devnet-3, and Platforms-1, with multiple sequencers and RPC nodes now light node enabled. ([#22352](https://github.com/ethereum-optimism/specs/issues/22352))

### Game Proving Improvements
*   The issue concerning game-proving retries discarding completed proofs and regenerating all witnesses has been closed. This indicates a resolution to the problem where the proposer did not checkpoint progress during multi-chunk game proving. ([#22622](https://github.com/ethereum-optimism/specs/issues/22622))
