## ACTIVE ISSUES

### Flaky Test: `TestReorgUnsafeHead`
The flaky `TestReorgUnsafeHead` issue ([#20198](https://github.com/ethereum-optimism/specs/issues/20198)) saw significant progress today. A root cause was identified: the test picked the next block's parent by reading the EL's mutable `eth.Unsafe` ("latest") label, which could lag and return the original head, silently undoing reorgs. A fix has been opened in a separate PR, involving using the `ReorgExact` DSL poll to wait for divergence and explicit parent selection, along with generous poll budgets to tolerate CI overload. Validation showed the fix resolved the issue across multiple parallel runs.

### Interop Proofs Devnet
Discussions on the Interop Proofs Devnet issue ([#20489](https://github.com/ethereum-optimism/specs/issues/20489)) focused on withdrawal finalization. It was noted that the `op-chain-ops` script for proving withdrawals is currently not working and requires a fix. A withdrawal initiated last week on `inphi-devnet-0` is awaiting proof and finalization on L1, which is the last verification step for proofs.

### L2CM FeeVaults Update
The issue regarding adding `setWithdrawalRoute` to FeeVaults ([#20806](https://github.com/ethereum-optimism/specs/issues/20806)) is currently blocked. A problem was identified where bumping L2 contract semvers causes CI failures. The `TestActivationBlockNUTBundle` test, which applies locked bundles to the L2Genesis state, fails because the L2CM code prevents upgrading a contract to a lower semver. This is considered a deficiency in the test rather than a bug in L2CM, and a solution is needed before further modifications to L2 contracts can proceed smoothly.
