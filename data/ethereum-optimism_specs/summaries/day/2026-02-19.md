# ethereum-optimism/specs Daily Update (Feb 19, 2026)
## OVERVIEW 
Today's development focused on refining the NUT bundle format by removing the `value` field, ensuring consistency with execution layer enforcement. An issue related to cleaning up `ProxyAdmin` implementation was closed, and a new issue regarding non-blocking engine resets for `SequencerActor` was opened.

## KEY TECHNICAL DEVELOPMENTS

### NUT Bundle Format Refinement
The `value` field has been removed from the NUT bundle transaction format, with an explicit prohibition added. This change aligns the specification with the execution layer's enforcement that the value for NUT transactions is always zero. ([#893](https://github.com/ethereum-optimism/specs/pull/893))
