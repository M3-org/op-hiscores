# ethereum-optimism/specs Daily Update (Mar 31, 2026)

## NEW ISSUES

### New Flaky Interop Fault Proof Tests
Two new flaky tests related to `TestInteropFaultProofs` were reported, both exhibiting issues with the Kona interop program.
- [#19829](https://github.com/ethereum-optimism/specs/issues/19829): `TestInteropFaultProofs_VariedBlockTimes_FasterChainB/SuperRootInvalidIfUnsupportedByL1Data-fpp` is failing because the Kona interop program exits as valid when the test expects it to fail.
- [#19828](https://github.com/ethereum-optimism/specs/issues/19828): `TestInteropFaultProofs_VariedBlockTimes_FasterChainB/FirstChainReachesL1Head-fpp` is failing because the Kona interop program exits as invalid when the test expects it to pass.

## ACTIVE ISSUES

### Flaky Test: `TestInteropFaultProofs_VariedBlockTimes_FasterChainB/SuperRootInvalidIfUnsupportedByL1Data-fpp`
This issue, [#19829](https://github.com/ethereum-optimism/specs/issues/19829), reports a flaky test where the Kona interop program exits as valid when it should fail. The latest comments confirm additional flakes with similar error messages, specifically "An error is expected but got nil. expected kona interop program to fail, got: <nil>". The root cause is suspected to be a missing L1 head check in the Kona no-op transition path.

### Flaky Test: `TestInteropFaultProofs_VariedBlockTimes_FasterChainB/FirstChainReachesL1Head-fpp`
This issue, [#19828](https://github.com/ethereum-optimism/specs/issues/19828), describes a flaky test where the Kona interop program exits as invalid when it should pass. Recent comments indicate further occurrences of this flake, with error messages like "Failed to validate progressed transition state. Expected post-state commitment: ..., actual: ...". This flake is considered a sibling to [#19829](https://github.com/ethereum-optimism/specs/issues/19829), sharing the same suspected root cause: a missing L1 head check in the Kona no-op transition path.
