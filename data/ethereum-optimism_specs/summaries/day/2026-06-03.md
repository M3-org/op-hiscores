## ACTIVE ISSUES

### State-Persistent Partial DoS in OptimismPortal2
A discussion on a potential state-persistent partial DoS vulnerability in OptimismPortal2 via high-gas deposits continued, with a new comment simply stating "Wtf man". ([#20820](https://github.com/ethereum-optimism/specs/issues/20820))

### CL Sync Recovery Stalling in op-supernode/op-reth
Significant progress was reported on the issue where CL sync recovery can stall due to `SafeDB`/bookkeeping referencing an EL-missing block. The root cause was identified as a cyclic deadlock in reth's `StateTrieOverlayManager` / `DeferredTrieData` machinery, with two distinct "lock held across a `rayon` compute" sites. A two-patch fix has been implemented and is undergoing a 6-hour soak test, showing promising results with no wedges. The issue was reproduced without `op-supernode`, confirming the problem lies within the `op-node`/`op-reth` CL derive/build Engine API path. ([#21076](https://github.com/ethereum-optimism/specs/issues/21076))

### SDM: Add a Limit for SDM Refunds
Discussion on adding a protocol-level upper bound for sequencer rebates continued. The current suggestion is to enforce `MAX_GAS_LIMIT` regardless of the refund amount, effectively capping the sequencer's maximum computation. ([#20709](https://github.com/ethereum-optimism/specs/issues/20709))

### Add Test for `relayMessage` Gas Changes
The issue to add a test that would trigger a failure if gas changes cause `relayMessage` to fail was reopened. This is due to existing TODOs in the codebase referencing this issue, awaiting a stable Foundry release that includes `foundry-rs/foundry#9904` to enable `default.isolate = true` in tests. ([#14609](https://github.com/ethereum-optimism/specs/issues/14609))
