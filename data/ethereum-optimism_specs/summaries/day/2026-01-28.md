## ACTIVE ISSUES

**Withdrawal Proving Mechanism Refinement**
Discussion on [#18517](https://github.com/ethereum-optimism/specs/issues/18517) regarding proving withdrawals using chain-specific root claims indicates a decision to move this to the backlog. The `OptimismPortalInterop` changes are complete, but updating `OptimismPortal2` is dependent on U19 execution and must be done separately from the FaultDisputeGame upgrade to avoid disrupting withdrawals.

**op-supernode SyncStatus API Definition**
On [#18947](https://github.com/ethereum-optimism/specs/issues/18947), there was a discussion to define the `SyncStatus` API for `op-supernode`. The agreed-upon interface should include the `op-node` SyncStatus for every chain and the sync status of every verification activity. For interop activity, this includes the latest verified timestamp and the current L1. Additionally, SyncStatus should report on the latest verified L2 to simplify acceptance testing.

**EIP-1559 Parameter Decoding Fix in op-alloy**
Issue [#18951](https://github.com/ethereum-optimism/specs/issues/18951) focuses on fixing EIP-1559 parameter decoding in `op-alloy` to properly catch zero elasticities early. A community member expressed interest in contributing to this fix.
