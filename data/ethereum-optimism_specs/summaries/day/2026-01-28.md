## ACTIVE ISSUES

### `op-supernode` SyncStatus API Definition
Discussion on [#18947](https://github.com/ethereum-optimism/specs/issues/18947) focused on defining the `op-supernode` SyncStatus API. It was decided that the interface should include the `op-node` SyncStatus for every chain and the sync status of every verification activity. For interop activity, this includes the latest verified timestamp and the current L1. Additionally, the SyncStatus should report on the latest verified L2 to simplify acceptance testing.

### `OptimismPortal2` Withdrawal Proving Mechanism
The issue [#18517](https://github.com/ethereum-optimism/specs/issues/18517), regarding proving withdrawals using a chain-specific root claim, was moved to the backlog. The `OptimismPortalInterop` changes are complete, but updating `OptimismPortal2` must wait until U19 is executed. This is to ensure withdrawals continue to function immediately after the upgrade, as `OptimismPortal2` needs to be upgraded separately from the FaultDisputeGame upgrade to avoid users waiting an additional week for finalization.

### `op-alloy` EIP-1559 Parameter Decoding
On [#18951](https://github.com/ethereum-optimism/specs/issues/18951), a community member offered to take on the task of fixing EIP-1559 parameter decoding in `op-alloy` to properly catch zero elasticities early in the decoding process.
