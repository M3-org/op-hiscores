## ACTIVE ISSUES

### Optimism Sepolia Intrinsic Gas After Karst Hard Fork
The issue [#21457](https://github.com/ethereum-optimism/specs/issues/21457) reports that Optimism Sepolia's intrinsic gas is too high after the Karst hard fork. The latest comment confirms this is a known issue and will be addressed in the next release, as per the upgrade notice.

### Flaky `reth-optimism-node` Integration Test
Issue [#20973](https://github.com/ethereum-optimism/specs/issues/20973) describes a recurring flake in the `reth-optimism-node` integration test `peers_negotiate_eth_69` which results in a SIGSEGV on teardown. The latest comment from sebastianst confirms the non-deterministic nature of the segfault, noting it recurred and impacted the merge queue. The issue is suspected to be related to how the payload builder service handles `std::thread` and `tokio` runtime teardown, leading to a race condition.

### Inconsistent Metrics Versioning in `kona-node` and `op-reth`
Issue [#20832](https://github.com/ethereum-optimism/specs/issues/20832) highlights a discrepancy where the version reported in Prometheus metrics for `kona-node` and `op-reth` does not align with the git/docker tag. The latest comment from sebastianst further details inconsistencies, including `op-reth`'s image tag and the version returned by `web3_clientVersion` or `--version` commands, which currently reflect the internal reth crate version instead of the build's git tag.
