### SystemConfig Override for Custom Gas Token
Issue [#18502](https://github.com/ethereum-optimism/specs/issues/18502) discusses the temporary allowance for `SystemConfig::isCustomGasToken` override in OPCMv2. The latest comment indicates that this issue has been fixed by pull request #18878, which is not detailed in this report. This override was necessary until U18 ships, at which point `isCustomGasToken` will be available directly on the SystemConfig.
