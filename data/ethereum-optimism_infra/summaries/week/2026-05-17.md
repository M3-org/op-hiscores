# ethereum-optimism/infra Weekly Report (May 17 - 23, 2026)

## 🚀 Highlights
This week, the infrastructure team achieved a major milestone in the Interop project by completing the interop hard fork activation via the L2CM upgrade mechanism for both `kona-node` and `op-node`. Significant progress was made in stabilizing the consensus layer by resolving critical Brotli channel divergence issues between Kona and op-node. Additionally, the team finalized the migration of dispute game tests to the acceptance test suite, paving the way for the decommissioning of the legacy `op-supervisor`.

## 🛠️ Key Developments

### Interop Hard Fork & RPC Refactoring
The foundational work for the Interop project saw significant advancement this week.
*   **Hard Fork Activation:** Successfully implemented the interop hard fork using the L2CM upgrade mechanism across `kona-node` and `op-node` [#20082].
*   **Namespace Refactoring:** The `supervisor` RPC namespace was replaced with a dedicated interop filter namespace. This refactor removes a critical dependency on the supervisor component, which is slated for removal, and improves the clarity of the RPC interface [#20005].
*   **Proxyd Updates:** A new fix was introduced for the `proxyd` interop access-list namespace to ensure compatibility with the new RPC structures [#623].

### Consensus Reliability & Brotli Compression
Engineers resolved technical debt and bugs related to data decompression that were causing node divergence.
*   **Divergence Fixes:** Addressed critical bugs in `kona::decompress_brotli` and an upstream brotli crate that caused `kona` and `op-node` to diverge when processing compressed channels [#19333].

### Testing Infrastructure & Fault Proofs
Efforts focused on migrating tests to more robust frameworks and investigating CI flakiness.
*   **Test Migration:** Completed the migration of dispute game tests from `op-e2e/super_test.go` to `op-acceptance-tests`, centralizing fault proof validation [#20814].
*   **Code Auditing:** An investigation into `debug_executePayload` confirmed that these crates are essential for fault-proof witness prefetching and are not dead code, ensuring they remain in the codebase for performance optimization [#20879].

## 🐛 Issues & Triage

### Closed Issues
*   **Interop Milestones:** Successfully closed issues related to the L2CM hard fork implementation and the RPC namespace migration [#20082, #20005].
*   **Stability Improvements:** Resolved the Brotli-related consensus divergence and finalized the dispute game test migration [#19333, #20814].

### New & Active Issues
*   **Devnet Blockers:** The spin-up of new devnets is currently delayed pending the readiness of `glamsterdam-devnet-4` images. Workarounds are being explored using `bal-devnet-6` for local testing [#20691].
*   **Integration Blockers:** SDM Flashblocks integration is currently stalled by an upstream dependency in the core optimism repository [#20175, #20599].
*   **Flaky Test Investigations:** Two major flakes are being addressed:
    *   `TestSupernodeInterop_SafeHeadProgression`: A fix PR is currently open to stabilize this pipeline [#20851].
    *   `TestChallengerCountersPreGenesisGame`: Identified as a timing issue where block inclusion collisions occur under high CI load. A proposal to increase the block delay budget is under review [#20869].
*   **Interop Proofs Devnet:** Active development continues on a long-term internal devnet to automate the deployment of SuperRootMigrations and InteropPortal contracts [#20489].

## 💬 Community & Collaboration
The week was characterized by high-intensity internal coordination regarding the Interop project. Collaboration was particularly evident between the teams managing `kona` and `op-node` to resolve upstream crate issues affecting consensus. There is also ongoing cross-repo coordination, as seen in the SDM Flashblocks integration and the proposed fixes for CI timing issues that bridge the `infra` and `optimism` repositories. The successful migration of tests to `op-acceptance-tests` indicates a concerted effort to streamline the contributor experience by reducing CI noise and flakiness.
