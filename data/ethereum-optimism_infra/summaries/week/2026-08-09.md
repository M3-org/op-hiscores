# ethereum-optimism/infra Weekly Report (Aug 9 - 15, 2026)

## 🚀 Highlights
This week focused on the successful stabilization and operationalization of the **State-Dependent Mining (SDM)** devnet, marking a significant milestone for the Superchain's infrastructure. The `sdm-net-0` environment is now in a steady state with active fault proofs, continuous standing workloads, and verified monitoring dashboards. Parallel efforts were directed toward hardening the **Lightnode** deployment strategy for production readiness and improving CI reliability by addressing silent data truncation and flaky P2P tests. Security also remained a priority with critical dependency updates and enhanced repository-local review mechanisms.

## 🛠️ Key Developments

### SDM Devnet & Protocol Operations
The rollout of the alpha/beta devnet for SDM reached a major milestone. The environment is now "hands-free" with operator opt-in armed at boot.
*   **Standing Workload & Benchmarking:** Implemented a continuous workload on `sdm-net-0` to ensure the network remains active. This involved funding the `BENCHMARK_PKEY` with 100 ETH to resolve initial balance issues and verifying that blocks now consistently carry rebates ([#22343](https://github.com/ethereum-optimism/infra/issues/22343), [#22344](https://github.com/ethereum-optimism/infra/issues/22344)).
*   **Fault Proofs:** Successfully aligned `fp-permissionless` with deployed contracts, enabling functioning fault proofs on the SDM devnet for the first time ([#21273](https://github.com/ethereum-optimism/infra/issues/21273)).

### CI/CD Infrastructure & Tooling
Significant work was done to improve the visibility and security of the development pipeline.
*   **Dependency Security:** Updated `golang.org/x/crypto` to v0.52.0 to address security concerns within the `bailiff` module ([#700](https://github.com/ethereum-optimism/infra/pull/700)).
*   **Review Mechanisms:** Implemented a repository-local dependency-review exception mechanism, allowing for more granular control over security workflows ([#708](https://github.com/ethereum-optimism/infra/pull/708)).
*   **Pipeline Reliability:** Opened PR [#709](https://github.com/ethereum-optimism/infra/pull/709) to retry `cci-stats` pipelines that were indexed while still running, ensuring more accurate data collection.

## 🐛 Issues & Triage

### Closed Issues
*   **Documentation & Runbooks:** The SDM operator guide was rewritten to reflect current opt-in mechanisms ([#22347](https://github.com/ethereum-optimism/infra/issues/22347)). Additionally, a comprehensive runbook for recovering a chain after invalid interop messages and reorgs was finalized ([#21161](https://github.com/ethereum-optimism/infra/issues/21161)).
*   **Protocol Stability:** Resolved an issue where invalidation recovery would reset prematurely before Execution Layer (EL) convergence ([#21948](https://github.com/ethereum-optimism/infra/issues/21948)).
*   **Compatibility:** Implemented missing hardfork override flags in `op-reth`, enabling Superchain nodes to connect via P2P ([#20224](https://github.com/ethereum-optimism/infra/issues/20224)).

### New & Active Issues
*   **Lightnode Hardening:** New discussions are underway regarding the re-deployment of Lightnode across staging and production environments to validate interop readiness and harden the configuration ([#22352](https://github.com/ethereum-optimism/infra/issues/22352), [#22354](https://github.com/ethereum-optimism/infra/issues/22354)).
*   **CI Data Integrity:** Issue [#710](https://github.com/ethereum-optimism/infra/issues/710) was opened to address silent truncation in `cci-stats` caused by CircleCI page size limits.
*   **Flaky Tests:** `TestP2PFull` has been identified as flaky. Initial investigations suggest a race condition during disconnect/reconnect cycles and an unidentified "Noise error" ([#22381](https://github.com/ethereum-optimism/infra/issues/22381)).
*   **SDM Test Coverage:** Discussions continue regarding integration tests for invalid PostExec payloads. Current testing is limited by the `op-geth` engine, suggesting a future transition to `op-reth` for full coverage ([#21344](https://github.com/ethereum-optimism/infra/issues/21344)).

## 💬 Community & Collaboration
The week was characterized by high-intensity troubleshooting and operational coordination. The SDM rollout required cross-functional collaboration to merge k8s and private devnet PRs, alongside live fixes for on-chain funding. There is an emerging need for more secure communication channels to discuss sensitive technical concerns related to Lagoon and Kona. The investigation into P2P flakiness demonstrates a rigorous approach to technical debt, with contributors moving toward trace-level logging to resolve non-deterministic failures.
