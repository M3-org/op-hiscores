# ethereum-optimism/infra Daily Update (Mar 3, 2026)
## OVERVIEW 
Today's focus was on optimizing `op-acceptor` test execution by implementing a runtime cache for sorting tests. Several issues related to L2 contract upgrades and vm runner support were closed. A new issue was opened to investigate Glamsterdam gas pricing impacts on precompile acceleration.

## KEY TECHNICAL DEVELOPMENTS

### `op-acceptor` Test Optimization
A new feature was added to `op-acceptor` to sort tests by their previous runtime, front-loading the longest tests. This is achieved by introducing a `RuntimeCache` that persists wall-clock runtimes between runs, aiming to optimize test execution efficiency. ([#557](https://github.com/ethereum-optimism/infra/pull/557))

### `proxyd` Performance Improvement
A new pull request was opened to optimize `proxyd` when handling large JSON responses, indicating an ongoing effort to improve performance in key infrastructure components. ([#559](https://github.com/ethereum-optimism/infra/pull/559))
