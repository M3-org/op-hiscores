# ethereum-optimism/infra Daily Update (Mar 3, 2026)
## OVERVIEW 
Today, development focused on optimizing `op-acceptor` test execution by sorting tests based on runtime. Several issues related to L2 contract upgrades and VM runner support were closed, and a new issue was opened to investigate gas pricing impacts on precompile acceleration.

## KEY TECHNICAL DEVELOPMENTS

*   **`op-acceptor` Test Optimization**
    *   Implemented a `RuntimeCache` to store and retrieve wall-clock runtimes for `op-acceptor` tests.
    *   Tests are now sorted by previous runtime, with the longest tests executed first to optimize the critical path ([#557](https://github.com/ethereum-optimism/infra/pull/557)).
