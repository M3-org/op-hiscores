# ethereum-optimism/infra Daily Update (Mar 27, 2026)
## OVERVIEW 
Today's development focused on significant refactoring within the `proxyd` component, streamlining its consensus tracking interface and preparing for enhanced block hash tracking. Several new pull requests were opened, continuing the refactoring efforts in `proxyd`. Two issues related to `L2ProxyAdmin` and `L2CM` access control were closed.

## KEY TECHNICAL DEVELOPMENTS

### `proxyd` Consensus Tracker Refactoring
The `proxyd` component saw a significant refactoring of its `ConsensusTracker` interface. This involved collapsing a 6-method interface into a simpler `GetState()`/`SetState()` pattern, improving code clarity and maintainability. This change is part of ongoing efforts to enhance the `proxyd`'s efficiency and robustness. ([#588](https://github.com/ethereum-optimism/infra/pull/588))

## NEWLY OPENED PULL REQUESTS
Four new pull requests were opened, all focusing on the `proxyd` component. These include renaming EL-specific functions and fixing type assertion panics ([#592](https://github.com/ethereum-optimism/infra/pull/592)), adding block hash tracking to the consensus state ([#591](https://github.com/ethereum-optimism/infra/pull/591)), extracting a reusable function for `findConsensusBlock` walk-back ([#590](https://github.com/ethereum-optimism/infra/pull/590)), and further refactoring related to `proxyd` EL consensus preparation ([#589](https://github.com/ethereum-optimism/infra/pull/589)).
