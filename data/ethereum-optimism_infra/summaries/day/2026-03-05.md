# ethereum-optimism/infra Daily Update (Mar 5, 2026)
## OVERVIEW 
Today's focus was on enhancing the security and stability of `op-conductor-mon` through dependency updates and hardened container images. A new pull request was opened to address interop access list validation in `proxyd`.

## KEY TECHNICAL DEVELOPMENTS

### `op-conductor-mon` Security and Hardening
The `op-conductor-mon` service received significant security enhancements. Vulnerable Go module dependencies were updated to their latest compatible versions, and the container image was hardened by switching to Docker Hardened Images (DHI) for both build and runtime stages, improving overall security posture.
[#563](https://github.com/ethereum-optimism/infra/pull/563), [#562](https://github.com/ethereum-optimism/infra/pull/562)

## ACTIVE ISSUES

### `op-reth` Database Read Transaction Memory Leak
Discussion continues on [#19212](https://github.com/ethereum-optimism/infra/issues/19212) regarding a memory leak triggered by long-open database read transactions in `op-reth`. The latest update indicates that the issue has not reoccurred in the last 7 days on `v1.10.2`, and an upgrade to `v1.11.0` is pending.

### `op-reth` Interop Transaction Pool Features
Issue [#19411](https://github.com/ethereum-optimism/infra/issues/19411) was opened to track the implementation of interop transaction pool features in `op-reth`, specifically the interop ingress filter and interop transaction reorg eviction, which are currently present in `op-geth`. A comment questions the necessity of "Periodic re-validation."
