## ACTIVE ISSUES

### Flaky Test: `TestReorgUnsafeHead`
A root cause for the flaky `TestReorgUnsafeHead` was identified and a fix has been opened in a related PR. The issue stemmed from the test picking the next block's parent by reading the EL's mutable `eth.Unsafe` label, which could lag behind `op-reth`'s post-forkchoice canonical-tag swap, leading to reorgs being silently undone. The proposed fix involves using `ReorgExact` DSL poll to wait for the divergence height to reorg and taking the confirmed conflicting block as the explicit parent. ([#20198](https://github.com/ethereum-optimism/infra/issues/20198))

### Interop Proofs Devnet Progress
Progress on the Interop Proofs Devnet continues, with the SuperFaultDisputeGame played and resolved. A current challenge is that the `op-chain-ops` script used to prove withdrawals is not working and needs to be fixed. ([#20489](https://github.com/ethereum-optimism/infra/issues/20489))

### L2CM: Adding `setWithdrawalRoute` to FeeVaults
A significant blocking issue has been identified regarding modifications to L2 contracts, specifically when bumping semvers. The problem arises because the `TestActivationBlockNUTBundle` in Go starts from an L2Genesis state, and the L2CM code prevents upgrading a contract to a lower semver. When an L2 contract's semver is bumped, the existing bundle can no longer be executed against the locally generated genesis state, causing CI failures. This is considered a deficiency in the test rather than a bug in L2CM. ([#20806](https://github.com/ethereum-optimism/infra/issues/20806))
