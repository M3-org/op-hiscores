## ACTIVE ISSUES

- **op-supernode: Introduce SyncStatus API** ([#18947](https://github.com/ethereum-optimism/infra/issues/18947)): Discussions continued on defining the `SyncStatus` API for `op-supernode`. The latest comments suggest the interface should include `op-node` SyncStatus for every chain, sync status of every verification activity, and for interop activity, the latest verified timestamp and current L1. It was also suggested that SyncStatus should report on the latest verified L2 to simplify acceptance testing.

- **contracts: Prove withdrawals using chain-specific root claim** ([#18517](https://github.com/ethereum-optimism/infra/issues/18517)): The issue of ensuring `OptimismPortal2.proveWithdrawalTransaction` uses `IDisputeGame.rootClaim(uint256)` was discussed. The latest comment indicates that while `OptimismPortalInterop` changes are done, `OptimismPortal2` cannot be updated until U19 is executed. This change will be moved to the backlog and executed separately after the FaultDisputeGames support the new `rootClaimByChainId(uint256)` method to avoid withdrawal delays.

- **op-alloy: Fix EIP-1559 params decoding** ([#18951](https://github.com/ethereum-optimism/infra/issues/18951)): This issue, following up on #18625, aims to properly catch zero elasticities during EIP-1559 parameter decoding at the `op-alloy` level. A community member expressed interest in taking on this task.
