## ACTIVE ISSUES

**`op-supernode` SyncStatus API Definition**
Discussions continued on defining the `op-supernode` SyncStatus API. It was decided that the interface should include the `op-node` SyncStatus for every chain and the sync status of every verification activity. For interop activity, the status should cover the latest verified timestamp and the current L1. Additionally, the SyncStatus should report on the latest verified L2 to simplify acceptance testing ([#18947](https://github.com/ethereum-optimism/infra/issues/18947)).

**`op-alloy` EIP-1559 Parameters Decoding**
A community member expressed interest in taking on the task of fixing EIP-1559 parameters decoding in `op-alloy` to properly catch zero elasticities early in the decoding process ([#18951](https://github.com/ethereum-optimism/infra/issues/18951)).

**Contracts: Proving Withdrawals with Chain-Specific Root Claim**
The issue of ensuring `OptimismPortal2.proveWithdrawalTransaction` uses `IDisputeGame.rootClaim(uint256)` for L2 chain output root proof verification has been moved to the backlog. This is due to the dependency on U19 execution and the need to upgrade `OptimismPortal2` separately from the `FaultDisputeGame` to avoid disrupting withdrawals immediately after the upgrade ([#18517](https://github.com/ethereum-optimism/infra/issues/18517)).
