# ethereum-optimism/infra Daily Update (Jan 29, 2026)
## OVERVIEW 
Today's development focused on enhancing `proxyd` with transaction validation middleware and fixing a critical bug in the `cci-stats` service related to missing test metadata.

## KEY TECHNICAL DEVELOPMENTS

### Enhanced `proxyd` with Transaction Validation
A new feature was added to `proxyd` that introduces transaction validation middleware. This allows for custom URL and interface specifications for transaction validation. ([#539](https://github.com/ethereum-optimism/infra/pull/539))

### Critical Bug Fix in `cci-stats` Service
A bug in the `cci-stats` service was resolved, addressing failures when processing pipelines that contained jobs without test metadata. This fix prevents "not found" errors from the CircleCI API for such jobs. ([#543](https://github.com/ethereum-optimism/infra/pull/543))

## NEWLY OPENED PULL REQUESTS
- A new pull request, [#544](https://github.com/ethereum-optimism/infra/pull/544), was opened to verify GitHub Actions functionality on fork PRs.

## CLOSED ISSUES

### Resolution of CCI Stats Cronjob Failures
The issue regarding `cci-stats` cronjob failures, which was caused by the service failing to process pipelines without test metadata, has been closed. The fix has been implemented and a subsequent job run showed no "not found" errors. ([#542](https://github.com/ethereum-optimism/infra/issues/542))

The issue [#18473](https://github.com/ethereum-optimism/infra/issues/18473), concerning the addition of `op-reth` snapshots to `datadirs.optimism.io` for verifiers/node operators using Reth, is under discussion. The latest comment from sebastianst suggests that the task might be completed.

### Migration of Historical Proofs Support
Issue [#18984](https://github.com/ethereum-optimism/infra/issues/18984) was opened today to track the migration of historical proofs support code from `op-rs/op-reth` into `op-reth`. The issue highlights the importance of maintaining the code in both stable and unstable branches of `op-rs/op-reth` until cyclic dependencies with upstream Reth are resolved. The issue has been assigned to @theochap.
