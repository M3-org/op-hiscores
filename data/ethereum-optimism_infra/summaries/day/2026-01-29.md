# ethereum-optimism/infra Daily Update (Jan 29, 2026)
## OVERVIEW 
Today's development focused on enhancing `proxyd` with transaction validation middleware and fixing a bug in the `cci-stats` service related to missing test metadata. A new pull request was opened to verify GitHub Actions on fork PRs.

## KEY TECHNICAL DEVELOPMENTS

### Enhanced Transaction Validation in Proxyd
A new feature was added to `proxyd` that introduces transaction validation middleware. This allows for custom URL and interface specifications for transaction validation. ([#539](https://github.com/ethereum-optimism/infra/pull/539))

### Bug Fix for CCI Stats Service
A critical bug in the `cci-stats` service was resolved. The fix addresses an issue where the service would fail when processing pipelines that contained jobs without test metadata, such as setup or deploy jobs. ([#543](https://github.com/ethereum-optimism/infra/pull/543))

## NEWLY OPENED PULL REQUESTS
- A new pull request was opened to verify the functionality of GitHub Actions on fork PRs. ([#544](https://github.com/ethereum-optimism/infra/pull/544))

## CLOSED ISSUES

### Resolution of CCI Stats Cronjob Failures
The issue regarding `cci-stats` cronjob failures, which was caused by the service failing to process pipelines without test metadata, has been closed. The fix has been implemented and a subsequent job run showed no "not found" errors. ([#542](https://github.com/ethereum-optimism/infra/issues/542))

## NEW ISSUES
- A new issue was opened to track the migration of historical proofs support from `op-rs/op-reth` into `op-reth`. This migration is crucial for maintaining compatibility and avoiding cyclic dependencies with upstream reth. ([#18984](https://github.com/ethereum-optimism/infra/issues/18984))
