## ACTIVE ISSUES

### Binary Format for Kona Hints
Discussion continues on using a binary format for Kona hints instead of string serialization ([#19125](https://github.com/ethereum-optimism/infra/issues/19125)). The latest comments clarify that while performance is a potential benefit, the primary motivation is "making things right." A key challenge is maintaining backward compatibility, as the host program must continue to support string versions for existing games. The possibility of an approach that preserves compatibility without requiring user code changes is being considered.

### Multiple Sequencer RPC Endpoints
The conversation around supporting multiple sequencer RPC endpoints for transaction forwarding in `op-geth` ([#763](https://github.com/ethereum-optimism/infra/issues/763)) highlights the trade-off between reliability and user experience. The latest comment emphasizes that while infrastructure-level redundancy is ideal, client-side failover across different CDNs/regions adds a valuable layer of defense-in-depth, especially given past incidents where single endpoint failures caused outages. The proposed change is fully backward compatible, offering optional support for multiple endpoints without altering existing single-URL configurations.
