## ACTIVE ISSUES

### Binary Format for Kona Hints
Discussion continues on the proposal to use a binary format for Kona hints instead of string serialization ([#19125](https://github.com/ethereum-optimism/infra/issues/19125)). The latest comments clarify that while the primary motivation is correctness, performance improvements are also expected. A key challenge is maintaining backward compatibility, as the host program must continue to support existing string-based hints. The discussion is exploring approaches to preserve compatibility while implementing the binary format.

### Support for Multiple Sequencer RPC Endpoints
The issue of supporting multiple sequencer RPC endpoints for transaction forwarding in `op-geth` is being actively discussed ([#763](https://github.com/ethereum-optimism/infra/issues/763)). The latest comment emphasizes that while infrastructure-level redundancy is ideal, client-side failover across different CDNs/regions provides defense-in-depth against outages. The proposed change is backward compatible and aims to improve reliability for operators by allowing optional configuration of multiple endpoints.
