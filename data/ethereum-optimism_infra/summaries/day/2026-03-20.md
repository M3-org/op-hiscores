## ACTIVE ISSUES
- **Flaky Test: `TestCLELDivergence`** [#19681](https://github.com/ethereum-optimism/infra/issues/19681)
  - Investigation suggests this might be a real bug rather than just a flaky test. The test expects CL-EL divergence to persist, but intermittently, the `StatusTracker`'s `UnsafeL2` is reset. The core question for the team is whether this reset is correct behavior or a bug in the reset logic. If it's a bug, the test is correctly catching it, albeit unreliably.
- **`op-reth` Recurring State Root Mismatch** [#19532](https://github.com/ethereum-optimism/infra/issues/19532)
  - The issue describes `op-reth` archive nodes on Base mainnet experiencing recurring "mismatched block state root" errors, leading to permanent sync stalls and crashes. It's suggested that this might be linked to a known `reth` issue. The Base team has been advised to open an issue on their repository for further investigation, as they recently forked the OP Stack.
- **Non-terminating CI job: `memory-all-opn-op-geth`** [#19563](https://github.com/ethereum-optimism/infra/issues/19563)
  - This issue was closed today, but significant discussion occurred. The root cause was identified as a mutex deadlock in `VirtualNode` during shutdown, involving the test cleanup thread, `Start()` goroutines, and event loop goroutines. A fix has been proposed to release the mutex before calling `inner.Stop()` and add a defensive timeout. The flakiness was attributed to the deadlock only occurring when the event system processes a `SyncStatus()` call at a specific moment during shutdown.
- **Flaky test: `TestSupernodeInteropInvalidMessageReplacement`** [#19677](https://github.com/ethereum-optimism/infra/issues/19677)
  - This test continues to flake, with another occurrence reported in CI. The failure is consistently "Condition never satisfied" related to "reset should be detected."
