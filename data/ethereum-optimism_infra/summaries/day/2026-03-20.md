## ACTIVE ISSUES
- **Flaky Test: `TestCLELDivergence` Investigation**
  Issue [#19681](https://github.com/ethereum-optimism/infra/issues/19681) reports a flaky test, `TestCLELDivergence`. The latest comment from `ajsutton` provides an in-depth investigation, suggesting that the flakiness might indicate a real bug rather than just a test issue. The core finding is a potential deadlock cycle involving `VirtualNode.Start()`, `OpNode.Stop()`, and the event system's `GlobalSyncExec.Drain`. The test aims to observe a persistent CL-EL divergence, but an intermittent reset of the `UnsafeL2` head is occurring. The discussion questions whether this reset is the correct behavior or if it points to a bug in the reset logic, impacting the test's expectations.

- **`op-reth` State Root Mismatch and Sync Stalls**
  Issue [#19532](https://github.com/ethereum-optimism/infra/issues/19532) describes recurring "mismatched block state root" errors in `op-reth` archive nodes on Base mainnet, leading to permanent sync stalls and crashes. `ngotchac` suggests a link to a similar issue in the `reth` repository ([#22973](https://github.com/paradigmxyz/reth/issues/22973)). `sebastianst` recommends opening the issue on the Base repository, especially given recent OP Stack forks, to determine if it's a general issue. `InoMurko` confirms similar issues on custom chains like Manta Pacific.

- **Flaky Test: `TestSupernodeInteropInvalidMessageReplacement`**
  Issue [#19677](https://github.com/ethereum-optimism/infra/issues/19677) reports a flaky test, `TestSupernodeInteropInvalidMessageReplacement`. `ajsutton` provided an update, noting another occurrence of the flake in CI, specifically a "Condition never satisfied" error related to "reset should be detected." The test ran for 93.75s, and CircleCI Insights show 3 flakes for this test on the `main` workflow.
