## ACTIVE ISSUES

### `op-interop-filter` Verdict RPC Blocking
Discussion continues on an issue where the `op-interop-filter`'s verdict RPC can block behind an ingester write lock, leading to fail-closed timeouts. A new test fingerprint, `TestInteropFilter_IngressRejectsInvalid`, was identified as another occurrence of this defect. The test failed because the `checkAccessList` query did not receive a response within the timeout, resulting in an "interop quorum not reached" error, rather than a definitive parse-error rejection. This behavior is consistent with the verdict path blocking behind the ingester write lock. ([#21943](https://github.com/ethereum-optimism/infra/issues/21943))
