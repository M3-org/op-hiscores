## NEW ISSUES

### Reactive Runtime Config Reload for `op-node`
A new issue was opened to address the problem of `op-node` verifier nodes rejecting valid blocks from a new signer during a stale signer window when the unsafe block signer address is rotated ([#19981](https://github.com/ethereum-optimism/infra/issues/19981)). The proposed solution involves adding a reactive reload mechanism to trigger an early runtime config reload when a gossip block fails signature verification.
