## ACTIVE ISSUES

### Support for Multiple Sequencer RPC Endpoints
Discussion continues on [#763](https://github.com/ethereum-optimism/infra/issues/763) regarding supporting multiple sequencer RPC endpoints for transaction forwarding. The latest comments suggest using existing generic proxy solutions like HAProxy, Nginx, or Envoy instead of implementing a bespoke fallback client within `op-geth`. It was highlighted that Proxyd already offers various routing strategies that could abstract multiple RPC URLs. The initial proposal for client-side failover was seen as a defense-in-depth measure against CDN failures, but the preference leans towards leveraging established infrastructure tools for reliability.
