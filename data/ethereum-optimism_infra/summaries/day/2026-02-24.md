# ethereum-optimism/infra Daily Update (Feb 24, 2026)
## OVERVIEW 
The day saw a key feature addition to `op-acceptor`, enabling native ARM64 binary releases for improved compatibility, particularly for Apple M series users.

## KEY TECHNICAL DEVELOPMENTS

### Enhanced `op-acceptor` Compatibility
A new feature was added to `op-acceptor` to include `linux/arm64` release binaries ([#555](https://github.com/ethereum-optimism/infra/pull/555)). This change removes the ignore entry from `.goreleaser.yaml`, allowing `op-acceptor` to be pulled and run in Docker images on Apple M series (arm64) CPUs without emulation.
