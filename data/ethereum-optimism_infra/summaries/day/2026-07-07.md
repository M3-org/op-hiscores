## NEW ISSUES

- **Flaky Test Investigation**: A new issue, [#21635](https://github.com/ethereum-optimism/infra/issues/21635), was opened to investigate a flaky test: `TestSupernodeLightSequencerInteropInvalidMessageReplacement`.
- **Fuzzing Strategy Review**: The team opened an issue, [#21636](https://github.com/ethereum-optimism/infra/issues/21636), to re-enable or retire fuzzing tests, following a discussion on their effectiveness.

## ACTIVE ISSUES

- **`op-reth` Dependency Update**: Issue [#21524](https://github.com/ethereum-optimism/infra/issues/21524) remains open, tracking the update of the `revm` dependency in `op-reth` to version 2.4.0 or 2.3.1. The issue is assigned to @joshklop, but the update is pending a new release of the dependency. The team plans to revisit this issue regularly until the new release is available.
- **Flaky Test Root Cause Analysis**: Issue [#21635](https://github.com/ethereum-optimism/infra/issues/21635) is actively being investigated. @ajsutton provided a detailed root cause analysis, explaining that the flakiness stems from ordering issues between `FollowSource` processing, `op-reth` importing/reorging, and queued sequencer build-start events. A draft PR, ethereum-optimism/optimism#21637, has been created to address this by forcing active sequencer resets on upstream local-safe advance/divergence, emitting reset notifications, clearing stale build states, and dropping stale queued build-start events. The fix has been reviewed and verified with targeted engine/sequencer tests.
- **Fuzzing Audit and Decision**: Issue [#21636](https://github.com/ethereum-optimism/infra/issues/21636) details an audit of all Go fuzz tests in the repository. @geoknee concluded that the current PR-time fuzzing jobs provide minimal value due to the lack of a committed corpus, sparse seeds, and the fact that deterministic value is already covered by unit tests. The recommendation is to retire all six current fuzzing jobs, keep the fuzz functions for deterministic seed tests, and only consider a nightly job if it includes a committed seed corpus, meaningful fuzz time, and crash-artifact persistence/alerting, specifically for high-value differential targets. A PR, #21639, has been opened to implement this decision.
