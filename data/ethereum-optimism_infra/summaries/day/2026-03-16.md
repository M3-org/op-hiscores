## ACTIVE ISSUES

**op-reth Memory Leak Investigation**
Discussion continued on [#19212](https://github.com/ethereum-optimism/infra/issues/19212) regarding the `op-reth` database read transaction memory leak. A user reported experiencing the issue on World Chain v1.10.1, leading to node crashes. The original reporter, `jonathanudd`, confirmed they had upgraded to `1.11.0` but encountered other issues, leading to a downgrade to `1.10.2` and eventually switching to the Base fork of `op-reth` for their Base nodes. They also noted that the issue has not reoccurred since their initial report.

**op-supernode/acceptance-tests Reinstatement**
On [#19403](https://github.com/ethereum-optimism/infra/issues/19403), `geoknee` provided additional context, highlighting that the test setup/teardown code itself contributes to the problem, as teardown can hang if tests fail. A useful existing test was also linked as a potential starting point for extension.

**op-reth State Root Mismatch on Base Mainnet**
The issue of recurring state root mismatches on Base mainnet, causing permanent sync stalls and crashes in `op-reth` archive nodes, is being actively discussed on [#19532](https://github.com/ethereum-optimism/infra/issues/19532). `InoMurko` confirmed experiencing the same issue on custom chains like Manta Pacific. `sebastianst` suggested that since Base recently forked the OP Stack, the issue should be reported on the Base GitHub repository, with a link provided for cross-referencing.
