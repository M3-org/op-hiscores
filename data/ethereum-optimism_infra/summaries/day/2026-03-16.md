## ACTIVE ISSUES

**op-reth Memory Leak Investigation**
Discussion continues on [#19212](https://github.com/ethereum-optimism/infra/issues/19212) regarding the `op-reth` database read transaction memory leak. A user reported experiencing the issue on World Chain v1.10.1, leading to node crashes. Another user confirmed upgrading to `1.11.0` caused other issues, prompting a downgrade to `1.10.2`, and eventually a switch to the Base fork of `op-reth` for their Base nodes. The original reporter noted the issue has not reoccurred since their initial report.

**op-supernode/acceptance-tests Reinstatement**
On [#19403](https://github.com/ethereum-optimism/infra/issues/19403), additional context was provided regarding the reinstatement of interop/activation tests. It was noted that the test setup/teardown code itself contributes to the problem, as teardown can hang if a test fails. A useful existing test was highlighted as a potential starting point for extension.

**op-reth State Root Mismatch on Base Mainnet**
Issue [#19532](https://github.com/ethereum-optimism/infra/issues/19532) concerning recurring state root mismatches on Base mainnet `op-reth` nodes saw further comments. A user confirmed experiencing the same issue on custom chains like Manta Pacific. An Optimism team member suggested that since Base recently forked the OP Stack, the issue should be reported on the Base GitHub repository, with a link provided for cross-referencing.
