# ethereum-optimism/infra Daily Update (Mar 25, 2026)
## OVERVIEW 
Today's focus was on infrastructure improvements, including a critical bug fix for `cci-stats` related to flaky status markers and significant updates to Go versions and Docker Hardened Images across multiple services for enhanced security and efficiency.

## KEY TECHNICAL DEVELOPMENTS

*   **Infrastructure Hardening and Dependency Updates**
    *   Bumped Go to version 1.26 across most modules, excluding `op-conductor-mon`. ([#579](https://github.com/ethereum-optimism/infra/pull/579))
    *   Migrated all Dockerfiles to Docker Hardened Images (DHI) to reduce the attack surface. ([#579](https://github.com/ethereum-optimism/infra/pull/579))
    *   Removed unused runtime dependencies (e.g., `jq`, `curl`, `git`) from `proxyd`, `op-ufm`, and `peer-mgmt-service` Docker images, switching to a leaner `alpine-base:3.23` image. ([#580](https://github.com/ethereum-optimism/infra/pull/580))

*   **`cci-stats` Bug Fix**
    *   Fixed an issue in `cci-stats` where `mapFlakyStatus` incorrectly used `strings.HasPrefix` to detect `FLAKY_PASS`/`FLAKY_FAIL` markers, leading to missed matches due to the Go test framework embedding these markers mid-message. The fix now uses `Contains` for accurate detection. ([#578](https://github.com/ethereum-optimism/infra/pull/578))
