# ethereum-optimism/infra Daily Update (Mar 17, 2026)
## OVERVIEW 
Today's development focused on enhancing transaction logging in proxyd and addressing several flaky tests across the Optimism monorepo, improving CI stability and reliability.

## KEY TECHNICAL DEVELOPMENTS

### Enhanced Transaction Logging
A new feature was added to proxyd to log `sendRawTransaction` forwarding events, including `tx_hash`, `req_id`, `backend`, `backend_group`, and `duration_ms` when `enable_tx_hash_logging` is enabled. This provides more detailed insights into transaction processing and performance. ([#569](https://github.com/ethereum-optimism/infra/pull/569))

## NEWLY OPENED PULL REQUESTS
No new pull requests were opened today.

## CLOSED ISSUES

### Flaky Test Stabilization
Several flaky tests were investigated and fixed today, significantly improving the reliability of the CI pipeline. This includes `TestBreakTimestampInvariant` ([#18137](https://github.com/ethereum-optimism/infra/issues/18137)), `TestExpiredMessage` ([#19588](https://github.com/ethereum-optimism/infra/issues/19588)), `TestImplementations` ([#19583](https://github.com/ethereum-optimism/infra/issues/19583)), and `TestExecMsgDifferTxIndex` ([#19589](https://github.com/ethereum-optimism/infra/issues/19589)). The fixes addressed issues such as nonce races, overly tight timeouts in `RetryProxy`, and insufficient sync propagation.

### Supernode Reporting Correction
The issue where `op-supernode` was reporting the current derived L1 instead of the current verified L1 has been resolved. ([#18651](https://github.com/ethereum-optimism/infra/issues/18651))

### Glamsterdam Gas Pricing Investigation
The investigation into the impacts of Glamsterdam gas pricing on precompile acceleration has been closed, with further work being tracked in a separate issue. ([#19375](https://github.com/ethereum-optimism/infra/issues/19375))

### Blob Archiver Endpoint Support
An issue regarding the `blob-archiver` not supporting the `/eth/v1/beacon/blobs/` endpoint, which was breaking beacon fallback, has been closed and moved to the `ethereum-optimism/blob-archiver` repository for resolution. ([#19623](https://github.com/ethereum-optimism/infra/issues/19623))

## ACTIVE ISSUES

### op-node: Initial EL Sync UX and Correctness ([#17631](https://github.com/ethereum-optimism/infra/issues/17631))
Discussion continues on the behavior of `op-node` marking the reached target as finalized after initial EL Sync, even if the block is not actually finalized. The latest comments propose solutions such as continuing EL sync to the unsafe head and using a different finalization gadget. Options for the finalization gadget include a command-line flag, an RPC URL for a trusted checkpoint provider, looking at L1 for the last finalized head, or an arbitrary delay. The potential impact on `op-geth` and `opp-reth` is also being considered.

### [tracking]: Review kona-interop block hash oracle ([#18288](https://github.com/ethereum-optimism/infra/issues/18288))
The remaining task for this issue is to ensure an integration/acceptance test exists to verify that block lookups prior to the current history window function correctly.

### Supernode test coverage ([#19010](https://github.com/ethereum-optimism/infra/issues/19010))
