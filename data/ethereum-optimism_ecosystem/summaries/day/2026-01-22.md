The project completed the migration of Docker builds from CircleCI to GitHub Actions. This change streamlines the CI/CD pipeline and improves build efficiency. ([#972](https://github.com/ethereum-optimism/ecosystem/pull/972))

## ACTIVE ISSUES

### Withdrawal Proof Mechanism for Interoperability
Discussions on [#18517](https://github.com/ethereum-optimism/ecosystem/issues/18517) focused on ensuring `OptimismPortal2.proveWithdrawalTransaction` utilizes `IDisputeGame.rootClaim(uint256)` for verifying L2 chain output root proofs. A key point raised was the need to similarly update the `OptimismPortalInterop` contract. This is a critical step for enabling robust cross-chain withdrawal proofs within the Superchain.

### Updating Withdrawal Script for Interoperability
Regarding [#18615](https://github.com/ethereum-optimism/ecosystem/issues/18615), the team discussed updating the `op-chain-ops/cmd/withdrawal` script to leverage output roots for proving withdrawals, especially in the context of recent Super Dispute Game changes. It was noted that implementing [#18517](https://github.com/ethereum-optimism/ecosystem/issues/18517) first would significantly simplify this script, as the codepath for proving pre-interop and post-interop withdrawal transactions would become identical.
