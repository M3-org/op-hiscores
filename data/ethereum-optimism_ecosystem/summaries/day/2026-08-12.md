## ACTIVE ISSUES

### op-interop-filter RPC Blocking Issue
The issue [#21943](https://github.com/ethereum-optimism/ecosystem/issues/21943) highlights a problem where the `op-interop-filter` verdict RPC can block behind an ingester write lock, leading to fail-closed timeouts. A recent comment from `claude` on 2026-08-12 at 00:33:35Z describes another occurrence of this defect during testing, where a transaction with a fabricated access-list key failed due to a timeout instead of a definitive rejection. This behavior is consistent with the verdict path blocking behind the ingester write lock, and a fix would allow for immediate rejection.
