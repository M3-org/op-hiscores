# ethereum-optimism/ecosystem Daily Update (May 4, 2026)

## OVERVIEW 
The day saw significant progress in interop testing and infrastructure, with several key issues related to interop chain creation, stress testing, and supernode functionality being closed. Efforts focused on validating interop mechanisms and improving development tooling.

## CLOSED ISSUES

### Interop Chain Creation and Supernode Functionality
Several issues related to interop chain creation and supernode functionality were closed. This includes the resolution of an issue ensuring new chains can be created post-interop, with the decision to ship a new OPCM that deploys new chains into their own dependency set of 1, without support for shared dependency sets ([#15884](https://github.com/ethereum-optimism/ecosystem/issues/15884)). Additionally, a discussion around fetching super roots from `op-supernode` for unsafe data was closed, with the team opting for independent construction of expected super roots in tests rather than relying on `op-supernode` for unsafe data ([#19059](https://github.com/ethereum-optimism/ecosystem/issues/19059)).

### Kona Prestate Build and Test Porting
Improvements were made to the Kona prestate build process and test migration. A task to add a fast Kona prestate build was closed, indicating that Kona prestates can now be built outside of Docker, improving local development velocity ([#19057](https://github.com/ethereum-optimism/ecosystem/issues/19057)). Furthermore, missing "after head" tests were migrated to `op-supernode`, with all relevant tests now ported to `op-acceptance-test` and `supernode`, leading to the discovery and fix of a bug in `supernode` ([#20370](https://github.com/ethereum-optimism/ecosystem/issues/20370)).

### Duplicate Issue Resolution
A duplicate issue regarding `op-challenger` using the incorrect prestate URL for `SuperPermissionedGameType` was identified and closed ([#20500](https://github.com/ethereum-optimism/ecosystem/issues/20500)).

## ACTIVE ISSUES

### Interop Expiry Window Stress Testing
Discussion on [#15285](https://github.com/ethereum-optimism/ecosystem/issues/15285) (interop: Stress test expiry window) indicates that live devnet stress testing on `interop-jnt-v1` has been conducted. A Kona EIP-2935 proof decoding issue was found and fixed, allowing consolidation to complete cleanly. Stress tests with up to 4096 executing messages showed linear scaling of cost and successful termination in Cannon/MIPS, suggesting that extending the expiry window to 7 days is unlikely to cause completion issues. The analysis is considered sufficient, pending a merged RLP decoding fix with a test.

### L2CM Acceptance Testing on Betanet
Issue [#20089](https://github.com/ethereum-optimism/ecosystem/issues/20089) ([L2CM] Milestone: Acceptance testing on Betanet) was identified as a duplicate of [#18839](https://github.com/ethereum-optimism/ecosystem/issues/18839).

### Runbook for Super Root Chain Update
Discussion on [#20473](https://github.com/ethereum-optimism/ecosystem/issues/20473) (Runbook: Update super root chain from permissioned to permissionless with OPCMv2) suggests deferring this documentation update until after interop has shipped. The update is only required when a chain has upgraded to SuperDisputeGame (U20 at least) and then wants to move from permissioned to permissionless, making it non-blocking for the current release.
