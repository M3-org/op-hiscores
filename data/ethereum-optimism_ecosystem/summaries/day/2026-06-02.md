# ethereum-optimism/ecosystem Daily Update (Jun 2, 2026)
## OVERVIEW 
Today's development focused on a critical bug fix for Docker builds, ensuring lifecycle scripts are ignored. Discussions continued on `op-revm` synchronization and interop transaction pool recovery, with new issues opened for interop message recovery runbooks.

## KEY TECHNICAL DEVELOPMENTS

*   **Docker Build Process Improvement**
    *   Resolved an issue where Docker builds were not ignoring lifecycle scripts during dependency installation, improving build reliability and efficiency ([#1007](https://github.com/ethereum-optimism/ecosystem/pull/1007)).

## NEW ISSUES
*   **Interop Transaction Pool Recovery Challenges**
    *   An issue was identified where `op-reth`'s transaction pool does not resume accepting interop transactions after the `op-interop-filter` failsafe is disabled, requiring a restart of `op-reth` and `op-rbuilder` ([#21149](https://github.com/ethereum-optimism/ecosystem/issues/21149)).
*   **Invalid Interop Message Recovery**
    *   A new issue was created to develop and test a runbook for recovering a chain after an invalid interop message triggers a large reorg, addressing systems that do not smoothly handle such events ([#21161](https://github.com/ethereum-optimism/ecosystem/issues/21161)).
