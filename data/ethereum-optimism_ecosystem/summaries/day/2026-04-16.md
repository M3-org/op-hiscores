## ACTIVE ISSUES

### CrossL2Inbox Conditional Deployment
Discussion on [#19311](https://github.com/ethereum-optimism/ecosystem/issues/19311) regarding the conditional deployment of `CrossL2Inbox` continued. The latest comments clarify that the concern is not with `kona-node` itself, but rather ensuring that `kona-derive` and `kona-proof` do not generate spurious `CrossL2Inbox` deployments. It was noted that the core crates used by `kona-proof` and `kona-node` for post-interop derivation need to be adjusted to resolve this.

### GitHub Actions Workflow for Provenance Attestation
Issue [#20122](https://github.com/ethereum-optimism/ecosystem/issues/20122) was opened to add a GitHub Actions workflow to verify the provenance attestation of the `ci-base-clang` image. However, a subsequent comment indicated that this task will be rolled into an existing issue in the `optimism` repository.
